使用 Xcode 的 coding agent 設定 App Icon

Xcode 自從有了 coding agent，AI 能做的事愈來愈多。以下彼得潘示範如何使用 Xcode 的 coding agent 設定 App Icon。

按下 cmd + c 複製 Gemini 繪製的冰島旅遊 App icon。

打開 Xcode 的 Coding Assistant，選擇 Claude Agent，在輸入框按下 cmd + v 貼上圖片。

輸入以下 prompt。

將圖片設為 App Icon

AI 成功設定 App Icon，Assets 的 AppIcon 格子出現了冰島旅遊的 App icon。

App 執行後從桌面可看到 App Icon。
