Codex 超方便的截取當前視窗功能 Appshots

Codex 的新功能，截取當前視窗的 Appshots 超方便的 !

只要按下兩邊的 cmd 鍵，即可截取目前操作的視窗，詢問 Codex 相關問題。

Appshots — Codex | OpenAI Developers
Give Codex context from any Mac appdevelopers.openai.com

以下彼得潘以截取目前正在操作的 Xcode 視窗示範。

按下兩邊的 cmd 鍵觸發 Appshots，初次觸發時請先點選 Enable。

ps: 觸發 Appshots 前必須先啟動 Codex。

Appshots 觸發時將自動切換到 Codex App，prompt 裡出現了剛剛截取的 Xcode 視窗。

輸入 prompt 請 Codex 說明程式。

Appshots 不只對視窗截圖，還會讀取視窗裡的文字，因此視窗裡需要捲動才會看到的文字也能讀取。
