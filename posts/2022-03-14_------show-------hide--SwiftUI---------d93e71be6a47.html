依情況顯示(show) / 隱藏(hide) SwiftUI 元件的幾種方法

  • 方法 1: 利用 modifier opacity 設定透明度。
  • 方法 2: 利用 if。

方法 1: 利用 modifier opacity 設定透明度

  • 範例 1: 依據 showResult 是否為 true 設定 opacity。
struct ContentView: View {
    
    @State private var showResult = false
    @State private var result = ""

    var body: some View {
        
        VStack {
            Text(result)
                .font(.system(size: 200))
                .opacity(showResult ? 1 : 0)
            Button("Play") {
                result = ["😘", "😢"].randomElement()!
                showResult = true
            }
        }
    }
}
  • 範例 2: 依據 result 是否為空字串設定 opacity。
struct ContentView: View {
    
    @State private var result = ""

    var body: some View {
        
        VStack {
            Text(result)
                .font(.system(size: 200))
                .opacity(result.isEmpty ? 0 : 1)
            Button("Play") {
                result = ["😘", "😢"].randomElement()!
            }
        }
    }
}
  • 範例 3: 利用 overlay 顯示元件。

當元件的顯示 / 隱藏時，不影響畫面的排版。之前的兩個範例當表情符號顯示時，play button 都會下移。

struct ContentView: View {
    
    @State private var showResult = false
    @State private var result = ""
    
    var body: some View {
        
        ZStack {
            Color.yellow
               .ignoresSafeArea()
            
            Button("Play") {
                result = ["😘", "😢"].randomElement()!
                showResult = true
            }
        }
        .overlay(alignment: .top) {
            Text(result)
                .font(.system(size: 200))
                .opacity(showResult ? 1 : 0)
        }
    }
}

方法 2: 利用 if

  • 範例 1: 利用 if 檢查 showResult 是否為 true。
struct ContentView: View {
    
    @State private var showResult = false
    @State private var result = ""

    var body: some View {
        
        VStack {
            if showResult {
                Text(result)
                    .font(.system(size: 200))
            }
            Button("Play") {
                result = ["😘", "😢"].randomElement()!
                showResult = true
            }
        }
    }
}
  • 範例 2: 利用 if 檢查 result.isEmpty。
struct ContentView: View {
    @State private var result = ""
    
    var body: some View {
        
        VStack {
            if !result.isEmpty {
                Text(result)
                    .font(.system(size: 200))
            }
            Button("Play") {
                result = ["😘", "😢"].randomElement()!
            }
        }
    }
}
  • 範例 3: 利用 if let 判斷 result 是否有值。
struct ContentView: View {
    @State private var result: String?
    
    var body: some View {
        
        VStack {
            if let result = result {
                Text(result)
                    .font(.system(size: 200))
            }
            Button("Play") {
                result = ["😘", "😢"].randomElement()!
            }
        }
    }
}
