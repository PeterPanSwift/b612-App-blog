將 Xcode 開發 App 的 skills 加到 Codex 和 Claude Code — Xcode 27 新功能

Xcode 27 內建許多開發 App 的 skill，因此能幫助 AI 寫出更好的 App 。然而有時我們也想從別的軟體透過 AI 開發 App，比方 Codex 和 Claude Code，能不能讓它們的 AI 也享用這些好用的 skill 呢 ?

當然可以，Xcode 是很大方的。只要從 Terminal 輸入以下指令即可輸出這些強大的 skill。

xcrun agent skills export

結果。

從下圖可看到 Xcode 目前內建 10 個 skill。

比方 swiftui-specialist skill 將幫助 AI 開發更好的 SwiftUI App。

加到 Codex 和 Claude Code

拿到 skill 後，剩下的事就只是複製貼上了。

將 xcode-skills 下想要的 skill 資料夾複製到 Codex 和 Claude Code 存放 skill 的資料夾。

  • Codex: ~/.codex/skills。
  • Claude Code: ~/.claude/skills。

如果 ~/.claude 下沒有 skills 資料夾，請先在 ~/.claude 下建立 skills 資料夾。

以下我們以 Codex 為例說明。

比方想加入 swiftui-specialist skill，假設它的路徑是 ~/Desktop/xcode-skills/swiftui-specialist，請在 Terminal 輸入以下指令。

cp -r ~/Desktop/xcode-skills/swiftui-specialist ~/.codex/skills

若想將 xcode-skills 全部的 skill 資料夾複製到 ~/.codex/skills/，請輸入以下指令。

cp -r ~/Desktop/xcode-skills/* ~/.codex/skills

加入 swiftui-specialist skill 後，Codex 和 Claude Code 打 / 時都可看到 SwiftUI Specialist。
