使用 AI 開發 Xcode Source Editor Extension — 以 SwiftUI Unembed Container 為例

彼得潘最近發現 AI 很適合開發 Xcode Source Editor Extension，做一些自己想要的程式修改功能。

以 SwiftUI App 為例，Xcode 提供方便的 Embed in 功能，方便我們快速將元件包在另一個容器。但是它卻沒有提供相反的 unembed container 功能，因此我們只能自己辛苦地移除容器。

感謝 Claude Opus 5 的幫忙，雖然彼得潘對 Xcode Source Editor Extension 完全沒研究，還是能透過一句 prompt 加上幾次的 prompt 修正，快速生成unembed container 的 Xcode Source Editor Extension。

開發 Xcode Source Editor Extension，製作 SwiftUI 的 unembed 功能

程式的 GitHub 連結如下，有興趣的朋友可參考 AI 實作的細節和相關的疑難排解。

GitHub — PeterPanSwift/SwiftUIUnembed: Xcode Source Editor Extension that removes the SwiftUI…
Xcode Source Editor Extension that removes the SwiftUI container around the cursor — the inverse of Embed in VStack …github.com

參考以上 GitHub 的說明安裝後，Xcode menu 的 Editor 多出了 SwiftUI Unembed > Unembed Container。

Unembed Container 可以方便地移除 SwiftUI 容器，比方我們想將以下程式的 VStack 拿掉。

struct ContentView: View {
    var body: some View {
        VStack(spacing: 10) {
            Text("Hello, Peter Parker!")
                .padding()
        }
    }
}

只要游標點擊 VStack { } 內的任一個地方，然後點選 Unembed Container。

VStack 和 { } 就會神奇地消失 !

struct ContentView: View {
    var body: some View {
        Text("Hello, Peter Parker!")
            .padding()
    }
}

如果想要更快，我們還可從 Xcode Settings 的 Shortcuts 設定 Unembed Container 的快速鍵。

使用 AI 開發 Xcode Source Editor Extension 的注意事項

AI 經過多次修改才做出正確的版本，請 AI 開發時請記得提醒它以下事項。

  • XcodeKit.framework 要記得包進 bundle。
  • 要設定 Team 帳號，不能用 Sign to Run Locally／ad hoc。
