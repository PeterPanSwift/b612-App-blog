設定 UI 元件樣式和功能的 SwiftUI modifier(修改器)

SwiftUI 提供豐富的 modifier 幫助我們設定 UI 元件的樣式和功能，諸如陰影，旋轉等效果皆可透過 modifier 實現，而且我們還可以搭配方便的拖曳加入相關程式碼呢 !

當我們從 Quick Actions 點選 Show Library 顯示 Library 視窗(快速鍵 cmd + shift + L)，然後點選左邊數來第二個按鈕 Modifiers library，將可看到琳瑯滿目的 modifiers。

Modifiers 的分類

SwiftUI 提供了豐富的 Modifiers，主要分成以下類別。

  • Effect

邊框，圓角，陰影，旋轉等各種常見的效果。

  • accessibility

accessibility(輔助使用)相關的功能。

  • Controls

action sheet，alert 等功能。

  • Layout

調整元件的大小位置。

  • Text

調整文字，比方字型，底線，斜體，文字行數等。

  • Image

調整圖片，比方縮放圖片大小。

  • Style

調整元件的樣式，比方 Button 的樣式。

  • List

表格的相關功能，比方分隔線的顏色。

  • Events

元件相關事件發生時執行的程式，比方元件出現，元件消失等。

  • Gestures

手勢相關功能，比方點擊，長按和縮放。

  • Shape

形狀相關功能，比方設定填滿的顏色，線條的樣式。

  • Navigation Bar

Navigation Bar 相關功能。

  • Other

其它的 modifiers，比方動畫，元件觸碰是否有反應。

從 Apple 官方 View 文件的側邊欄，也可以查詢各類的 modifier。

View | Apple Developer Documentation
A type that represents part of your app's user interface and provides modifiers that you use to configure views.developer.apple.com

呼叫 modifier 的格式如下。

回傳新元件的 modifier

現在讓我們回頭仔細瞧瞧剛剛的程式。

struct ContentView: View {
    var body: some View {
        Text("知否知否 應是綠肥紅瘦")
            .bold()
    }
}

所謂的 modifier 其實是個 function，以下是 bold() 的宣告。

func bold() -> Text

從它的宣告我們明白它將回傳 Text。我們用 Text 元件呼叫 function bold()，得到變粗的 Text 元件，而這正是 modifier 最重要的概念。

modifier 會依據原本的元件和我們想要的設定調整，生成新的元件給我們。bold() 表示我們想要粗體的文字，因此它生成變粗的文字給我們。就好像原本彼得潘身高 175，當彼得潘呼叫改變身高的 modifier height(180) 後，將得到一個身高 180 的全新彼得潘。(不要問原來的彼得潘去哪了，很可怕)

modifier 的串聯

modifier 會依據原本的元件調整生成新 view，因此我們可以串接多個 modifier，不斷地為元件加入新的設定，生成我們最後想要的元件模樣。就好像彼得潘使用美肌 App 微調照片，先將臉變白，再把眼睛變大，最後再將頭髮染成金色，成為一個金髮大眼的白馬王子。

接下來就讓我們繼續對剛剛的知否宋詞添加 modifier foregroundStyle，試試 modifier 串聯的威力吧。

struct ContentView: View {
    var body: some View {
        Text("知否知否 應是綠肥紅瘦")
            .bold()
            .foregroundStyle(.orange)
    }
}

了解 modifier 將回傳產生新 view 的原理後，剛剛的程式其實也可以寫成以下的模樣，用不同的常數儲存 modifier 產生的東西。呼叫 bold() 得到粗體文字存在 boldText ，然後再用 boldText 呼叫 foregroundStyle(.orange) 得到放大的橘色文字存在 boldOrangeText ，最後再回傳 boldOrangeText。

struct ContentView: View {
    var body: some View {
        let boldText = Text("知否知否 應是綠肥紅瘦").bold()
        let boldOrangeText = boldText.foregroundStyle(.orange)
        return boldOrangeText
    }
}

相較之下原本的寫法簡單多了，因此多個 modifier 串聯時，我們習慣採用 single expression 撰寫，而且這樣還享有省略 return 的好處。

single expression 指的是可以執行的一段程式，剛剛採用多個常數儲存的寫法則有 3 個 expression。

也許有人好奇，原本寫法明明有 3 行，怎麼會是 single expression 呢 ?

Text("知否知否 應是綠肥紅瘦")
    .bold()
    .foregroundStyle(.orange)

如以下例子，我們也可以寫成一行。不過加上 enter 讓 .bold() 和 .foregroundStyle(.orange) 換到下一行的寫法，依然算是 single expression，而且還能讓可讀性更好。

struct ContentView: View {
    var body: some View {
        Text("知否知否 應是綠肥紅瘦").bold().foregroundStyle(.orange)
    }
}

加入 font 調整字體大小

font 裡我們可傳入各種字體大小的 Font，在此我們傳入 .title，希望文字大一點。

            .font(.title)

}

            .bold()

加入 clipShape 設定圓角
struct ContentView: View {
    var body: some View {
        Text("知否知否 應是綠肥紅瘦")
            .bold()
            .foregroundStyle(.orange)
            .font(.title)

加入設定邊距的 padding

加了圓角的文字顯得可愛多了，可惜文字有點太靠近邊邊，似乎被切到了。

這點小問題，利用 Padding modifier 即可解決。padding 是填空的意思，它可以在元件的上下左右添加空間，讓內容不會太靠近邊邊。

利用 padding() 讓元件的上下左右都加入預設大小的邊距。值得注意的，要先呼叫 padding，再呼叫 background，關於順序的問題我們待會再說明。

struct ContentView: View {
    var body: some View {
        Text("知否知否 應是綠肥紅瘦")
            .bold()
            .foregroundStyle(.orange)
            .font(.title)
            .padding()
            .background(.blue)
            .clipShape(.rect(cornerRadius: 10))
    }
}

加了邊距後，知否的文字漂亮多了，再也不會太靠近邊邊被切到了。

加入 rotationEffect 旋轉
struct ContentView: View {
    var body: some View {
        Text("知否知否 應是綠肥紅瘦")
            .bold()
            .foregroundStyle(.orange)
            .font(.title)
            .padding()
            .background(.blue)
            .clipShape(.rect(cornerRadius: 10))
            .rotationEffect(.degrees(30))
    }
}

利用 rotationEffect( ) 旋轉元件，我們傳入 .degrees(30)，讓它順時針旋轉 30 度。

如果想要更特別的旋轉，SwiftUI 還有殺手鐧，3D 旋轉的 Rotation 3D modifier !

比方以下程式將產生 3D 旋轉的文字效果。

struct ContentView: View {
    var body: some View {
        Text("知否知否 應是綠肥紅瘦")
            .bold()
            .foregroundStyle(.orange)
            .font(.title)
            .padding()
            .background(.blue)
            .clipShape(.rect(cornerRadius: 10))
            .rotation3DEffect(
                .degrees(30), axis: (x: 1.0, y: 1.0, z: 1.0)
            )
    }
}
轉吧七彩霓虹燈 ! SwiftUI 的 rotationEffect & rotation3DEffect
開發 SwiftUI App 時，利用 rotationEffect & rotation3DEffect 可實現各種有趣的旋轉效果。我們不只能控制旋轉的角度，還可以控制它延著 x, y, z 軸 & 某個 anchor 點旋轉。medium.com

modifier 串聯的縮排

串聯多個 modifier 時，最好遵照 SwiftUI 的縮排習慣增加程式的可讀性。下圖為 SwiftUI 多個 modifier 串聯時標準的縮排，每個 modifier 都往內縮排並獨立一行，讓我們一目瞭然 Text 元件添加了哪些效果。

struct ContentView: View {
    var body: some View {
        Text("知否知否 應是綠肥紅瘦")
            .bold()
            .foregroundStyle(.orange)
            .font(.title)
            .padding()
            .background(.blue)
            .clipShape(.rect(cornerRadius: 10))
            .rotation3DEffect(
                .degrees(30), axis: (x: 1.0, y: 1.0, z: 1.0)
            )
            .shadow(radius: 10)
    }
}

一般當我們輸入程式時，Xcode 會自動縮排。不過如果縮排不小心亂掉的話，還是有補救的方法，我們可以利用 Xcode 的 Format File with swift-format 縮排程式。(快速鍵 ctrl + shift + i )

利用 Xcode 的 Format File with swift-format 縮排程式 — Xcode 16 新功能
Xcode 從 16 開始內建縮排程式的工具 swift-format，現在縮排程式變得更加容易，按下快速鍵 ctrl + shift + i 即可用 Format File with swift-format 縮排整個檔案。medium.com

當然你喜歡的話也可以在同一行串接多個 modifier，不過這樣子將讓程式變得較不易理解閱讀。

struct ContentView: View {
    var body: some View {
        Text("知否知否 應是綠肥紅瘦")
            .bold().foregroundStyle(.orange)
            .font(.title).background(.blue).clipShape(.rect(cornerRadius: 10))
    }
}

modifier 串聯的順序

由於 modifier 會依原本的元件調整生成新的 view，modifier 串聯的順序將大大影響最後生成的東西。比方我們看看以下例子:

以下程式先利用 background 設定背景顏色，然後再用 rotationEffect 旋轉，最後順利生成藍色背景並旋轉 30 度的文字。

struct ContentView: View {
    var body: some View {
        Text("知否知否 應是綠肥紅瘦")
            .background(.blue)
            .rotationEffect(.degrees(30))
    }
}

但如果我們先用 rotationEffect 得到旋轉的文字，然後再用 background 產生藍色背景的文字呢 ?

struct ContentView: View {
    var body: some View {
        Text("知否知否 應是綠肥紅瘦")
            .rotationEffect(.degrees(30))
            .background(.blue)
    }
}

結果變得十分可怕 ! 因為旋轉後文字的框框依然是水平的，所以接著設定背景色時只有水平的區塊填滿藍色。

以下是另一個例子，說明 padding & background 順序不同的差異。

struct ContentView: View {
    var body: some View {
        Text("知否知否 應是綠肥紅瘦")
            .padding()
            .background(.blue)
    }
}
struct ContentView: View {
    var body: some View {
        Text("知否知否 應是綠肥紅瘦")
            .background(.blue)
            .padding()
    }
}
SwiftUI modifier 的順序(order)
開發 SwiftUI App 時，我們常串接多個 modifier 調整元件的樣式跟功能。大部分的 modifier 可以用任意順序串接，然而某些 modifier 卻要特別注意順序問題，以下我們分幾種情況討論。medium.com

有些 modifier 只能作用在某些元件

大部分的 modifier 可以加在任何的 SwiftUI 元件上，不過也有一些特例，只能作用在某些元件。

比方 resizable 只能作用在 Image 上，所以加到 Text 會產生錯誤。

有些 modifier 有累加效果

有些 modifier 有累加的效果，當我們重覆呼叫時，它會有累加的效果，比方以下 padding 的例子。

struct ContentView: View {
    var body: some View {
        Text("知否知否 應是綠肥紅瘦")
           .padding(10)
           .background(.blue)
    }
}

呼叫一次 padding 的畫面。

當我們呼叫第 2 次 padding(10) 時，SwiftUI 將讓上下左右再多出 10 points 的 padding。

struct ContentView: View {
    var body: some View {
        Text("知否知否 應是綠肥紅瘦")
           .padding(10)
           .padding(10)
           .background(.blue)
    }
}

旋轉也有累加的效果，因此我們可以先轉 30 度，再轉 60 度，最後元件變成旋轉 90 度。

struct ContentView: View {
    var body: some View {
        Text("知否知否 應是綠肥紅瘦")
            .background(.blue)
            .rotationEffect(.degrees(30))
            .rotationEffect(.degrees(60))
    }
}

offset 也有累加的效果。

struct ContentView: View {
    var body: some View {
        Text("知否知否 應是綠肥紅瘦")
            .background(.blue)
            .offset(CGSize(width: 100, height: 0))
            .offset(CGSize(width: 0, height: 100))
    }
}

不過每種 modifier 的效果不同，不是每個都會累加。比方以下程式將產生 largeTitle 的文字。

Text("peter")
    .font(.largeTitle)
    .font(.caption)

有些 modifier 可以作用在 child view

有些 modifier 會作用到 child view 上，有些不會，以下我們分別用 foregroundStyle 和 background 說明。

  • foregroundStyle 加在 VStack 上，作用在 child view Text 和 Image 上。
struct ContentView: View {
    var body: some View {
        VStack {
            Text("我的聲音在笑 淚在飆 電話那頭的你可知道")
            Image(systemName: "heart.slash.fill")
                .resizable()
                .scaledToFit()
        }
        .foregroundStyle(.pink)
    }
}

當 child view 也設定 foregroundStyle 時，child view 將採用自己設定的樣式。

struct ContentView: View {
    var body: some View {
        VStack {
            Text("我的聲音在笑 淚在飆 電話那頭的你可知道")
                .foregroundStyle(.purple)
            Image(systemName: "heart.slash.fill")
                .resizable()
                .scaledToFit()
        }
        .foregroundStyle(.pink)
    }
}
  • background 加在 VStack 上，只作用於 VStack，不影響 child view。
struct ContentView: View {
    var body: some View {
        VStack {
            Text("我的聲音在笑 淚在飆 電話那頭的你可知道")
            Image(systemName: "heart.slash.fill")
                .resizable()
                .scaledToFit()
        }
        .background(.yellow)
    }
}
