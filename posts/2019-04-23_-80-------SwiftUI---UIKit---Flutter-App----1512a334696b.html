Flutter
  • 定義 StatefulWidget。
  • 用到 setState。
  • 用到 callback function (Lifting State Up) 管理狀態。
  • 利用 Timer 實現計時、倒數或其它功能。
UIKit
  • 多個頁面。
  • 至少定義一個跟資料有關的型別，比方定義撲克牌的 Card 型別。
  • 利用 Timer 實現計時、倒數或其它功能。
  • 利用 UIViewPropertyAnimator 製作動畫效果。
  • 利用 IBSegueAction 傳資料。
  • 使用 UIAlertController。
