Firebase Firestore 多個欄位 query 的 index 問題

透過 Firebase 的 Firestore 我們可以方便地抓取雲端的資料，比方透過以下用 FirestoreQuery 宣告的 property 可讀取 songs 下 mood 是 😢 的悲傷情歌。

@FirestoreQuery(collectionPath: "songs", predicates: [
     .isEqualTo("mood", "😢")
]) var songs: [Song]

不過當我們的 query 比較複雜，需要同時結合多個欄位時，可能會遇到資料無法抓取的問題，比方以下程式的 query 會判斷 mood & rate，抓取以 rate 排序的悲傷情歌。

@FirestoreQuery(collectionPath: "songs", predicates: [
        .isEqualTo("mood", "😢"),
        .order(by: "rate")
]) var songs: [Song]

此時資料將無法抓取，Xcode 的 Console 會印出以下錯誤訊息。

2022-05-21 16:02:22.049754+0800 Demo[2197:25002] 9.0.0 - [FirebaseFirestore][I-FST000001] Listen for query at songs failed: The query requires an index. You can create it here: https://console.firebase.google.com/v1/r/project/fir-4ef1c/firestore/indexes?create_composite=Ckdwcm9qZWN0cy9maXItNGVmMWMvZGF0YWJhc2VzLyhkZWZhdWx0KS9jb2xsZWN0aW9uR3JvdXBzL3NvbmdzL2luZGV4ZXMvXxABGggKBG1vb2QQARoICgRyYXRlEAEaDAoIX19uYW1lX18QAQ

ps: 使用另一種寫法 whereField 設定條件也會遇到一樣的問題。

let db = Firestore.firestore()
db.collection("songs").whereField("mood", isEqualTo: "😢").order(by: "rate").getDocuments { snapshot, error in
}

錯誤訊息裡最關鍵的是這句話，The query requires an index。我們必須加上 index 才能順利讀取資料。但是要怎麼加 index 呢 ?

很簡單，剛剛的錯誤訊息裡提供了一串網址，將它貼到瀏覽器上，它將自動連到 Firebase 網站，然後貼心地自動跳出 create index 的視窗。從下圖可看到 Fields 裡提到的 mood & rate 正是剛剛我們 query 判斷的欄位。

點選 Create index 後，Cloud Firestore 的 indexes > Composite 分頁將顯示正在建立的 index。請注意它的 Status 狀態，Building 表示還在建立中，通常需要幾分鐘的時間才能建立完成。

請再稍等一下，等 Status 變成 Enabled 時即可順利在 query 時同時判斷 mood & rate。
