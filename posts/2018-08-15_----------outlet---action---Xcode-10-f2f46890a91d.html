從拉線位置聰明判斷 outlet / action 的 Xcode 10

開發 iOS App 時，我們每天照三餐拉著 outlet 和 action。outlet 產生存取畫面上元件的變數，action 產生事件發生時觸發的 function。

在舊版的 Xcode 拉 action 比較麻煩，因為拉線預設會產生 outlet，要另外手動切換才會變成 action。

Xcode 10 看到了我們的困擾，現在它變得更聰明貼心了。從我們拉線到程式碼的位置就能判斷我們想要 outlet 還是 action。

定義 class 時，我們習慣在前面宣告 property，後面定義 function，就像以下類別 Baby 的例子。

class Baby {
   var age = 1
   var name = "peter"
  
   func sleep() {
      print("😴😴😴")
   }
   func eat() {
      print("🍼🍼🍼")
   }
}

因此當我們拉線到 class 的第一個 function 之前時，Xcode 將猜測我們想要拉 outlet。若是拉線到第一個 function 之後，則認為我們想要拉 action。

任何事都要親眼看見才能相信，不然誰知道 Xcode 是不是說說而已。接下來我們就以 Yaya 同學的擇偶條件 App 實驗證明吧。

鴨鴨 The One App
終於要把APP介面跟swift code結合在一起惹medium.com
1 拉線到第一個 function viewDidLoad 之前將產生 outlet。
@IBOutlet weak var starTextField: UITextField!
2 拉線到第一個 function viewDidLoad 之後將產生 action。
@IBAction func buttonPressed(_ sender: Any) {
}

Xcode 10 果然真心不騙，就像它在 release note 裡說的:

Control-dragging from Interface Builder to a Swift source file defaults to creating @IBOutlet when the insertion point is above the first method in a class, and @IBAction otherwise.
