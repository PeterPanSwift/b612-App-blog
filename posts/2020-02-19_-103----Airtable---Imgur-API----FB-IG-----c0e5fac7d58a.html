#103 利用 Airtable & Imgur API 製作 FB，IG 動態牆

初學者因為不會寫後台，通常會利用 Firebase 當後台練習開發 App，不過使用 Firebase 的 iOS App 公司其實不多。

最近研究了一下，新手也可以考慮利用 Airtable & Imgur API 上傳資料，練習使用 URLSession 開發結合網路功能的 App 。

利用 Airtable 製作 iOS App 連結的後台資料
Airtable 擁有強大的資料表單功能，如下圖所示，美美的表格可以在瞬間完成，而且欄位裡可輸入多種類型的資料，比方文字，時間，圖片，多選的選項等都不是問題。medium.com
串接 Airtable的 API 開發 iOS App
在之前的文章，我們介紹了如何利用 Airtable 製作 iOS App 連結的後台資料，建立包含電影資料的表單。接下來我們將繼續介紹如何串接它的 API。medium.com
Swift iOS App 的圖片上傳，以 remove.bg & Imgur API 為例
網路上有很多幫助我們練習串接後台的第三方 API，不過如果想做到圖片上傳，相關的 API 就比較少了。彼得潘研究了一下，發現以下兩個 API 特別適合初學者練習圖片上傳的相關技術。medium.com
