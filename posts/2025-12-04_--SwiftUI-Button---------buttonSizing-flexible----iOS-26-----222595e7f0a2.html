讓 SwiftUI Button 佔滿可用空間的 buttonSizing flexible — iOS 26 新功能

SwiftUI Button 的預設大小將貼心地剛好等於內容的大小，因此以下例子的 Login & Register Button 因字數的不同而有不同的寬度。

struct ContentView: View {
    var body: some View {
        VStack {
            Button("Login") {
                
            }
            
            Button("Register") {
                
            }
        }
        .buttonStyle(.borderedProminent)
        .padding()
    }
}

然而有時我們想要 button 有一樣的寬度，或是想要 button 的寬度佔滿可用空間，這在以前得加上不少程式才能實現，但在 iOS 26 透過新推出的 modifier buttonSizing(_:) 一下子就能搞定。

buttonSizing(_:) | Apple Developer Documentation
The preferred sizing behavior of buttons in the view hierarchy.developer.apple.com

利用 buttonSizing(.flexible)，我們可讓 button 的寬度變成可用空間的寬度。

  • 範例 1。
struct ContentView: View {
    var body: some View {
        VStack {
            Button("Login") {
                
            }
            
            Button("Register") {
                
            }
        }
        .buttonStyle(.borderedProminent)
        .buttonSizing(.flexible)
        .padding()
    }
}
  • 範例 2。
struct ContentView: View {
    var body: some View {
        VStack {
            Button {
                
            } label: {
                Text("Login")
            }
            Button {
                
            } label: {
                Text("Register")
            }
        }
        .buttonStyle(.borderedProminent)
        .buttonSizing(.flexible)
        .padding()
    }
}

結合 buttonSizing(.flexible) & frame(width: 200)，實現指定寬度的多個 Button。

  • 範例 1。
struct ContentView: View {
    var body: some View {
        VStack {
            Button("Login") {
                
            }
            
            Button("Register") {
                
            }
        }
        .buttonStyle(.borderedProminent)
        .buttonSizing(.flexible)
        .frame(width: 200)
    }
}
  • 範例 2。
struct ContentView: View {
    var body: some View {
        VStack {
            Button {
                
            } label: {
                Text("Login")
            }
            Button {
                
            } label: {
                Text("Register")
            }
        }
        .buttonStyle(.borderedProminent)
        .buttonSizing(.flexible)
        .frame(width: 200)
    }
}
