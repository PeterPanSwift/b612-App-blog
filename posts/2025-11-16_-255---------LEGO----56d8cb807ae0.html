#255 創作可愛的樂高(LEGO)公仔

使用 SwiftUI、UIKit 或 Flutter 創作可愛的樂高(LEGO)公仔。

功能需求

從 LEGO 創作公仔的網頁取得圖片素材，點擊圖片換圖。

https://www.lego.com/en-us/minifigure-factory

點選 Customize your minifigure。

取得預設的身體 & 腳。

取得想要替換的圖片。

  • 範例: Head。
  • 範例: Headwear。
  • 範例: Torso。

SwiftUI 程式範例。

struct ContentView: View {
    var body: some View {
        ZStack {
            Image(.leg)
            Image(.body)
            Image(.head1)
                .offset(y: -80)
            Image(.headwear1)
                .scaleEffect(1.2)
                .offset(y: -110)
            Image(.clothes1)
                .scaleEffect(1.1)
                .offset(y: 10)
        }
    }
}

範例: 點選頭像換臉。
