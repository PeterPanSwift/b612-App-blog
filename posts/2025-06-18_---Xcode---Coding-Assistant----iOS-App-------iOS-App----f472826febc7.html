  • 啟用 Xcode 的 Coding intelligence。
  • 專案設定 git。
  • 開啟 AI 聊天。
  • 請 AI 訂定 App 實作計畫(Plan Mode)。
  • 開始實作程式。
  • 測試 App。
  • 請 AI 修改程式。
  • 還原 AI 修改的程式。
  • 專案的 GitHub 連結。

啟用 Xcode 的 Coding intelligence

使用 Coding Assistant 前，我們必須先啟用 Xcode 的 Coding intelligence，設定幫忙的 AI model。

使用 Xcode 的 Coding intelligence 開發 App

專案設定 git

專案必須設定 git 才能還原 AI 修改的程式跟保存聊天記錄，因此使用 AI 修改程式前最好先儲存專案，勾選 Create Git repository on my Mac。

勾選 Create Git repository on my Mac。

一定要記得，勾選 Git 之後進行的聊天才會儲存，勾選 Git 之前進行的聊天都會煙消雲散。

開啟 AI 聊天有 6 種方法，相關說明可參考以下連結。

聰明的 model 會消耗較多 AI 用量，而且也會花更多時間完成工作。建議依照工作的難度選擇合適的 model，比較困難的工作才使用比較聰明的 model。當笨的 model 無法完成任務時，再試試更聰明的 model 或其它家的 model。

以下彼得潘選擇使用 Codex 的 GPT-6-Astra。

請 AI 訂定 App 實作計畫(Plan Mode)

請 AI 寫程式前，我們可以請 AI 花點時間訂定 App 的開發計畫，之後它依據計畫將能開發更好的 App。

  • 方法 1: 打開 Plan Mode 的開關。
  • 方法 2: 輸入 /plan。

指定 Plan Mode 後，以下我們請 AI 設計可愛的打地鼠 App，將地鼠改成北極狐。

出現 AI 正在思考中的轉圈按鈕。

點擊它將打開聊天頁面。AI 工作時有時需要執行指令，此時會出現如下圖的權限請求。

通常都可以點選 Allow 同意。如果希望同樣的指令之後都直接執行，不要再問我們，也可以點選 Always Allow These Commands。

AI 為了訂定更好的計畫，它有時會先詢問我們一些問題(Q&A)。以下彼得潘選擇 30秒挑戰、原創插畫、連擊競技、加入音效。

AI 依據我們的回答訂定詳細的 App 開發計畫，列出一條條功能清單。

我們可以手動修改計畫，或是滑鼠移到想調整的地方點擊 @ 按鈕，輸入修改的 prompt。

開始實作程式

點擊 Implement the plan 的 Yes，請 AI 開始實作程式。

我們使用的 AI Codex 有繪圖能力，它生成可愛的北極狐圖片，將圖加到了 Assets。

ps: Xcode 的 Codex & Antigravity 可繪製精美的圖片，Claude Agent 只能繪製 SVG。

使用 Xcode 的 Codex & Antigravity 繪製 iOS App 的 assets 圖片和 App Icon
Xcode 的 Codex & Antigravity 不只會寫程式，還可以生成圖片並加到 assets。以下彼得潘使用 Codex 示範說明。medium.com

AI 成功完成 App，而且還自己確認程式建置成功，沒有任何語法錯誤。

測試 App

切換到 Project navigator，點選 Assets 可看到 AI 繪製的可愛北極狐。

點選 ContentView，右邊的 Canvas 出現了 App 畫面。

我們可以從 Canvas 操作測試 App。彼得潘遊玩時發現遊戲真的有音效，程式採用的是系統內建的音效，我們也可以另外加入音效檔，然後再請 AI 修改程式。

請 AI 為 iOS App 加入影音播放功能
當我們想在 iOS App 播放音樂或影片時，只要提供檔案或網址，AI 就能幫我們搞定。medium.com

請 AI 修改程式

一個 100 分的 App 當然不是一句 prompt 就搞定，我們可以不斷調整，麻煩 AI 修改程式新增功能。比方我們可以請它繪製三種不同的北極狐，打到時有不同的分數。

建議使用 New Conversation in Editor Pane 開啟新對話，或是點擊左上的星星按鈕後用 Open in Editor Pane 開啟舊對話，方便我們同時看到 App 畫面和聊天畫面。
