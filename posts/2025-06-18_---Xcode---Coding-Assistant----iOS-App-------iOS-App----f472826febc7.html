使用 Xcode 的 Coding Assistant 開發 iOS App — 第一個 iOS App 作業

從 Xcode 26 開始，我們終於可以出一張嘴下 prompt 請 Xcode 的 AI Coding Assistant 生出 App。

以下彼得潘使用 Xcode 27 的 Coding Assistant 示範，製作超可愛的打北極狐 App。

  • 啟用 Xcode 的 Coding intelligence。
  • 專案設定 git。
  • 開啟新聊天。
  • 請 AI 訂定 App 實作計畫(Plan Mode)。
  • 開始實作程式。
  • 測試 App。
  • 請 AI 修改程式。

啟用 Xcode 的 Coding intelligence

使用 Coding Assistant 前，我們必須先啟用 Xcode 的 Coding intelligence，設定幫忙的 AI model。

打開 Xcode 的 Coding intelligence — Xcode 26 新功能
從 Xcode 26 開始，我們終於可以出一張嘴下 prompt 請 AI 幫忙開發 App 了。medium.com

專案設定 git

專案必須設定 git 才能儲存我們跟 AI 的聊天記錄，因此記得專案要先設定 git，儲存專案時勾選 Create Git repository on my Mac。

開啟新聊天

點擊上方的 + 開啟新聊天。

點選下方長得像開關的按鈕可調整 AI model。

彼得潘選擇使用 Codex 的 GPT-5.6-Sol。

請 AI 訂定 App 實作計畫(Plan Mode)

請 AI 寫程式前，我們可以請 AI 花點時間訂定 App 的開發計畫，之後它依據計畫開發將能完成更好的 App。

  • 方法 1: 打開 Plan Mode 的開關。
  • 方法 2: 輸入 /plan。

指定 Plan Mode 後，以下我們請 AI 設計可愛的打地鼠 App，將地鼠改成北極狐。

出現 AI 正在思考中的轉圈按鈕。

點擊它將打開聊天頁面。AI 工作時有時需要執行指令，此時會出現如下圖的權限請求。

通常都可以點選 Allow 同意。如果希望同樣的指令之後都直接執行，不要再問我們，也可以點選 Always Allow These Commands。

AI 為了訂定更好的計畫，它有時會先詢問我們一些問題(Q&A)。以下彼得潘選擇 30秒挑戰、原創插畫、連擊競技、加入音效。

AI 依據我們的回答訂定詳細的 App 開發計畫，列出一條條功能清單。

完整的內容可參考以下連結。

開始實作程式

點擊 Implement the plan 的 Yes，請 AI 開始實作程式。

我們使用的 AI Codex 有繪圖能力，它生成可愛的北極狐圖片，將圖加到了 Assets。

AI 成功完成 App，而且還自己確認程式可以建置成功，沒有任何語法錯誤。

測試 App

切換到 Project navigator，點選 Assets 可看到 AI 繪製的可愛北極狐。

點選 ContentView，右邊的 Canvas 出現了 App 畫面。

我們可以從 Canvas 操作測試 App。彼得潘遊玩時發現遊戲真的有音效，程式採用的是系統內建的音效，我們也可以另外加入音效檔，然後再請 AI 修改程式。

請 AI 修改程式

一個 100 分的 App 當然不是一句 prompt 就搞定，我們可以不斷調整，麻煩 AI 修改程式新增功能。

比方我們可以請它繪製三種不同的北極狐，打到時有不同的分數。

我們可以按 + 開啟新對話。

或是點選左上的星星打開 Coding Assistant，開啟之前的聊天頁面輸入 prompt。

輸入 prompt。

AI 繪製了兩種北極狐，第三個是透過程式在狐狸身上添加藍圍巾。
