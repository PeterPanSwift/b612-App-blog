取得 Google 登入需要的 OAuth client ID

串接 Google 登入時，我們需要搭配 OAuth client ID。接下來彼得潘將示範如何取得 OAuth client ID。

取得 Google 登入需要的 OAuth 用戶端(client) ID

開發 App 的 Google 登入功能時，我們需要搭配 OAuth 用戶端 ID。接下來彼得潘將示範取得 ID 的相關步驟。

連到 Google Developers Console 的憑證頁

https://console.cloud.google.com/apis/credentials

選取專案或建立專案

在此我們點選建立專案。

點選建立憑證 > OAuth 用戶端 ID。

點選設定同意畫面。

點選開始。

照著網頁輸入專案的相關資訊。

專案建立後，點選建立 OAuth 用戶端。

選擇應用程式類型，在此我們選擇 iOS。

輸入 iOS App 的相關資訊。軟體包 ID 是 App 的 bundle ID，只要輸入 軟體包 ID 即可建立，App Store ID、團隊 ID 和 Firebase App Check 可先跳過。

複製用戶端 ID。
