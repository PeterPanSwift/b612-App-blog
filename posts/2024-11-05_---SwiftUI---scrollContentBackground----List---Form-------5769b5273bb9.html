利用 SwiftUI 的 scrollContentBackground 取消 List / Form 預設的背景

當我們使用 SwiftUI 的 List / Form 設計 App 畫面時，它會預設有背景顏色，就像以下可愛 emoji 動物清單的例子。

struct ContentView: View {
    let animals = ["🐶", "🐱", "🐭", "🐹", "🐰", "🦊", "🐻"]
    
    var body: some View {
        List(animals, id: \.self) { animal in
            Text(animal)
                .font(.largeTitle)
        }
    }
}

此時就算加了 background modifier 也無法改變背景顏色。

struct ContentView: View {
    let animals = ["🐶", "🐱", "🐭", "🐹", "🐰", "🦊", "🐻"]
    
    var body: some View {
        List(animals, id: \.self) { animal in
            Text(animal)
                .font(.largeTitle)
        }
        .background(.yellow)
    }
}

若想改變 List / Form 的背景色，我們必須透過 scrollContentBackground 隱藏它預設的背景。

scrollContentBackground(_:) | Apple Developer Documentation
Specifies the visibility of the background for scrollable views within this view.developer.apple.com

加了 scrollContentBackground(.hidden)後，background modifier 終於能成功設定背景顏色。

struct ContentView: View {
    let animals = ["🐶", "🐱", "🐭", "🐹", "🐰", "🦊", "🐻"]
    
    var body: some View {
        List(animals, id: \.self) { animal in
            Text(animal)
                .font(.largeTitle)
        }
        .scrollContentBackground(.hidden)
        .background(.yellow)
    }
}

ps: 當 List 的 style 設為 plain 時也能取消預設的背景。

struct ContentView: View {
    let animals = ["🐶", "🐱", "🐭", "🐹", "🐰", "🦊", "🐻"]
    
    var body: some View {
        List(animals, id: \.self) { animal in
            Text(animal)
                .font(.largeTitle)
        }
        .listStyle(.plain)
        .background(.yellow)
    }
}
