如何將 Xcode 專案資料夾壓縮成 zip
常常有學生問彼得潘問題，需要將專案程式碼傳給彼得潘參考。除了 Github 連結分享外，另一個比較簡單的方法是直接將專案資料夾壓縮成 zip 後傳給彼得潘，步驟如下:medium.com

不過壓縮成 zip 其實也有更快的方法，接下來就讓我們利用 Xcode behavior 一鍵生成專案的 zip 檔。

下載 zipApp.sh

https://bit.ly/3mgZUme

zipApp.sh 的內容如下，它將壓縮專案的資料夾，產生 app.zip。

#!/bin/sh
osascript <<END
tell application "Terminal"
if not (exists window 1) then reopen
activate
do script "cd `pwd`;zip -r app.zip .;open ." in window 1
end tell
END

zipApp.sh 下載後將存在 Downloads 資料夾下，請將它移到你想儲存的地方。在此彼得潘將它移到 Documents 資料夾下。

將 zipApp.sh 變成可執行的檔案

  • 打開 Terminal App。
如何在 Mac 啟動輸入神奇咒語的 terminal
江湖傳說，terminal (終端機)是 iOS App 工程師一定要精通的強大工具，透過它可輸入許多神奇的指令咒語，瞬間完成高難度的複雜工作。在學習這些古怪咒語前，先讓我們了解如何啟動沉睡的 terminal 吧。medium.com

輸入以下指令。(假設 zipApp.sh 存在 Documents 資料夾下)

cd Documents
chmod +x zipApp.sh

打開 Xcode 的 Behaviors 視窗

從 Xcode 的 menu 選擇 Xcode > Behaviors > Edit Behaviors。

點選左下的 + 新增 Behavior

輸入名稱 zip project

勾選下方的 Run

點選 Run 旁的 Choose Script

選擇 zipApp.sh

大功告成 ! 現在我們可以開始測試一鍵生成專案的 zip 檔。

生成專案的 zip 檔

打開 Xcode 專案後，從 Xcode 的 menu 點選 Xcode > Behaviors > zip project。

此時專案資料夾將自動壓縮成 app.zip，而且 Finder 視窗也將自動打開顯示 app.zip。
