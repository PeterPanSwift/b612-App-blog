如何在 Xcode 的 App Playground 加入圖片

透過 Xcode 的 App Playground template 開發 App 時，生成的專案是 swiftpm，因此有些地方會跟 Xcode project 不太一樣。

其中有個明顯的差異是 App Playground 預設沒有存放圖片的 Asset。

若想將圖片加到專案，請依據以下步驟新增 Asset。

從 Quick Actions 點選 New > File from Template。

選擇 iOS 下的 Asset Catalog。

生成 Media.xcassets。

在 Media.xcassets 加入圖片。

現在可以在 swift 程式顯示圖片了，可在 Image( ) 裡傳入 "friend" 或 .friend。

import SwiftUI

struct ContentView: View {
    var body: some View {
        VStack {
            Image("friend")
                .resizable()
                .scaledToFit()
            Image(.friend)
                .resizable()
                .scaledToFit()
        }
       
    }
}

以下是幾個要注意的小問題。

  • 若想從 Swift Playground 編輯 swiftpm，Image( ) 裡不能傳入 .friend，此寫法只能在 Xcode 使用。
  • 圖片要放在 Asset，直接放在 Project navigator 下將無法讀取。
