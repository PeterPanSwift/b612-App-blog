數學和程式的經典分組問題(Ceiling Division)

算數學和寫程式時，我們時常會遇到經典的分組問題，例如以下例子。

有 8 個小 🦊，每 3 個一組，可分成幾組呢 ?

彼得潘跟 AI 討論後，整理了以下幾種算法。

  • 無條件進位、天花板除法。
  • 判斷餘數，有餘數加 1 組。
  • 加上一組的數量 — 1 後再除。
  • Swift Algorithms 的 chunks(ofCount:)。

無條件進位、天花板除法

8 / 3 = 2.667，進位成 3。

import Foundation

let total = 8
let perGroup = 3
let groups = Int(ceil(Double(total) / Double(perGroup)))

判斷餘數，有餘數加 1 組

8 / 3 的商為 2，餘數為 2，因此需要加 1，結果為 3。

  • 寫法 1。
let total = 8
let perGroup = 3
let (quotient, remainder) = total.quotientAndRemainder(dividingBy: perGroup)
let groups = quotient + (remainder > 0 ? 1 : 0)
  • 寫法 2。
let total = 8
let perGroup = 3
let isDivisible = total.isMultiple(of: perGroup)
let groups = total / perGroup + (isDivisible ? 0 : 1)

加上一組的數量 — 1 後再除

let total = 8
let perGroup = 3
let groups = (total + perGroup - 1) / perGroup

剛剛的 (total + perGroup — 1) / perGroup 也可以改成以下寫法。

let groups = (total - 1) / perGroup + 1

Swift Algorithms 的 chunks(ofCount:)

GitHub - apple/swift-algorithms: Commonly used sequence and collection algorithms for Swift
Commonly used sequence and collection algorithms for Swift - apple/swift-algorithmsgithub.com
import Algorithms

let total = 8
let perGroup = 3
let groups = (1...total).chunks(ofCount: perGroup).count
