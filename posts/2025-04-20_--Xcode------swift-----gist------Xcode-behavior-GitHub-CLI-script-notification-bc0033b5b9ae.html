撰寫將 swift 變成 gist 的 script createGist.sh

#!/bin/sh

activePath=$(osascript <<'OSA'
tell application "Xcode"
    if not (exists window 1) then return
    set wName to name of window 1
    try
        set docPath to path of (document 1 whose name ends with (word -1 of wName))
        POSIX path of docPath
    on error
        return
    end try
end tell
OSA
)

export PATH="$PATH:/opt/homebrew/bin"  
gistURL=$(gh gist create "$activePath" --public | tail -n1)
printf "%s" "$gistURL" | pbcopy
osascript -e "display notification \"$gistURL\""

以上 script 將進行以下動作。

  • 找到 Xcode 目前正在編輯的檔案。
  • 利用 gh gist create 指令將檔案內容變成 gist。如果不想公開 gist，請拿掉指令結尾的 — public。

ps: 為了讓 Xcode behavior 能找到 gh 指令，必須加入 export PATH="$PATH:/opt/homebrew/bin" 。

  • 將 gist 的網址複製到剪貼簿。
  • 顯示通知，內容為 gist 的網址。

剛剛的 script 產生的 gist 檔名將為 swift 的檔名，若想進一步加上 gist 的描述，可另外透過 display dialog 顯示輸入描述的輸入框。

#!/bin/sh

activePath=$(osascript <<'OSA'
tell application "Xcode"
    if not (exists window 1) then return
    set wName to name of window 1
    try
        set docPath to path of (document 1 whose name ends with (word -1 of wName))
        POSIX path of docPath
    on error
        return
    end try
end tell
OSA
)

description=$(osascript <<'OSA'
tell application "System Events"
    activate
    try
        text returned of (display dialog ¬
            "請輸入這份 Gist 的描述：" ¬
            default answer "" ¬
            with title "Share to Gist 🦊" ¬
            buttons {"Cancel", "OK"} ¬
            default button 2)
    on error number -128 -- 使用者按了 Cancel
        return ""
    end try
end tell
OSA
)

[[ -z "$description" ]] && exit 0

export PATH="$PATH:/opt/homebrew/bin"  
gistURL=$(gh gist create "$activePath" -d "$description" --public | tail -n1)
printf "%s" "$gistURL" | pbcopy
osascript -e "display notification \"$gistURL\""

寫好 script 後，記得要設定檔案的執行權限。

chmod +x createGist.sh

設定執行 script 的 Xcode behavior 和快速鍵

新增 behavior Create Gist，設定執行 createGist.sh，快速鍵設為 cmd + option + ctrl + i。(ps: 搭配 g 的快速鍵都已被佔用，彼得潘只好使用 i)
