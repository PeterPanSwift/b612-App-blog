使用快速鍵縮放獨立視窗的 Android 模擬器

當我們使用 Antigravity IDE、VS Code 開發 Flutter App 時，啟動 Android 模擬器會變成下圖的獨立視窗。

不過有時會遇到視窗太大，甚至超出整個螢幕的問題。

此時我們可透過以下快速鍵縮放模擬器。

  • Windows 
    放大: ctrl + 向上的方向鍵。
    縮小: ctrl + 向下的方向鍵。
  • Mac
    放大: cmd + 向上的方向鍵。
    縮小: cmd + 向下的方向鍵。
