使用 Xcode 的 coding agent 修正 iOS App 專案的程式錯誤

相較於一般的 AI，擁有 agent 功能的 AI 在改完程式後還會自我檢查是否正確，因此我們可以方便地透過 agent 修正 App 專案的程式錯誤。

以下彼得潘示範使用 Xcode 的 coding agent 修正 App 專案的程式錯誤。

首先我們修改 Apple 的 Landmarks 專案，故意讓它出現一些錯誤。

接著打開 Xcode 的 Coding Assistant，選擇具備 agent 功能的 Codex 或 Claude Agent。

在 prompt 輸入簡單明瞭的 fix error。

AI 成功地修正多個檔案的錯誤，Issue navigator 變得乾乾淨淨，一個錯誤也沒有。
