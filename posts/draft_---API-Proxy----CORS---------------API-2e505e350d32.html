如果網頁部署在自己的後台，我們可在自己的後台實作讓網頁串接的 API，然後再從後台串接第三方 API。

如果網頁部署在第三方平台，則可透過第三方平台提供的機制實現 API Proxy，比方 Cloudflare Worker、Cloudflare Pages Function、Firebase Functions、Supabase Edge Functions、Vercel Function 等。
