設定 Xcode 專案 Build Settings 的 User-Defined Setting

開發 iOS App 時，我們可在 Xcode 專案 Build Settings 加入額外的設定，透過在 User-Defined Setting 區塊新增欄位。

新增的方法如下，點選 Build Settings 頁面左上的 + > Add User-Defined Setting，然後輸入欄位的名稱和內容。

以下我們示範兩個例子。

  • 定義 accent color name。

透過 User-Defined 的

ASSETCATALOG_COMPILER_GLOBAL_ACCENT_COLOR_NAME 設定，當我們從 New Project > App 快速建立專案時，它預設不會設定 accent color name，因此我們要自己在 Assets 加入 AccentColor，然後將 ASSETCATALOG_COMPILER_GLOBAL_ACCENT_COLOR_NAME 設為 AccentColor。

  • 定義自訂的 API 網址。

User-Defined 的內容可以區分 Debug 和 Release，很適合用來定義需要在 Debug 和 Release 版本有不同內容的資料。比方下圖的 API_BASE_URL。

若要從程式讀取 User-Defined 設定的內容，則須另外於 Info 設定。以剛剛的 API_BASE_URL 為例，我們在 Info 設定 APIBaseURL，指定 value 為 $(API_BASE_URL)，表示它的內容來自 User-Defined 的 API_BASE_URL。

之後在 App 裡透過以下程式即可讀出 API_BASE_URL 設定的網址。

if let baseURL = #bundle.object(forInfoDictionaryKey: "APIBaseURL") as? String {
    print(baseURL)
}
