使用線上 IDE Replit 開發 Python 程式

Replit 是跑在雲端的 IDE，我們只要從瀏覽器連到 Replit 即可開發各種程式，省下在自己電腦設定開發環境的時間。

以下我們一步步示範利用 Replit 開發 Python 程式的方法。

  • 建立 Replit 帳號。
  • 建立 Python 專案開發程式。
  • 執行 Python 程式。
  • 顯示 Python 程式生成的視窗畫面。
  • 分享專案程式。

建立 Replit 帳號

從瀏覽器連到 Replit 網站。

https://replit.com/

點選右上方的 Create account 建立帳號。

選擇免費方案 Create with Starter。

建立 Python 專案開發程式

點選 Developer Frameworks。

在右上的搜尋框輸入 python，出現 python 相關的樣版清單。

選擇 Python 建立基本的 Python 專案，點選 Use Framework。

輸入專案名稱，點選 Use Framework。

成功建立專案，視窗如下。

點選右上的 icon 打開專案的檔案清單。

點選 main.py，輸入 python 程式。

執行 Python 程式

點選左上的三角形執行程式。

從 Console 分頁可查看程式列印的內容。

點選三角形執行 python 程式時會自動檢查是否要安裝額外的套件。比方在 main.py 輸入使用 pandas 的骰子範例。

import pandas as pd
import random

# 1️⃣ 模擬擲骰子 100 次
dice_results = [random.randint(1, 6) for _ in range(100)]

# 2️⃣ 用 Pandas 建立 DataFrame
df = pd.DataFrame({
    "Dice": dice_results
})

print("🎲 擲骰子結果（前 10 筆）")
print(df.head(10))

# 3️⃣ 統計每個點數出現次數
count = df["Dice"].value_counts().sort_index()

print("\n📊 每個點數出現次數")
print(count)

# 4️⃣ 算平均值
average = df["Dice"].mean()
print(f"\n✨ 平均點數是：{average:.2f}")

點選三角形執行後將自動安裝 pandas，因此 Console 順利地出現擲骰子結果。

從 pyproject.toml 可發現 dependencies 新增了 pandas。

顯示 Python 程式生成的視窗畫面

若 Python 程式會產生視窗畫面，則需開啟 VNC 分頁才能看到畫面。

點選 +。

點選 VNC。

以下我們用 turtle 繪製冰島國旗，示範 Python 程式在視窗繪製的畫面。

在 main.py 輸入繪製冰島國旗的程式。(ps: 使用 Claude Opus 4.5 生成)

import turtle

# 設定畫布和畫筆
screen = turtle.Screen()
screen.title("冰島國旗 🇮🇸")
screen.setup(500, 360)  # 比例約 25:18

t = turtle.Turtle()
t.speed(0)  # 最快速度，不然會畫到睡著
t.hideturtle()

# 冰島國旗的顏色（官方色碼）
BLUE = "#02529C"   # 藍色 - 代表大西洋和天空
WHITE = "#FFFFFF"  # 白色 - 代表冰雪
RED = "#DC1E35"    # 紅色 - 代表火山岩漿 🌋

# 畫矩形的小幫手函數
def draw_rectangle(x, y, width, height, color):
    t.penup()
    t.goto(x, y)
    t.pendown()
    t.fillcolor(color)
    t.begin_fill()
    for _ in range(2):
        t.forward(width)
        t.right(90)
        t.forward(height)
        t.right(90)
    t.end_fill()

# 旗幟尺寸
flag_width = 500
flag_height = 360
unit = flag_width / 25  # 把寬度分成 25 份，方便計算

# 起始位置（左上角）
start_x = -flag_width / 2
start_y = flag_height / 2

# 1️⃣ 先畫藍色背景（整片藍天～）
draw_rectangle(start_x, start_y, flag_width, flag_height, BLUE)

# 2️⃣ 畫白色水平條紋（橫的那條白色毛衣）
white_h_y = start_y - 7 * unit  # 從上面數下來 7 份
draw_rectangle(start_x, white_h_y, flag_width, 4 * unit, WHITE)

# 3️⃣ 畫白色垂直條紋（直的那條白色毛衣）
white_v_x = start_x + 7 * unit  # 從左邊數過來 7 份
draw_rectangle(white_v_x, start_y, 4 * unit, flag_height, WHITE)

# 4️⃣ 畫紅色水平條紋（橫的紅色內搭）
red_h_y = start_y - 8 * unit  # 在白色中間
draw_rectangle(start_x, red_h_y, flag_width, 2 * unit, RED)

# 5️⃣ 畫紅色垂直條紋（直的紅色內搭）
red_v_x = start_x + 8 * unit  # 在白色中間
draw_rectangle(red_v_x, start_y, 2 * unit, flag_height, RED)

# 完成！
screen.mainloop()

執行程式後從 VNC 分頁看到漂亮的冰島國旗。

其它範例: 使用 Python Tkinter 製作可愛的猜數字。

ps: Replit 沒有安裝 Emoji 或中文字型，因此若畫面上呈現 Emoji 和中文字將變成醜陋的方塊。

分享專案程式

點選左上的專案 icon，然後點選 Share。

複製專案網址。

https://replit.com/@b612firebase/Demo2?v=1

當朋友連到專案網址從 Code 分頁即可查看程式內容，若想執行程式則須點選 Remix this app 將程式變成自己的專案。
