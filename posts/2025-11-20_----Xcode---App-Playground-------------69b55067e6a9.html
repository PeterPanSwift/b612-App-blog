如何在 Xcode 的 App Playground 加入非程式的影音素材檔

透過 Xcode 的 App Playground template 開發 App 時，生成的專案是 swiftpm，因此有些地方會跟 Xcode project 不太一樣。

在一般的 Xcode 專案，將影音，文字等素材檔加到 Project navigator 即可讀取。然而對 swiftpm 來說，卻要費一番工夫。

以下彼得潘以 AI Suno 創作的歌曲 Little Dreams 說明。

小小的夢想 (Little Dreams)
小小的夢想 (Little Dreams) by UnhurriedCassetteTape012 (@unhurriedcassettetape012). Listen and make your own on Suno.suno.com

首先我們將 Little Dreams.mp3 加入 swiftpm 的 Project navigator。

然後利用 AVPlayer 播放音樂。

import SwiftUI
import AVFoundation

struct ContentView: View {
    let player = AVPlayer(url: #bundle.url(forResource: "Little Dreams", withExtension: "mp3")!)
    
    var body: some View {
        Button("Play") {
            player.play()
        }

    }
}

App 執行後馬上閃退，因為找不到 Little Dreams.mp3。

為了讓 swiftpm 認得程式以外的素材檔，我們必須新增資料夾存放素材，然後從 Package.swift 將資料夾設為 resources。以下為逐步實行的步驟。

從右鍵選單點選 New Folder。

命名資料夾，通常會命名為 Resources。

在資料夾下加入 Little Dreams.mp3。

接著編輯 swiftpm 的 Package.swift。swiftpm 其實是資料夾，從右鍵選單點選 Show Package Contents 可查看資料夾的內容。

打開 Package.swift。

找到 executableTarget 區塊。

在 executableTarget( ) 裡加入 resources 設定存放素材的資料夾名字，剛剛我們新增的資料夾是 Resources，因此輸入 .process("Resources")。

resources: [
    .process("Resources")
]

現在 App 終於能播放 Little Dreams.mp3，再也不會閃退了。

若有多種素材檔，我們也可在 Resources 下建立資料夾分類，Package.swift 則不用修改，只要設定 .process("Resources") 即可找到 Resources 子資料夾的檔案。

另外圖片除了加到 Resources 下，還有更簡單的做法，只要新增 Assets 存放圖片即可，相關說明可參考以下連結。
