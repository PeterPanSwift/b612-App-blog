使用 DiceBear API 快速生成多張圖片網址

學習 App 程式開發時，我們常常需要在畫面上顯示多張圖片，比方練習用 SwiftUI 的 LazyVGrid 製作格子照片牆。

從前為了讓畫面豐富點，我們要花許多時間準備圖片素材。最近彼得潘跟 AI 請教後，發現有個超棒的 DiceBear API 可以快速生成多張圖片網址。

DiceBear | Open Source Avatar Library & API
DiceBear is a free, open source avatar library and avatar API with 52 styles. Create deterministic SVG profile pictures…www.dicebear.com

DiceBear API 可生成超過 1 億種的圖片，因此拿來練習程式時不太需要擔心圖片會重覆。

DiceBear API 的基本格式如下。

https://api.dicebear.com/10.x/風格/圖片格式?seed=種子值

DiceBear 可生成 52 種風格，詳細的清單可參考以下連結。

Avatar Styles - Browse 52 Avatar Designs
Browse 52 styles and generate avatars with the DiceBear avatar library. From abstract patterns to character designs…www.dicebear.com

以下我們採用 adventurer 風格，png 格式，因此 API 格式變這樣。

https://api.dicebear.com/10.x/adventurer/png?seed=種子值

不同的種子值可生成不同的圖片。任何東西都可以當種子值，英文、中文、日文、數字都可當種子值。

https://api.dicebear.com/10.x/adventurer/png?seed=peter
https://api.dicebear.com/10.x/adventurer/png?seed=彼得潘
https://api.dicebear.com/10.x/adventurer/png?seed=100

同一個 API 網址將產生固定的圖片，因此可確保程式每次抓取時都會顯示同一張圖片。

以下我們以 SwiftUI 的 LazyVGrid 為例，示範串接 DiceBear API 製作格子照片牆。

  • 以英文名字當種子值。
struct ContentView: View {
    let names = ["peter", "mike", "jack", "john", "penny", "marry"]
    let columns = [GridItem(), GridItem()]
    
    var body: some View {
        LazyVGrid(columns: columns) {
            ForEach(names, id: \.self) { name in
                AsyncImage(url: URL(string: "https://api.dicebear.com/10.x/adventurer/png?seed=\(name)"))

            }
        } 
    }
}
  • 以數字當種子值。
struct ContentView: View {
    let columns = [GridItem(), GridItem()]
    
    var body: some View {
        LazyVGrid(columns: columns) {
            ForEach(0..<6) { number in
                AsyncImage(url: URL(string: "https://api.dicebear.com/10.x/adventurer/png?seed=\(number)"))

            }
        }              
    }
}

除了 DiceBear API，RoboHash API 也有類似功能，一樣可用任何字串生成圖片網址，有興趣的朋友可參考以下連結。

RoboHash
Robohash is a easy web service that makes it easy to provide unique, robot/alien/monster/whatever images for any text…robohash.org

範例。

struct ContentView: View {
    let names = ["peter", "mike", "jack", "john", "penny", "marry"]
    let columns = [GridItem(), GridItem()]
    
    var body: some View {
        LazyVGrid(columns: columns) {
            ForEach(names, id: \.self) { name in
                AsyncImage(url: URL(string: "https://robohash.org/\(name).png"))
            }
        }
    }
}
