Main actor-isolated conformance of xxx to Decodable cannot be used in nonisolated context

在 iOS App 解析網路 API 抓到的 JSON 資料時，我們通常會用 JSONDecoder 將資料解碼成自訂的 Decodable 型別，例如以下程式將 JSON 解碼成 SearchResponse。

struct SearchResponse: Codable {
    let resultCount: Int
    let results: [StoreItem]
}

struct StoreItem: Codable {
    let artistName: String
    let trackName: String
}

class ViewController: UIViewController {

    override func viewDidLoad() {
        super.viewDidLoad()
        // Do any additional setup after loading the view.

        let urlStr = "https://itunes.apple.com/search?term=swift&media=music&country=tw"
        if let url = URL(string: urlStr) {
            URLSession.shared.dataTask(with: url) { data, response , error in
                if let data {
                    let decoder = JSONDecoder()
                    do {
                        let searchResponse = try decoder.decode(SearchResponse.self, from: data)
                        print(searchResponse)
                    } catch {
                        print(error)
                    }
                }
            }.resume()
        }
    }
}

然後從 Swift 6.2 開始，Xcode 專案預設將 Default Actor Isolation 設為 MainActor，因此專案裡定義的型別和 function 都會預設在 main actor & main thread 執行。

此時剛剛的 JSON 解碼程式將產生警告，Main actor-isolated conformance of ‘SearchResponse’ to ‘Decodable’ cannot be used in nonisolated context; this is an error in the Swift 6 language mode。

問題出在型別 SearchResponse 的程式跑在 main thread，但是 dataTask completionHandler 傳入的 decode 程式跑在 background thread，因此會有衝突。

修正警告的方法主要有以下三種。

  • Codable 型別加上 nonisolated。
  • 使用 DispatchQueue.main.async。
  • 使用 async 版本的 URLSession method。

Codable 型別加上 nonisolated

讓 SearchResponse 的程式可在 background thread 執行。

nonisolated struct SearchResponse: Codable {
    let resultCount: Int
    let results: [StoreItem]
}

使用 DispatchQueue.main.async

讓解碼的 decode function 在 main thread 執行。

class ViewController: UIViewController {
    
    override func viewDidLoad() {
        super.viewDidLoad()
        // Do any additional setup after loading the view.
        
        let urlStr = "https://itunes.apple.com/search?term=swift&media=music&country=tw"
        if let url = URL(string: urlStr) {
            URLSession.shared.dataTask(with: url) { data, response , error in
                if let data {
                    let decoder = JSONDecoder()
                    DispatchQueue.main.async {
                        do {
                            let searchResponse = try decoder.decode(SearchResponse.self, from: data)
                            print(searchResponse)
                        } catch {
                            print(error)
                        }
                    }
                    
                }
            }.resume()
        }
    }
}

使用 async 版本的 URLSession method

Swift 6.2 開始，Xcode 專案預設將 Default Actor Isolation 設為 MainActor，因此以下 ViewController 呼叫 decode 的程式將在 main thread 執行。

class ViewController: UIViewController {
    
    override func viewDidLoad() {
        super.viewDidLoad()
        // Do any additional setup after loading the view.
        
        let urlStr = "https://itunes.apple.com/search?term=swift&media=music&country=tw"
        if let url = URL(string: urlStr) {
            Task {
                do {
                    let (data, _) = try await URLSession.shared.data(from: url)
                    let decoder = JSONDecoder()
                    let searchResponse = try decoder.decode(SearchResponse.self, from: data)
                    print(searchResponse)
                } catch {
                    print(error)
                }
            }
        }
    }
}
