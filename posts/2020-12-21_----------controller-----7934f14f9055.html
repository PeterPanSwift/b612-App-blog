將資料回傳到前一頁 controller 的問題

開發 iOS App 時，我們時常在 controller 間溝通 & 傳資料。不過傳資料可分成兩種，一種是將資料傳到下一頁，一種是將資料回傳到前一頁。

以下圖為例，點選 New Event 頁面的 Repeat Cell 跳到下一頁，在 Repeat 頁面選擇重覆的頻率後，SelectFrequencyTableViewController 將返回前一頁並將選擇的頻率告訴 EditEventTableViewController。

將資料回傳到前一頁有很多不同的方法，例如以下 4 種

  • unwind segue (一定要返回之前的頁面）
  • delegate (可以不返回之前的頁面）
  • notification (可以不返回之前的頁面）
  • closure callback (可以不返回之前的頁面）

接下來我們將示範如何利用 delegate 實現資料回傳，不過在這之前我們將先示範一個可行但比較不好的做法，然後再改成 delegate 的做法。

範例: 選擇最愛的動物

第一頁 FavoriteAnimalViewController 將顯示可愛的動物圖片。點選請選擇 button 可進入 SelectAnimalViewController 頁面選擇最愛的動物，點選動物 button 後將返回前一頁，顯示選擇的動物圖片。

需解決的問題

為了實現剛剛的 App，點選動物 button 返回前一頁時，SelectAnimalViewController 必須將選擇的動物告訴 FavoriteAnimalViewController，如此 FavoriteAnimalViewController 才能顯示正確的動物圖片。

所以 SelectAnimalViewController 要怎麼告訴 FavoriteAnimalViewController 選擇的動物呢？

宣告 property 儲存前一個畫面的 controller

其實有一個最容易想到但有些缺點的方法。我們只要在 SelectAnimalViewController 利用 property 儲存 FavoriteAnimalViewController，即可將資料傳給 FavoriteAnimalViewController 。接下來就讓我們一步步實現吧。

在 asset 加入可愛動物的圖片

定義代表動物的型別 Animal

enum Animal: String {
    case cat, fish, dog
}

定義 FavoriteAnimalViewController & SelectAnimalViewController

FavoriteAnimalViewController

class FavoriteAnimalViewController: UIViewController {
    @IBOutlet weak var animalImageView: UIImageView!
    
    func selectAnimal(_ animal: Animal) {
        animalImageView.image = UIImage(named: animal.rawValue)
    }
    
    override func viewDidLoad() {
        super.viewDidLoad()
    }

    @IBSegueAction func showSelectAnimal(_ coder: NSCoder) -> SelectAnimalViewController? {
        let selectAnimalViewController = SelectAnimalViewController(coder: coder)
        selectAnimalViewController?.favoriteAnimalViewController = self
        return selectAnimalViewController
    }
}

SelectAnimalViewController

class SelectAnimalViewController: UIViewController {
    
    var favoriteAnimalViewController: FavoriteAnimalViewController?
    
    override func viewDidLoad() {
        super.viewDidLoad()
    }
    
   
    @IBAction func selectAnimal(_ sender: UIButton) {
        switch sender.currentTitle {
        case "🐈":
            favoriteAnimalViewController?.selectAnimal(.cat)
        case "🐠":
            favoriteAnimalViewController?.selectAnimal(.fish)
        case "🦮":
            favoriteAnimalViewController?.selectAnimal(.dog)
        default:
            break
        }
        navigationController?.popViewController(animated: true)
    }
}

透過下圖分割畫面並排 FavoriteAnimalViewController & SelectAnimalViewController，我們可以更容易理解程式的邏輯。

當畫面從 FavoriteAnimalViewController 切換到 SelectAnimalViewController 時，IBSegueAction function showSelectAnimal 將被觸發，我們在其中設定 SelectAnimalViewController 的 property favoriteAnimalViewController。而當使用者選擇某個動物 button 時，將觸發 IBAction selectAnimal，我們從 button 的 currentTitle 判斷選擇的動物，然後呼叫 FavoriteAnimalViewController 的 selectAnimal 顯示動物圖片。
