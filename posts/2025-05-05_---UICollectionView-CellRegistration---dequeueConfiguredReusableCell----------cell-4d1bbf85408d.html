使用 UICollectionView.CellRegistration & dequeueConfiguredReusableCell 更安全簡潔地生成 cell

從 iOS 14 開始，UICollectionView 可以利用 CellRegistration & dequeueConfiguredReusableCell 更安全簡潔地生成 cell。相較於之前的 dequeueReusableCell，它享有許多好處，比方以下幾點。

  • 不須設定 Reusable ID。

Reusable ID 必須以字串輸入，有著容易打錯的缺點。

  • 不須用 as 轉型 cell 型別。
  • 註冊和設定 cell 的程式集中在一個地方。

以下我們以可愛的動物 emoji 為例示範 UICollectionView.CellRegistration & dequeueConfiguredReusableCell 的寫法。

從 storyboard 設定顯示動物清單的 collection view

  • 在 storyboard 的 view controller 加入 collection view，移除它的 cell，controller 的類別設為繼承 UIViewController 的 AnimalCollectionViewController。

CellRegistration 的寫法可搭配程式、 xib & SwiftUI 設計的 cell，無法搭配 storyboard 設計的 cell，等下我們將利用 xib 檔設計 cell。

  • collection view 的 Scroll Direction 設為 Horizontal。
  • cell 的大小固定為 100 * 100，Estimate Size 設為 None，間距(Min Spacing For Cells)設為 10。
  • 設定 collection view 的 dataSource 為 AnimalCollectionViewController。

設計顯示動物的 AnimalCollectionViewCell

  • 新增 AnimalCollectionViewCell 的 swift & xib 檔。
  • 在 cell 裡用 stack view 裝顯示 emoji 和名字的 label，連結 outlet 生成 nameLabel & emojiLabel。
import UIKit

class AnimalCollectionViewCell: UICollectionViewCell {
    
    @IBOutlet weak var nameLabel: UILabel!
    @IBOutlet weak var emojiLabel: UILabel!
    
    override func awakeFromNib() {
        super.awakeFromNib()
        // Initialization code
    }

}

定義動物型別 Animal

struct Animal {
    let name: String
    let emoji: String
}

定義 AnimalCollectionViewController，使用 CellRegistration & dequeueConfiguredReusableCell 設定 cell

import UIKit

class AnimalCollectionViewController: UIViewController {
    let animals = [
        Animal(name: "fox", emoji: "🦊"),
        Animal(name: "penguin", emoji: "🐧"),
        Animal(name: "elephant", emoji: "🐘"),
        Animal(name: "tiger", emoji: "🐯"),
        Animal(name: "lion", emoji: "🦁"),
        Animal(name: "snake", emoji: "🐍"),
        Animal(name: "rabbit", emoji: "🐇"),
    ]
    
    let cellRegistration = UICollectionView.CellRegistration<AnimalCollectionViewCell, Animal>(cellNib: UINib(nibName: "AnimalCollectionViewCell", bundle: Bundle(for: AnimalCollectionViewCell.self))) { cell, indexPath, animal in
        cell.emojiLabel.text = animal.emoji
        cell.nameLabel.text = animal.name
    }
    
   
    override func viewDidLoad() {
        super.viewDidLoad()
        // Do any additional setup after loading the view.
        
    }

}

extension AnimalCollectionViewController: UICollectionViewDataSource {
    
    func collectionView(_ collectionView: UICollectionView, numberOfItemsInSection section: Int) -> Int {
            return animals.count
    }
    
    func collectionView(_ collectionView: UICollectionView, cellForItemAt indexPath: IndexPath) -> UICollectionViewCell {
        let animal = animals[indexPath.item]
        return collectionView.dequeueConfiguredReusableCell(using: cellRegistration, for: indexPath, item: animal)
    }
}

說明

  • 生成 UICollectionView.CellRegistration。
let cellRegistration = UICollectionView.CellRegistration<AnimalCollectionViewCell, Animal>(cellNib: UINib(nibName: "AnimalCollectionViewCell", bundle: Bundle(for: AnimalCollectionViewCell.self))) { cell, indexPath, animal in
    cell.emojiLabel.text = animal.emoji
    cell.nameLabel.text = animal.name
}

利用 CellRegistration 的 init(cellNib:handler:) 註冊要生成的 cell 和設定 cell 的內容。

init(
    cellNib: UINib,
    handler: @escaping UICollectionView.CellRegistration<Cell, Item>.Handler
)

<AnimalCollectionViewCell, Animal> 表示生成的 cell 型別為 AnimalCollectionViewCell，對應的資料型別為 Animal。參數 cellNib 傳入UINib(nibName: "AnimalCollectionViewCell", bundle: Bundle(for: AnimalCollectionViewCell.self)) 表示 cell 從 AnimalCollectionViewCell.xib 檔設計，參數 handle 傳入設定 cell 內容的 closure 程式，closure 的第三個參數將為 cell 要顯示的動物資料。

值得注意的，生成的 CellRegistration 要存在 controller 的 property，因為之後用 dequeueConfiguredReusableCell 生成 cell 時必須傳入 CellRegistration。

ps: 如果 cell 從程式或 SwiftUI 設計，而非 xib，可搭配 CellRegistration 的另一個 init，init(handler:)。

init(handler: @escaping UICollectionView.CellRegistration<Cell, Item>.Handler)
  • 生成 cell。

利用 dequeueConfiguredReusableCell 生成 cell，傳入 cellRegistration、indexPath & animal。

func collectionView(_ collectionView: UICollectionView, cellForItemAt indexPath: IndexPath) -> UICollectionViewCell {
    let animal = animals[indexPath.item]
    return collectionView.dequeueConfiguredReusableCell(using: cellRegistration, for: indexPath, item: animal)
}

搭配 UICollectionViewDiffableDataSource & UICollectionViewCompositionalLayout

CellRegistration 還可以搭配 UICollectionViewDiffableDataSource & UICollectionViewCompositionalLayout 實現更現代化的 collection view 做法，有興趣的朋友也可以再試試。
