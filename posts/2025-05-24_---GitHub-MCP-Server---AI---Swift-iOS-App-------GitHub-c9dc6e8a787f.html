透過 GitHub MCP Server 我們可以控制 AI 執行 GitHub 的相關操作，以下彼得潘以 Swift iOS App 專案為例，示範從 VS Code 出一張嘴叫 GitHub Copilot 完成專案的版本管理並上傳到 GitHub。

GitHub - github/CopilotForXcode: Xcode extension for GitHub Copilot
Xcode extension for GitHub Copilot. Contribute to github/CopilotForXcode development by creating an account on GitHub.github.com

在 Mac 上設定 GitHub MCP Server
最近 GitHub 推出了 GitHub MCP Server，方便我們透過 AI 執行 GitHub 的相關操作。medium.com

以下是彼得潘準備上傳到 GitHub 的 Xcode 專案。

從 VS Code 打開 App 的專案資料夾，將 GitHub Copilot 設為 Agent 模式，prompt 輸入 Create GitHub repository & push project to GitHub。

GitHub Copilot 開始進行一連串的動作，目標將 App 專案上傳到 GitHub。

Agent 模式的 copilot 在執行指令前會禮貌地徵求同意，比方下圖詢問是否透過 GitHub MCP Server 在 GitHub 建立 repository FirstApp。

copilot 還會仔細研究修改的程式，幫我們寫出適合的 commit 訊息。

Copilot 認真地執行一連串動作後，成功完成任務，App 專案在 GitHub 的網址為 https://github.com/PeterPanSwift/FirstApp。以下是 GitHub Copilot 執行的完整工作內容。
