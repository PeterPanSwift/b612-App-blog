控制點選範圍的 contentShape

利用 contentShape 我們可以控制點選的範圍，接下來讓我們看看以下幾種應用的例子。

控制點選範圍的 contentShape

利用 contentShape 我們可以控制點選的範圍，接下來讓我們看看以下幾種應用的例子。

  • 讓空白地方可點選。
  • 設定只有形狀內的區塊可點選。
  • 加大點選範圍。

讓空白地方可點選

原本只有文字可點選，文字右邊的空白區塊不能點選。

struct ContentView: View {
    let songs = [
        "你好不好",
        "小幸運"
    ]
    var body: some View {
        List(songs,id: \.self) { song in
            Text(song)
                .onTapGesture {
                    print(song)
                }
        }
    }
}

在 Text 加上 frame maxWidth .infinity 讓它的寬度佔滿可用空間，然後再加上 contentShape(.rect) 讓整個長方形區塊都可點擊。

Text(song)
    .frame(maxWidth: .infinity, alignment: .leading)
    .contentShape(.rect)
    .onTapGesture {
        print(song)
    }

設定只有形狀內的區塊可點選

原本圓形以外的空白區塊也可點選。

struct ContentView: View {
    var body: some View {
        Image(.fox)
            .resizable()
            .scaledToFill()
            .frame(width: 300, height: 300)
            .background(.yellow)
            .clipShape(.circle)
            .onTapGesture {
                print("tap")
            }
    }
}

我們想要只有圓形區塊可以點選，加入 modifier contentShape(.circle)，設定圓形範圍是點選區塊。

struct ContentView: View {
    var body: some View {
        Image(.fox)
            .resizable()
            .scaledToFill()
            .frame(width: 300, height: 300)
            .background(.yellow)
            .clipShape(.circle)
            .contentShape(.circle)
            .onTapGesture {
                print("tap")
            }
    }
}

加大點選範圍

原本只有點我可以點選。

struct ContentView: View {
    var body: some View {
        Text("點我")
            .onTapGesture {
                print("點我")
            }
    }
}

加大點選範圍，讓文字附近 100 * 100 的區塊都可點選。

struct ContentView: View {
    var body: some View {
        Text("點我")
            .frame(width: 100, height: 100)
            .contentShape(.rect)
            .onTapGesture {
                print("點我")
            }
    }
}
