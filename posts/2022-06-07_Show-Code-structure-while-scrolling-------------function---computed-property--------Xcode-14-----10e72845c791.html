Show Code structure while scrolling: 將目前瀏覽的程式型別，function & computed property 釘在上方 — Xcode 14 新功能

從 Xcode 14 開始，我們上下捲動瀏覽程式時可以更清楚地看出目前瀏覽的區塊是哪，不再迷失在茫茫的程式大海裡，因為 Xcode 會將目前瀏覽的程式型別，function & computed property 釘在上方。

接下來讓我們看看幾個不同的例子吧。

將型別釘在上方

當我們正在瀏覽型別 DonutGallery { } 的程式時，DonutGallery 將被釘在上方。

將 function 釘在上方

當我們正在瀏覽型別 TopDonutSalesChart 的 function donutFromAxisValue 時，TopDonutSalesChart & donutFromAxisValue 將被釘在上方。

將 computed property 釘在上方

當我們正在瀏覽型別 DonutGallery 的 computed property body 時，，DonutGallery & body 將被釘在上方。

只有一行程式的 function & computed property 不會釘在上方

Baby 的 age & sleep 都不會釘在上方，因為它們只有短短的一行，沒有資格釘在上方。

struct Baby {
    var age: Int {
        Int.random(in: 1...100)
    }
    func sleep() {
        print("😴😴😴😴😴")
    }
}

控制是否將型別，function & computed property 釘在上方

  • 點選 Xcode > Preferences。
  • 切換到 Text Editing 頁面，勾選 Show: 的 Code structure while scrolling 將打開釘在上方的功能。
