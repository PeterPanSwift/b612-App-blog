在 Windows 安裝最新版的 Python

連到 Python 官網的 Download 頁面。

Download Python
The official home of the Python Programming Languagewww.python.org

點選 Download Python install manager。

點選 python-manager 的 Open file。

點選 Install Python。

點選 Launch Python。

詢問是否允許超過 260 個字的 path，輸入 y 更新。

點選 Yes。

輸入 y。

完成安裝。

在 PowerShell 輸入 py、python 或 python 3 查詢剛剛安裝的 Python。

py -V

結果: Python 3.14.2。
