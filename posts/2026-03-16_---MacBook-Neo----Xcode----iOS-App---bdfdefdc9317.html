使用 MacBook Neo 搭配 Xcode 開發 iOS App ?

感謝 Straight A 香港，最近彼得潘有機會開箱 MacBook Neo，實驗一個自己跟許多同學關心的問題，採用 Apple A18 Pro 晶片跟 8 GB 記憶體的 Neo 能不能開發 iOS App ?

在測試前我們已經可以肯定 Neo 能安裝執行 Xcode 跟開發 iOS App，畢竟它的作業系統是 macOS，因此當然可以跑 Xcode。剩下的問題變成它適不適合初學者學程式，寫程式會不會 lag，編譯大型 App 的時間是否可以忍受 ?

接下來彼得潘將進行一系列的實驗，並且跟自己平常使用的 MacBook Pro M3 Max 36 GB 比較。

一開始先來幾張開心的開箱照。

從 App Store 下載安裝 Xcode，Neo 成功地運行 Xcode，啟動的速度也滿快的。

接著建立全新的 SwiftUI App 專案，基本的操作和寫程式都滿 ok 的，不過第一次測試時，Preview 的畫面跟 iOS 模擬器都跑不起來，還好重開機後就恢復正常了。

全新 SwiftUI 專案在 Neo 的 build 時間為 8.2 秒。

M3 Max 是 2.7 秒。

Neo 成功地顯示 Preview。

從模擬器執行 App 也不是問題。

測完了簡單的 Hello World App，接下來我們試試各種不同類型的 App 專案，看看 Neo 是否招架得住。

Apple 的 SwiftUI 範例專案

Apple 的 SwiftUI 範例專案包含常用的 App 功能，如果 Neo 可以應付，表示預算有限的同學可以使用 Neo 學習程式和開發 App。

Wishlist: Planning travel in a SwiftUI app | Apple Developer Documentation
Build a travel planning app that organizes trips into collections and tracks activity completion.developer.apple.com

Neo 的 build 時間為 16 秒。

M3 Max 是 7.4 秒。

App 成功地在 preview 和模擬器執行。

加入 Firebase iOS SDK 的專案

Firebase iOS SDK 包含大量的程式，而且也是同學常使用的套件，因此滿適合用來驗證 Neo 的能力。

GitHub - firebase/firebase-ios-sdk: Firebase SDK for Apple App Development
Firebase SDK for Apple App Development. Contribute to firebase/firebase-ios-sdk development by creating an account on…github.com

Neo 成功 build 加入 Firebase iOS SDK 的 App，時間為 44.3 秒。

M3 Max 是 14.7 秒。

複雜的 App 專案

IceCubesApp 是上架的 iOS App，而且包含大量的程式，很適合驗證 Neo 是否能應付大型複雜的 App 專案。

GitHub - Dimillian/IceCubesApp: A SwiftUI Mastodon client
A SwiftUI Mastodon client. Contribute to Dimillian/IceCubesApp development by creating an account on GitHub.github.com

Neo 再次通過了考驗，build 時間為 123.8 秒。

M1 8G 是 112.9 秒。(ps: 彼得潘另一台螢幕壞掉的 Mac)

M3 Max 是 45.6 秒。

App 成功地在模擬器執行。

顯示包含多個畫面的 storyboard

WordPress iOS App 使用大量的 storyboard，很適合驗證 Neo 是否能顯示複雜的 storyboard。

GitHub — wordpress-mobile/WordPress-iOS: WordPress for iOS — Official repository
WordPress for iOS — Official repository. Contribute to wordpress-mobile/WordPress-iOS development by creating an…github.com

Neo 成功顯示 storyboard。

Flutter App

Neo 開發 Flutter App 也沒問題，VS Code 成功執行預設專案的計數器 App。

結論

經過以上實驗，看來使用 MacBook Neo 學習程式和搭配 Xcode 開發 App 應該是 OK 的。

當然 Neo 的效能比不上彼得潘的 M3 Max，甚至可能連 M1 也比不上，不過這在大專案才會有明顯差異，學習程式的小專案差別不大。

如果預算有限，或是還沒有賺錢的能力，只能跟父母要錢，那麼使用 Neo 當第一台學程式的電腦也是可以接受的。就像彼得潘大學時也很想買 MacBook，但是不好意思跟父母要太多錢，所以只能購買 Mac Mini。

另外由於 Neo 的記憶體只有 8 GB，建議平時保持良好的使用習慣，比方不要同時開太多 App 跟網頁、每天重開機、定期刪除用不到的檔案等，如此我們才能跟 Neo 一起順暢地開發各式各樣有趣的 App。
