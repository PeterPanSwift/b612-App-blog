從 Mac 遠端連線操控 Windows — 使用 Windows App

最近彼得潘因為工作的關係，常需要一下子操作 Mac，一下子操作另一台 Windows 電腦。為了提升工作效率，彼得潘決定採用另一個做法，直接從 Mac 遠端連線操控 Windows，它將帶來以下優點。

  • 統一從 Mac 操作，切換 App 即可切換 Mac & Windows。
  • Mac & Windows 共用剪貼簿，方便複製貼上彼此的檔案。

以下我們一步步介紹 Mac 遠端連線操控 Windows 的步驟。

Windows 的設定

打開設定，點選系統 > 遠端桌面。

打開遠端桌面的開關。

之後 Mac 連到 Windows 電腦有兩種方式，一種是輸入電腦名稱， 一種是輸入電腦的 IP 位址。

Mac 有時會找不到電腦名稱對應的電腦，所以 IP 位址是比較保險的方法。打開命令提示字元，輸入 ipconfig，找到 IPv4 位址 192.168.68.64。

Mac 的設定

從 App Store 下載安裝 Windows App。

《Windows App》App - App Store
在 App Store 下載Microsoft Corporation的《Windows App》。查看截圖、評分與評論、使用者提示以及更多與《Windows App》類似的遊戲。apps.apple.com

啟動 Windows App，點選允許尋找區域網路上的裝置。

從 Mac 遠端連線操控 Windows

切換到 Devices 頁面，點選右上方的 +。

點選 Add PC。

輸入剛剛取得的 Windows 電腦 IPv4 位址 192.168.68.64，點選 Add。

雙擊 192.168.68.64 的圖片連線。

輸入 Windows 電腦的帳號密碼。

點選 Continue。

成功了 ! Windows App 視窗出現 Windows 電腦的畫面，現在我們可以從 Mac 遠端操作 Windows。

除了遠端操控，Mac 和 Windows 還可共用剪貼簿，在 Windows / Mac 按 cmd + c 複製文字、圖片、檔案後，在 Mac / Windows 可按 cmd + v 一鍵貼上。
