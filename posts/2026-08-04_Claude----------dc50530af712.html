Claude 換帳號的資料轉移

最近彼得潘有朋友辦新的 Claude 帳號，想將舊帳號的重要資料轉移。不過目前 Claude 並未提供方便的資料轉移功能，因此以下彼得潘簡單介紹如何在 Claude 的新帳號加入這六種重要資料。

  • Instruction for Claude
  • Memory
  • Project
  • Skill
  • Artifacts
  • Schedule

Instruction for Claude

從舊帳號的 Settings 的 General > Instruction for Claude 複製，然後再貼到新帳號的 Instruction for Claude。

Memory

  • 輸出記憶。

點選 Settings 的 Capabilities > View and manage memory。

選取複製記憶。

  • 匯入記憶。

點選 Settings 的 Capabilities > Import memory from other AI providers > Start import。

貼上之前複製的記憶，然後點選 Add to memory。

Project

從舊帳號複製 project 的 instructions 和檔案。

在新帳號點擊 New project 重新建立 project，輸入 instructions，加入相關的檔案。如果 Project 原本有搭配本機資料夾 ，建立 project 時請再點選 Use a folder 加入資料夾。

Skill

  • 下載 Skill。

從 Customize > Skills 點選 skill。

點選 Download 下載。

  • 上傳 skill。

點選 Customize > Skills > Add > Upload a skill。

Artifacts

  • 下載 Artifacts。

點選 Download 下載相關檔案。

  • 建立 Artifacts。

附上檔案，請 Claude 重新建立 Artifacts。

Schedule

進入舊帳號的 schedule task 頁面，點選長得像筆的編輯按鈕。

複製 Instruction 和 Frequency。

從新帳號的 Scheduled 頁面點選 New task > Set up manually。

輸入複製的 Instruction 和 Frequency。
