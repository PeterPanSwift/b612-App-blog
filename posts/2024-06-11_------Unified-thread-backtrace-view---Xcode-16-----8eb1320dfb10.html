一頁瀏覽的 Unified thread backtrace view — Xcode 16 新功能

從 Xcode 16 開始，我們可以從 Unified thread backtrace view 一頁瀏覽程式在中斷點或 exception 發生時呼叫的相關程式。

以下我們寫個簡單的範例，分別見證中斷點和 exception 的 backtrace。

  • Pet.swift。
import Foundation

struct Pet {
    func play() {
        print("play 🎾")
    }
    
    func eat() {
        print("eat 🍽️")
    }
}
  • Baby.swift。
import Foundation

struct Baby {
    var pet = Pet()
    
    func randomAction() {
        let action = ["play", "eat"].randomElement()!
        if action == "play" {
            pet.play()
        } else {
            pet.eat()
        }
    }
}
  • ContentView.swift。
import SwiftUI

struct ContentView: View {
    var body: some View {
        Button("Button") {
            let baby = Baby()
            baby.randomAction()
        }
    }
}

實驗中斷點的 backtrace

在下圖的 print("play 🎾") 設定中斷點。

執行 App，點擊 button 觸發中斷點。

從前為了追蹤呼叫 play 前執行了哪些程式，我們必須從側邊欄一個個點選呼叫的 function。

在 Xcode 16 debug bar 多了 Enable backtrace in Editor 按鈕，現在我們可以點選它顯示更方便的 Backtrace View。

點選後右邊出現了一頁顯示的 backtrace view，我們可一目瞭然看到程式呼叫的相關段落。

滑鼠移到相關的程式段落還可看到變數的內容。

實驗 exception 的 backtrace

為了產生 exception，以下程式故意用 balls[2] 存取只有兩個成員的 array。

import Foundation

struct Pet {
    func play() {
        let balls = ["🎾", "⚾️"]
        let ball = balls[2]
        print("play \(ball)")
    }
    
    func eat() {
        print("eat 🍽️")
    }
}

當程式閃退時，右邊一樣貼心地一頁顯示程式呼叫的相關段落。
