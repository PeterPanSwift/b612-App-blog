這個問題通常是因為 MainActivity 繼承了 FlutterActivity，而 Health Connect 的權限請求機制（基於 AndroidX Activity Result API）在某些情況下需要 FlutterFragmentActivity 才能正常運作。

我已經為您修改了 MainActivity.kt，將其改為繼承 FlutterFragmentActivity。

修改內容：

  1. MainActivity.kt
  • 將 import io.flutter.embedding.android.FlutterActivity 改為 import io.flutter.embedding.android.FlutterFragmentActivity
  • 將 class MainActivity : FlutterActivity() 改為 class MainActivity : FlutterFragmentActivity()
