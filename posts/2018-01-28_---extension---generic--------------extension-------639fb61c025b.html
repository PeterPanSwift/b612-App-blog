幫 generic 型別代號加上限制條件
generic 擁有設定型別條件的特殊能力，比方以下例子 ，由於型別代號 T 可置換成任何型別，因此如果小王子不小心養了殭屍 Zombie 當寵物，很可能在睡夢中被殭屍咬一口，再也見不到明天的太陽。medium.com

然而 generic 的威力不僅於此， 結合 extension 和 generic，我們還能實現只有當型別代號符合條件時，extension 才發揮作用。

當型別代號繼承某型別或遵從 protocol

小王子只有在可愛寵物陪伴時，才能安心睡覺。

class Animal {
   func eat() {
      print("🍔🍱")
   }
}

protocol Cute {
   func smile()
}

class Fox: Animal, Cute {
   func smile() {
      print("😊😘")
   }
}

class LittlePrince<T: Animal> {
   var pet: T?
}

extension LittlePrince where T: Cute {
   func sleep() {
      print("和可愛寵物一起睡覺 😴😴")
   }
}

利用 extension LittlePrince where T: Cute，限制只有當 T 遵從 protocol Cute 時，小王子才能安心 sleep。

var prince = LittlePrince<Fox>()
prince.pet = Fox()
prince.sleep()
