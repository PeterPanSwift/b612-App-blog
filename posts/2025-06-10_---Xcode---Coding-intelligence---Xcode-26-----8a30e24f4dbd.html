打開 Xcode 的 Coding intelligence — Xcode 26 新功能

從 Xcode 26 開始，我們終於可以出一張嘴下 prompt 請 AI 幫忙開發 App 了。

為了啟用 Xcode 的 AI 功能，我們必須先將 macOS 升級到 26 以上。

接著打開 Xcode 的 Coding intelligence，設定幫忙的 AI model。

打開 Xcode intelligence 設定頁面有兩個方法。

  • 方法 1: 從 Quick Action(cmd +shift + a)打開 Xcode 的 Settings。

切換到 Intelligence 頁面。

  • 方法 2: 點選左上的星星按鈕，然後點選 Set Up。

Xcode 內建免費的 AI Model，來自 OpenAI 的 ChatGPT。請先點選 OpenAI。

點選 ChatGPT in Xcode。

打開 ChatGPT in Xcode 的開關。

ChatGPT in Xcode 可免費使用，然而它有額度的限制，不能問太多問題。若有訂閱 ChatGPT 帳號，點擊 ChatGPT 的 Sign In 登入帳號可享有更高的額度問更多問題。

點選 Sign In。

登入訂閱的 ChatGPT 帳號。

登入成功後，ChatGPT Plus 下方將顯示登入的帳號。

若想使用更強大的 agentic coding 功能，建議點擊 Codex 右邊的 Get。 agentic coding 除了寫程式，還可以執行許多任務，比方上網查資料，執行指令等。

點選 install。

安裝好 Codex 後，點選三個點，然後點選 Sign In with a ChatGPT Account。

點選 Continue。

從 Model 欄位可選擇 model 的版本。

訂閱 ChatGPT 的帳號則可使用更厲害的 AI model 和享有更多的訊息額度。如下圖所示，訂閱帳號才有 5.4，免費帳號只能用 5.2。

當 agentic coding 功能啟用時，Intelligence 頁面將多出 Agents in Xcode 區塊，可設定 agent 的權限和功能。

相較於免費即可使用的 ChatGPT，Anthropic 的 Claude 則須訂閱才能使用。

若有訂閱可點選 Anthropic，然後點選 Claude 登入帳號和 Claude Agent 的 Get 打開 agent 功能。

從 Claude Agent 的 Model 欄位可選擇使用的 model。

綜合以上討論，我們不用花錢就可在 Xcode 使用 AI 開發 App，不過若想搭配更聰明的 AI 和更多的訊息額度，則須另外訂閱 ChatGPT 或 Claude。

除了 ChatGPT & Claude，我們也可以添加自己喜歡的 AI model。點選 Add a Provider 將可設定網路或本機的 AI model。

以下我們加入 OpenAI 的 API key，URL 輸入 https://api.openai.com/v1/responses。

ps: OpenAI API Key 的取得方法可參考以下連結。

用一餐麥當勞的錢玩玩 OpenAI API
OpenAI 提供豐富的 API 讓我們開發各種結合 AI 的有趣應用，比方聊天機器人、生成圖片，寫程式等。然而天下沒有白吃的午餐，串接 OpenAI API 會消耗 token，而 token 必須花錢購買，因此要先儲值才能使用…medium.com

加入 OpenAI 後，點選網路圖示的 OpenAI 可看到它琳琅滿目的 AI model。

若是選擇 Locally Hosted，則可設定本機的 AI。

成功設定 AI model 後，我們將可點選下圖的星星打開 Coding Assistant，請 AI 一起寫程式開發 App。

點選左上的向下箭頭可選擇 AI model 和 agent。

若選擇內建 OpenAI 下的 GPT-5，還可從下方的 Reasoning 選擇 AI 的思考程度，High 是最聰明的 AI，不過也會花更多的時間思考。

以下我們在 prompt 輸入加上漂亮的漸層背景，AI 直接修改專案的程式，幫我們加上漂亮的漸層背景。
