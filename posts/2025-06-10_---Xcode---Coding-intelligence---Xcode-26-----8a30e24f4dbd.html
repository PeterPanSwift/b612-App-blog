使用 Xcode 的 Coding intelligence 開發 App — Xcode 26 新功能

從 Xcode 26 開始，我們終於可以出一張嘴下 prompt 請 AI 幫忙開發 App 了。

啟用 Xcode 的 Coding intelligence

為了啟用 Xcode 的 AI 功能，我們必須先完成以下準備事項。

使用 Xcode AI 開發 iOS App 的準備事項
Xcode 從 26 開始提供強大的 AI 功能，現在開發 iOS App 可以說進入了新的時代，我們想要的精美 App 畫面和酷炫功能都可以請 AI 實現。medium.com

接著打開 Xcode intelligence 的設定頁面，從 Quick Action 打開 Xcode 的 Settings。

切換到 Intelligence 頁面。

Xcode 提供 Agents & Chat 兩種 AI 開發模式，Agents 的能力更強大，它除了寫程式，還可以執行許多任務，比方測試 App、上網查資料、執行指令等。

Agents 預設有 Claude Agent、Codex、Gemini 三種，使用前請先點選 Get，然後再點選 Install 安裝。

想使用 Claude Agent、Codex、Gemini 有以下方法。

  • 使用 Claude Agent 必須登入訂閱的 Claude 帳號。
  • 使用 Codex 必須登入 ChatGPT 帳號。免費的 ChatGPT 帳號也可使用，但訂閱的帳號可享有更高的訊息額度。
  • 申請付費的 Claude、OpenAI、Gemini API key。

以下我們以免費即可使用的 Codex 示範。點選 Codex 進入設定頁後，點選 Account 右側的三個點，然後點選 Sign In with a ChatGPT Account。

此時將開啟網頁，請從網頁完成 ChatGPT 的登入流程，登入成功後 Xcode 的 Codex 頁面將顯示登入的帳號。

若想使用最厲害的 model，可選擇最新版的 GPT-5.5。

除了剛剛介紹的 Agent，我們也可從 Chat 區塊設定 ChatGPT in Xcode & Claude。

同樣的，Claude 必須登入訂閱帳號才能使用，不過 ChatGPT 倒是十分佛心，只要打開開關，就算沒登入還是可以使用。

若想詢問更多問題跟使用更聰明的 ChatGPT model，則可點選 Sign In 登入訂閱的 ChatGPT 帳號。

綜合以上討論，我們不用花錢就可在 Xcode 使用 AI 開發 App，不過若想搭配更聰明的 AI 和更多的訊息額度，則須另外訂閱 ChatGPT、Claude 或申請付費的 API key。

使用 AI 開發 App

完成以上設定後，我們將可點選星星打開 Coding Assistant，請 AI 一起寫程式開發 App。

點選左上的鉛筆按鈕可選擇 Agent 或 chat 的 AI model。
