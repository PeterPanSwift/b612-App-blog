從程式輸入 asset 自訂的 Color

生成 Color 時傳入 . 加 asset 自訂的顏色名字。

struct ContentView: View {
    var body: some View {
        Text("Hello, world!")
            .foregroundStyle(.cute)
    }
}
自動將 asset 的圖片和顏色變成 ImageResource 和 ColorResource 的型別屬性 — Xcode 15 新功能
從 Xcode 15 開始，我們可以更方便地從程式生成圖片和顏色了。Xcode 會自動將 asset 的圖片和顏色變成 ImageResource 和 ColorResource 的型別屬性，我們不用再擔心打錯圖片和顏色的名字。medium.com

從程式輸入顏色的 RGB

搭配 Color 接收 RGB 參數的 init。( opacity 預設為 1，因此可省略)

init(_ colorSpace: Color.RGBColorSpace = .sRGB, red: Double, green: Double, blue: Double, opacity: Double = 1)

範例。

Text("Hello World")
   .foregroundStyle(Color(red: 100/255, green: 209/255, blue: 204/255))

參數 red，green & blue 的型別是 Double ，所以 100 / 255 會變成 100.0 / 255.0，不然的話，100 / 255 的結果應該會是 0。

從程式設定透明顏色

我們可利用 opacity 設定顏色的透明度，opacity 的範圍是 0 ~ 1，0 表示完全透明，1 表示完全不透明。

比方想讓 Text 變半透明有以下兩種做法:

  • 做法一

生成 Color 時搭配參數 opacity。

Text("Hello World")
    .foregroundStyle(Color(red: 1, green: 0, blue: 0, opacity: 0.5))
  • 做法二

生成 Color 後再呼叫 modifier opacity。

Text("Hello World")
    .foregroundStyle(Color(red: 1, green: 0, blue: 0).opacity(0.5))

若想設定完全透明的顏色，還有更簡單的方法，直接使用 Color 的型別屬性 clear。

Text("Hello World")
    .foregroundStyle(.clear)

產生顏色的漸層色 — iOS 16 新功能

從顏色讀取 gradient 可以產生它的漸層色。

var body: some View {
    Text("Hello World")
        .font(.largeTitle)
        .foregroundStyle(.red.gradient)
}
