使用 Xcode 的 coding agent 將 iOS 專案上傳到 GitHub

Xcode 的 coding agent 可以幫我們實現 App 開發的相關工作，以下彼得潘示範如何透過 coding agent 將專案上傳到 GitHub。

  • 啟用 Xcode 的 coding agent。

訂閱 ChatGPT 可啟用 Codex，訂閱 Claude 可啟用 Claude agent。

打開 Xcode 的 Coding intelligence — Xcode 26 新功能
從 Xcode 26 開始，我們終於可以出一張嘴下 prompt 請 AI 幫忙開發 App 了。medium.com
  • 安裝 GitHub CLI 和登入 GitHub 帳號。

agent 必須透過 GitHub CLI 上傳專案到 GitHub，因此請先安裝 GitHub CLI 和登入 GitHub 帳號。

安裝 GitHub CLI 和登入 GitHub 帳號
參考 GitHub CLI 網頁的教學安裝 GitHub CLI。medium.com
  • 請 coding agent 將專案上傳到 GitHub。

從 Xcode 打開 Coding Assistant，選擇 Codex 或 Claude Agent。

輸入以下 prompt。

將 App 上傳到 GitHub，建立 public repository

agent 成功將專案上傳到 GitHub。

從上圖可看到專案的 GitHub repository 網址，不過若是直接複製網址貼到瀏覽器將看到可怕的 404 !

問題出在複製的網址會包含一些看不到的字元，造成它不是正確的網址。有興趣的朋友可參考以下連結的說明。

使用 AI 搭配 GitHub CLI 將程式存成雲端 gist
