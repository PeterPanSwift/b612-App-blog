Xcode 的 Claude agent 不認得 Homebrew 安裝的指令

Xcode 預設可搭配 Codex & Claude agent，不過最近彼得潘測試後，發現同樣的指令，Codex 認得，Claude agent 卻不認得。

比方我們請 AI 使用 GitHub CLI 將專案傳到 GitHub，Codex 成功完成了任務，Claude agent 卻回答電腦尚未安裝 GitHub CLI。

彼得潘研究後，發現問題出在 Xcode 的 Codex 和 Claude agent 有著自己的 PATH，跟 Terminal 的 PATH 不一樣，因此它們有時會不認得 Terminal 可執行的指令。

從 Xcode 分別詢問 Codex 和 Claude agent 後，它們的 PATH 如下。
