Font 縮放字體的 scaled(by:) — iOS 26 新功能

開發 SwiftUI App，我們常常會使用 Dynamic Type 內建的 style 設定字體大小，比方 title、largeTitle、caption 等，讓 App 顯示的文字大小自動依據使用者在設定 App 設定的字體大小調整。

不過 Dynamic Type 內建的 style 就那幾個，有沒有方法有更多選擇，比方 largeTitle 的 1.5 倍，caption 的 0.5 倍呢 ?

從 iOS 26 開始，透過 Font 的 scaled(by:) 可以輕鬆縮放字體。

scaled(by:) | Apple Developer Documentation
Scales the point size of the font.developer.apple.com

以下例子分別展示 0.5 倍、正常、1.5 倍和 1.5 倍並加粗的效果。

struct ContentView: View {
    var body: some View {
        VStack {
            Text("Guide to Iceland")
                .font(.largeTitle.scaled(by: 0.5))
            Text("Guide to Iceland")
                .font(.largeTitle)
            Text("Guide to Iceland")
                .font(.largeTitle.scaled(by: 1.5))
            Text("Guide to Iceland")
                .font(.largeTitle.scaled(by: 1.5).bold())
        }
    }
}
