利用指令啟動 IDE 開啟專案 — Xcode、VS Code、Antigravity IDE、Android Studio

在 Mac 下指令啟動 IDE 開啟專案十分簡單，只要輸入以下格式。

open -a App名稱 資料夾名字

因此以下寫法將可啟動 Xcode、VS Code、Antigravity IDE、Android Studio 開啟專案 Demo。

open -a Xcode Demo
open -a "Visual Studio Code" Demo
open -a "Antigravity IDE" Demo    
open -a "Android Studio" Demo
