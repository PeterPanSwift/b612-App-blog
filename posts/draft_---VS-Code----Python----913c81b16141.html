使用 VS Code 開發 Python 程式

從 Microsoft Store 安裝 VS Code。

使用 VS Code 開發 Python 程式


從 Microsoft Store 安裝 VS Code。

安裝 Python Extension。


安裝 Jupyter Extension。


新增 notebook 開發 Python

用 VS Code 開啟專案資料夾，新增 ipynb 檔。

點選右上方的 Select Kernel。

點選 Python Environments。

選擇某個 Python 版本。

點選 + Code 新增 cell，在 cell 裡輸入 python 程式，按 shift + return 或 cell 左側的三角形執行程式。

新增 py 檔開發 Python

用 VS Code 開啟專案資料夾，新增 py 檔。

點選下方的版本數字可選擇 Python Interpreter。

點選右上方的三角形執行程式。

程式印列的結果將顯示在下方的 TERMINAL 視窗。
