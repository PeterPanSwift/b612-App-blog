請 AI 將 App 畫面顯示的資料包裝成物件(model)

為了快速打造 App 畫面，有時我們會在畫面的程式先填寫固定的資料，之後再將資料包裝成獨立的物件。現在有了聰明的 AI ，將資料包裝成物件的任務也可以請它幫忙。

以下我們以呈現書籍資料的 BookDetail 畫面說明。設計畫面時我們先填入小王子的資料。

struct BookDetail: View {
    var body: some View {
        ScrollView {
            VStack(spacing: 24) {
                ZStack(alignment: .bottomLeading) {
                    Image(.bookCover)
                        .resizable()
                        .scaledToFill()
                        .frame(height: 260)
                        .frame(maxWidth: .infinity)
                    VStack(alignment: .leading, spacing: 8) {
                        Text("小王子")
                            .font(.title.bold())
                            .foregroundStyle(.white)
                            .shadow(radius: 8)
                        Text("作者：聖修伯里")
                            .font(.headline)
                            .foregroundStyle(.white.opacity(0.9))
                    }
                    .padding(16)
                }
                .clipShape(.rect(cornerRadius: 20))
                .shadow(color: .black.opacity(0.15), radius: 12, x: 0, y: 8)

                VStack(alignment: .leading, spacing: 16) {
                    Label("頁數：128", systemImage: "book")
                    Label("價錢：$200", systemImage: "dollarsign.circle")
                    Label("出版日期：2025/12/17", systemImage: "calendar")
                }
                .font(.body)
                .foregroundStyle(.primary)
                .padding(16)
                .frame(maxWidth: .infinity, alignment: .leading)
                .background(.ultraThinMaterial, in: .rect(cornerRadius: 16))

                VStack(alignment: .leading, spacing: 8) {
                    Text("內容簡介")
                        .font(.headline)
                    Text("獻給每一個曾是孩子的大人…… 小王子來自一個很小很小的小行星，在那裡，什麼都好小好小，一天可以看四十三次夕陽。 星球上有三座只到膝蓋高的火山、幾棵猴麵包樹，還有一朵驕傲的玫瑰。 小王子很容易憂傷，他小小的生命溫柔善感。有一天，他和心愛的玫瑰鬧了彆扭，趁著野鳥群遷之際出走，在各星球間遊歷，遇見了國王、愛虛榮的人、酒鬼、商人、點燈人、地理學家，還有狐狸。 最後，他在地球降落，來到了撒哈拉沙漠，和飛行途中迫降在沙漠上的「我」相遇了。")
                        .foregroundStyle(.secondary)
                        .lineSpacing(6)
                }
                .frame(maxWidth: .infinity)
            }
            .padding()
        }
    }
}

做好畫面後，請 AI 將畫面顯示的資料包裝成物件。

AI 成功地完成任務。

AI 新增了定義書籍資料的 Book.swift，而且還宣告儲存小王子資料的 sample。

import SwiftUI

struct Book: Identifiable {
    let id = UUID()
    let title: String
    let author: String
    let pages: Int
    let price: Int
    let publishDate: String
    let description: String
    let cover: ImageResource
}

extension Book {
    static let sample = Book(
        title: "小王子",
        author: "聖修伯里",
        pages: 128,
        price: 200,
        publishDate: "2025/12/17",
        description: "獻給每一個曾是孩子的大人…… 小王子來自一個很小很小的小行星，在那裡，什麼都好小好小，一天可以看四十三次夕陽。 星球上有三座只到膝蓋高的火山、幾棵猴麵包樹，還有一朵驕傲的玫瑰。 小王子很容易憂傷，他小小的生命溫柔善感。有一天，他和心愛的玫瑰鬧了彆扭，趁著野鳥群遷之際出走，在各星球間遊歷，遇見了國王、愛虛榮的人、酒鬼、商人、點燈人、地理學家，還有狐狸。 最後，他在地球降落，來到了撒哈拉沙漠，和飛行途中迫降在沙漠上的「我」相遇了。",
        cover: .bookCover

}

畫面 BookDetail 更新成顯示 Book 的內容。

import SwiftUI

struct BookDetail: View {
    let book: Book

    var body: some View {
        ScrollView {
            VStack(spacing: 24) {
                ZStack(alignment: .bottomLeading) {
                    Image(book.cover)
                        .resizable()
                        .scaledToFill()
                        .frame(height: 260)
                        .frame(maxWidth: .infinity)
                    VStack(alignment: .leading, spacing: 8) {
                        Text(book.title)
                            .font(.title.bold())
                            .foregroundStyle(.white)
                            .shadow(radius: 8)
                        Text("作者：\(book.author)")
                            .font(.headline)
                            .foregroundStyle(.white.opacity(0.9))
                    }
                    .padding(16)
                }
                .clipShape(.rect(cornerRadius: 20))
                .shadow(color: .black.opacity(0.15), radius: 12, x: 0, y: 8)

                VStack(alignment: .leading, spacing: 16) {
                    Label("頁數：\(book.pages)", systemImage: "book")
                    Label("價錢：$\(book.price)", systemImage: "dollarsign.circle")
                    Label("出版日期：\(book.publishDate)", systemImage: "calendar")
                }
                .font(.body)
                .foregroundStyle(.primary)
                .padding(16)
                .frame(maxWidth: .infinity, alignment: .leading)
                .background(.ultraThinMaterial, in: .rect(cornerRadius: 16))

                VStack(alignment: .leading, spacing: 8) {
                    Text("內容簡介")
                        .font(.headline)
                    Text(book.description)
                        .foregroundStyle(.secondary)
                        .lineSpacing(6)
                }
                .frame(maxWidth: .infinity)
            }
            .padding()
        }
    }
}
