利用 ignoresSafeArea 讓圖片延伸到 iPhone 的瀏海

在 iOS App 上我們常看到漂亮的照片延伸到 iPhone 的瀏海，就像以下音樂 App 裡漂亮的 Penny 照片。

這樣的效果其實是透過神奇的一行程式實現的。以下彼得潘以最近剛買的小狐狸筆電包說明。

struct ContentView: View {
    var body: some View {
        ScrollView {
            VStack {
                Image(.laptopBag)
                    .resizable()
                    .scaledToFit()
                Text(
                    """
                    Made from hardwearing G-1000 fabric, the 1960s Laptop Bag provides padded protection for your device, with a buttoned front sleeve to keep papers organised. Carry it by the sturdy handles for a smart, professional look, or use the detachable shoulder strap for a more relaxed, everyday style. Finished with a classic Fjällräven 1960 emblem.
                    """
                )
                .font(.title)
                .padding()
            }
        }
    }
}

iOS App 預設會讓內容顯示在 safe area 內，避免內容被上方的瀏海切到，因此圖片的上方將多出一塊空白。

解決的方法很簡單，只要加上 ignoresSafeArea(edges: .top) 或 ignoresSafeArea()，即可讓畫面延伸到 safe area 外的瀏海。

struct ContentView: View {
    var body: some View {
        ScrollView {
            VStack {
                Image(.laptopBag)
                    .resizable()
                    .scaledToFit()
                Text(
                    """
                    Made from hardwearing G-1000 fabric, the 1960s Laptop Bag provides padded protection for your device, with a buttoned front sleeve to keep papers organised. Carry it by the sturdy handles for a smart, professional look, or use the detachable shoulder strap for a more relaxed, everyday style. Finished with a classic Fjällräven 1960 emblem.
                    """
                )
                .font(.title)
                .padding()
            }
        }
        .ignoresSafeArea(edges: .top)
    }
}

圖片完美地填滿 iPhone 的上半部區塊。
