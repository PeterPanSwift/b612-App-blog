使用線上 IDE GitHub Codespaces 開發 Python 程式

GitHub Codespaces 是跑在雲端的 VS Code，我們只要從瀏覽器連到 Codespaces 即可開發各種程式，省下在自己電腦設定開發環境的時間。

以下我們示範利用 GitHub Codespaces 開發 Python 程式的兩種方法。

  • 開發執行 py 檔。
  • 開發 Jupyter Notebook 程式。

開發執行 py 檔

從瀏覽器連到 Codespaces，點選 Get started for free。

GitHub Codespaces
GitHub is where people build software. More than 150 million people use GitHub to discover, fork, and contribute to…github.com

從樣版(template) 頁面選擇樣版。

點選 Blank 的 Use this template。

生成空白專案。

點選 New File 新增 python 檔。

專案初次加入 python 檔時會跳出通知，點選 Install 安裝 Python extension。

Python extension 裝好後，回到剛剛新增的 python 檔，右下方將顯示 Python 的版本。

輸入 python 程式，點選三角形執行。

下方的 TERMINAL 顯示程式列印的內容。

若想加入套件，可從 terminal 用 pip 安裝。以下示範安裝 Pandas 的例子。

pip install pandas

安裝套件時會出現以下通知，提醒我們最好建立虛擬環境，避免不同專案因安裝的套件版本不同造成衝突。請點選 Create 建立虛擬環境。

選擇虛擬環境的 Python 版本。

虛擬環境建好後專案將多出 .venv。

輸入使用 pandas 的骰子範例。

import pandas as pd
import random

# 1️⃣ 模擬擲骰子 100 次
dice_results = [random.randint(1, 6) for _ in range(100)]

# 2️⃣ 用 Pandas 建立 DataFrame
df = pd.DataFrame({
    "Dice": dice_results
})

print("🎲 擲骰子結果（前 10 筆）")
print(df.head(10))

# 3️⃣ 統計每個點數出現次數
count = df["Dice"].value_counts().sort_index()

print("\n📊 每個點數出現次數")
print(count)

# 4️⃣ 算平均值
average = df["Dice"].mean()
print(f"\n✨ 平均點數是：{average:.2f}")

結果。

開發 Jupyter Notebook 程式

點選 Jupyter Notebook 的 Use this template。

生成 Jupyter Notebook 專案。

notebooks 資料夾下有一些預設的 notebook，我們可在底下點選 New File 另外新增 notebook。

點選 Select Kernel，選擇 Python Environments。

選擇 python 版本。

新增 Code cell 輸入程式並執行。

若需要裝套件，可在 cell 裡輸入 %pip install 指令，比方 %pip install gazpacho 安裝爬蟲套件。
