List & ForEach 搭配 array 的自動完成 — Xcode 14 新功能

產生 List & ForEach 時，我們時常會傳入 array，因此輸入 List & ForEach 時，自動完成會自動尋找它的好朋友 array & 輸入相關程式。

比方以下的 ContentView 有個 array singers。

struct Singer: Identifiable {
    let id = UUID()
    let name: String
    let instrument: String
    let lyrics: String
}
struct ContentView: View {
    let singers = [
        Singer(name: "戴佩妮", instrument: "🎸", lyrics: "有一首唱過的歌叫做願望，有一個追逐的夢叫做理想"),
        Singer(name: "林隆璇", instrument: "🎹", lyrics: "我愛妳這樣深，那怕夏雨冬雷震"),
        Singer(name: "蘇打綠", instrument: "🎹", lyrics: "彷彿還看見昨日那張悲傷的臉龐，快樂有時候竟然辣得像一記耳光")
    ]
    
    var body: some View {
        
    }
}

List 搭配 array

當我們在 body 裡輸入 list 時，自動完成將出現搭配 singers 的 List。

按下 enter 後自動輸入 List 搭配 singers 的完整程式。

此時我們可再客製 List { } 的內容，

var body: some View {
    List(singers) { singer in
        VStack(alignment: .leading) {
            Text(singer.lyrics)
                .bold()
            HStack {
                Spacer()
                Text(singer.name)
                Text(singer.instrument)
            }
        }
    }
}

ForEach 搭配 array

ForEach 的自動完成也跟 List 一樣聰明，例如以下例子:

var body: some View {
    ScrollView(.horizontal) {
        HStack {
            ForEach(singers) { singer in
                VStack(spacing: 10) {
                    Text(singer.lyrics)
                        .bold()
                        .frame(width: 150)
                    HStack {
                        Text(singer.name)
                        Text(singer.instrument)
                    }
                }
                .padding()
                .background(.orange.gradient)
            }
            
        }
    }
    
}

搭配 ObservableObject 裡的 array

開發 SwiftUI App 時，我們時常會將資料存在 ObservableObject 的 property，比方以下例子在 SingerBox 宣告 property singers。

struct Singer: Identifiable {
    let id = UUID()
    let name: String
    let instrument: String
    let lyrics: String
}
class SingerBox: ObservableObject {
    @Published var singers = [
        Singer(name: "戴佩妮", instrument: "🎸", lyrics: "有一首唱過的歌叫做願望，有一個追逐的夢叫做理想"),
        Singer(name: "林隆璇", instrument: "🎹", lyrics: "我愛妳這樣深，那怕夏雨冬雷震"),
        Singer(name: "蘇打綠", instrument: "🎹", lyrics: "彷彿還看見昨日那張悲傷的臉龐，快樂有時候竟然辣得像一記耳光")
    ]
}

List 或 ForEach 的自動完成還不夠聰明，它無法知道 SingerBox 裡有 array。不過沒關係，我們可以在 view 裡另外宣告回傳 array 的 property，比方以下例子的 singers。

struct ContentView: View {
    
    @StateObject private var singerBox = SingerBox()
    private var singers: [Singer] {
        singerBox.singers
    }

如此 List 的自動完成就能找到 singers 了。
