使用 Codex & Claude 的 Computer use 操控 Xcode 透過 SPM 安裝套件

目前在 Xcode 專案透過 SPM 安裝套件並沒有方便的指令，因此請 AI 加套件時它必須修改 xcodeproj、Package.resolved 之類的檔案，不保證百分百成功。

若想請 AI 加套件而且保證成功，目前較可行的做法是透過 AI 軟體的 Computer use 功能，它能操控 Xcode 的 UI 介面，因此可以實現我們平常操作 Xcode 做的各種工作。

之前彼得潘介紹過使用 Claude 的 Computer use 操控 Xcode 安裝套件，以下我們再示範使用 Codex 操作。

使用 Claude 的 Computer use 控制 Mac 開發 iOS App — 建立 Xcode 專案、寫程式、執行模擬器、螢幕錄影、上架 App
最近 Claude 推出強大的 Computer use 功能，我們平常在電腦的大部分操作它都能辦到。它就像真人一樣能看到螢幕畫面，然後進行點擊移動滑鼠和打字等操作。medium.com

ps: 記得先開啟 Codex 的 Computer use 功能。

打開 Codex，設定專案為 Xcode 的專案資料夾，輸入以下 prompt。

操作 Xcode 加入 Firebase iOS SDK，不要直接修改專案的相關檔案

當 Codex 操控 Xcode 加套件時，有些步驟需要較長的等待，此時 Codex 可能會放棄等待，改成修改專案的相關檔案，因此我們在 prompt 提醒它不要直接修改專案的相關檔案，確保它透過 Xcode 的 UI 介面加套件。

Codex 的 Computer use 工作時將在背景操作，我們還是可以繼續在電腦做其它工作。

Codex 成功加入套件，Library 加入 Firebase 最基本的 Library FirebaseCore。

已透過 Xcode 介面加入 Firebase iOS SDK，沒有直接手動修改專案檔。

結果：
- Package：`https://github.com/firebase/firebase-ios-sdk`
- Version rule：`Up to Next Major Version`
- 目前版本：`12.13.0 < 13.0.0`
- 加到 target 的產品：`FirebaseCore`
- Xcode 建置結果：`Build Succeeded`
