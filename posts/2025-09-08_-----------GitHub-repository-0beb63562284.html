邀請朋友一起存取修改 GitHub repository

比起單打獨鬥，我們更喜歡和朋友一起合作開發 App，一起有福同享有難同當。

為了方便團隊修改同一份程式，我們通常會在 GitHub 建立 App 專案的 repository，然後給予朋友存取修改的權限。

以下彼得潘以 PeterPanSwift 帳號示範邀請朋友 AppPeterPan 存取修改 GitHub repository。

ps: 因為沒有朋友，只能一人分飾兩角 😂。

連到 PeterPanSwift GitHub 的 Demo repository，點選右上的 Settings。

點選左側的 Collaborators。

點選 Add people。

輸入對方的名字或 email。

以下我們輸入 apppeterpan。

點選 Add AppPeterPan。

AppPeterPan 的狀態顯示 Pending invite，表示處於邀請狀態。

此時 AppPeterPan 將開心地收到 email 邀請，點選 View Invitation。

看來是個跟自己長得一模一樣的人邀請，想必是個好人，那一定要點選 Accept invitation 呀。

AppPeterPan 正式成為 collaborator，可以跟 PeterPanSwift 一起修改 Demo repository 了。
