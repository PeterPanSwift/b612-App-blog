Windows 安裝 Python 的最快方法

在 Windows 上安裝 Python 有許多方法，比方從 Python 官網下載安裝最新版的 Python。

Download Python
The official home of the Python Programming Languagewww.python.org

如果只想快速有個執行 Python 程式的開發環境，其實有個更快的方法。

安裝 Python

在 Windows Search 輸入 python，點選 python Run command。

此時將開啟 Microsoft Store 的 Python App 頁面，比方下圖的 Python 3.13。點擊 Get 下載安裝。

安裝成功，狀態變成 Installed。

執行 Python 程式

  • 方法 1: 在 Windows Search 輸入 python，點選 Python 3.13 App。

輸入 Python 程式，按下 enter 執行。

  • 方法 2: 從 Windows Search 打開 Windows PowerShell 或 Command Prompt。

輸入 python 進入 REPL 模式。

輸入 Python 程式，按下 enter 執行。
