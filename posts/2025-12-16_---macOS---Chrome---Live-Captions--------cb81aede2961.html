使用 macOS & Chrome 的 Live Captions 顯示影片字幕

網路上有許多好看的外國影片，可惜只有少部分有字幕。彼得潘研究了一下，發現有兩個不錯的方法可以辨識聲音顯示字幕。

  • 使用 macOS 的 Live Captions 顯示影片字幕。
  • 使用 Chrome 的 Live Captions 顯示影片字幕。

以下我們以 YouTube 上好笑的經典影片 Monty Python — The Black Knight 示範。

使用 macOS 的 Live Captions

macOS 的 Live Captions 可以辨識 Mac 發出的聲音跟麥克風收到的聲音。從 System Settings 打開 Live Captions 的開關即可啟動辨識聲音的功能。

從 Language 調整辨識的語言。

若想調整辨識的聲音來源，請從螢幕上方點選 Live Captions icon，然後選擇 Computer Audio 或 Microphone。

YouTube 影片播放時 Live Captions 成功地即時辨識顯示字幕。

使用 Chrome 的 Live Captions

打開 Chrome 的 Settings。

切換到 Accessibility 分頁，打開 Live Caption 的開關。

點選 Add language 可添加辨識的語言。

YouTube 影片播放時 Live Captions 成功地即時辨識顯示字幕。

除了 Live Caption，Chrome 還提供 Live Translate，以下我們設定翻譯成繁體中文。
