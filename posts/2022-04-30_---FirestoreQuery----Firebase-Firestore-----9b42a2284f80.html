利用 FirestoreQuery 讀取 Firebase Firestore 資料庫

Firebase 在新版推出了 property wrapper FirestoreQuery，利用它我們可以方便地讀取 Firebase Firestore 資料庫。

接下來讓我們以好聽的情歌資料庫為例說明吧。

Firestore 情歌資料庫

資料庫畫面如下，目前有三首好聽的歌。

定義歌曲對應的資料型別 Song

DocumentID 將讓 id 自動對應 Firestore 上 document 的 id。

import FirebaseFirestoreSwift

struct Song: Codable, Identifiable {
    @DocumentID var id: String?
    let name: String
    let singer: String
    let rate: Int
}

讀取某個路徑下的全部文件

import SwiftUI
import FirebaseFirestore
import FirebaseFirestoreSwift

struct ContentView: View {
    @FirestoreQuery(collectionPath: "songs") var songs: [Song]
    
    var body: some View {
        List {
            ForEach(songs) { song in
                HStack {
                    Text(song.name)
                    Spacer()
                    VStack(alignment: .trailing) {
                        Text(song.singer)
                        Text("\(song.rate)")
                    }
                }
            }
        }
    }
}

說明

@FirestoreQuery(collectionPath: "songs") var songs: [Song] 將自動讀取 Firestore songs 下的所有文件，然後將它存入 array songs。之後當 songs 下的文件有更新時，array songs 也會自動更新並更新 App 畫面。

結果

設定排序條件

在參數 predicates 傳入 order(by:) 設定排序條件，以下例子以 rate 排序，由小到大。

@FirestoreQuery(collectionPath: "songs", predicates: [
        .order(by: "rate")
]) var songs: [Song]

以 order 的參數 descending 為 true 控制排序由大到小。

@FirestoreQuery(collectionPath: "songs", predicates: [
        .order(by: "rate", descending: true)
]) var songs: [Song]

設定數量

以 limit(to:) 指定抓取的數量，以下例子設定最多抓取 2 首歌。

@FirestoreQuery(collectionPath: "songs", predicates: [
        .order(by: "rate", descending: true),
        .limitTo(2)
]) var songs: [Song]

搜尋特定的資料

  • 搜尋等於某個值的資料。

以下例子搜尋歌手小球的歌曲。

方法 1: 使用 isEqualTo(_:_:)

@FirestoreQuery(collectionPath: "songs", predicates: [
        .isEqualTo("singer", "小球")
]) var songs: [Song]

方法 2: 使用 where(_:isEqualTo:)

@FirestoreQuery(collectionPath: "songs", predicates: [
        .where("singer", isEqualTo: "小球")
]) var songs: [Song]
  • 搜尋大於某個值的資料。

以下例子搜尋評分大於 3 的歌曲。

方法 1: 使用 isGreaterThan(_:_:)

@FirestoreQuery(collectionPath: "songs", predicates: [
        .isGreaterThan("rate", 3)
]) var songs: [Song]

方法 2: 使用 where(_:isGreaterThan:)

@FirestoreQuery(collectionPath: "songs", predicates: [
        .where("rate", isGreaterThan: 3)
]) var songs: [Song]

除了比較等於和大於，還有很多比較的方法，有興趣的朋友可進一步查詢相關資訊。

Firebase Firestore 多個欄位 query 的 index 問題

在 FirestoreQuery 的參數 predicates array 裡若有用到多個欄位，可能會遇到資料無法抓取的問題。比方以下程式的 query 會判斷 mood & rate，抓取以 rate 排序的悲傷情歌。

@FirestoreQuery(collectionPath: "songs", predicates: [
        .isEqualTo("mood", "😢"),
        .order(by: "rate")
]) var songs: [Song]
