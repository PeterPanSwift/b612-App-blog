取得 GitHub token 的兩種方法

  • 方法 1: 透過 GitHub CLI。
  • 方法 2: 從 GitHub 網頁建立 token。

方法 1: 透過 GitHub CLI

參考以下連結安裝 GitHub CLI 和登入 GitHub 帳號。

安裝 GitHub CLI 和登入 GitHub 帳號
參考 GitHub CLI 網頁的教學安裝 GitHub CLI。medium.com

從 Terminal 輸入以下指令取得 token。

gh auth token

方法 2: 從 GitHub 網頁建立 token

連到以下網頁建立 token。

Build software better, together
GitHub is where people build software. More than 150 million people use GitHub to discover, fork, and contribute to…github.com

輸入自訂的 token 名字，在 Expiration 設定 token 過期的時間(ps: 若是想要 token 永不過期，請選擇 No expiration)，然後勾選 repo，如此才能擁有基本的權限，之後即可從 Xcode 將程式上傳到 GitHub。

點選下方的 Generate Token。

經歷千辛萬苦，終於產生 token。請馬上將寶貝的 token 複製，因為複製的機會只有一次，未來將無法再讀取 token 的內容。
