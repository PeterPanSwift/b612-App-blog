彼得潘寫了很多的 iOS App，可是從來沒寫過 Safari extension。結果在 macOS 27 發現一個天大的好消息，現在只要用文字描述想要的功能，Safari 就會利用 Apple Intelligence 生成 Safari extension。

以下彼得潘以生成 Medium 文章的短網址為例說明。

使用描述延伸功能製作 custom Safari extension

點選網址列左側的三條線，從選單點選描述延伸功能(Describe Extension)。

選擇建議的延伸功能，或是在下方框框描述想要的功能。

彼得潘在框框裡輸入以下文字。

將 Medium 網址變成短網址，存在剪貼簿
範例: https://medium.com/彼得潘的-swift-ios-app-開發問題解答集/macos-27-內建的螢幕錄影終於能錄製系統音訊-錄製有聲的-ios-app-操作影片-d0e4d4cfab67 -> https://medium.com/p/d0e4d4cfab67

Safari 會先尋找是否有相關的 extension。當它找不到時，我們可點選製作請它做一個。

Safari 製作了全新的 extension Medium Shortener，我們可點選試用測試。

連到某篇 Medium 文章，點選長得像連結 icon 的 Medium Shortener。

按下 cmd + v 貼上剪貼簿的內容，成功取得 Medium 文章的短網址 !

https://medium.com/p/d0e4d4cfab67

最後再點選儲存，之後即可方便地將 Medium 文章一鍵生成短網址。

找出 Safari extension 的相關程式

如果好奇 Medium Shortener 是如何生成短網址，可從以下路徑找出背後的程式，透過描述延伸功能製作的 custom Safari extension 將在 MagicExtensions 下。

~/Library/Containers/com.apple.Safari/Data/Library/Safari/MagicExtensions/
GitHub - adm1nsys/Safari-Ai-Extension: Safari Ai Extension for Mac OS 27, iOS 27, iPad OS 27.
Safari Ai Extension for Mac OS 27, iOS 27, iPad OS 27. - GitHub - adm1nsys/Safari-Ai-Extension: Safari Ai Extension for…github.com

範例: Medium Shortener 的資料夾為 MediumShortener-6D25，主要程式在 background.js。

browser.action.onClicked.addListener(async (tab) => {
  if (!tab || !tab.url) return;

  try {
    const url = new URL(tab.url);
    
    if (!url.hostname.includes('medium.com')) {
      return;
    }

    const pathParts = url.pathname.split('/');
    const lastPart = pathParts[pathParts.length - 1];
    const idMatch = lastPart.match(/-([a-f0-9]+)$/);
    
    let shortUrl = '';
    if (idMatch && idMatch[1]) {
      shortUrl = `https://medium.com/p/${idMatch[1]}`;
    } else if (/^[a-f0-9]+$/.test(lastPart)) {
      shortUrl = `https://medium.com/p/${lastPart}`;
    } else {
      return;
    }

    await navigator.clipboard.writeText(shortUrl);
    
    browser.action.setBadgeText({ text: '✓' });
    setTimeout(() => {
      browser.action.setBadgeText({ text: '' });
    }, 2000);
  } catch (error) {
    console.error("Failed to process URL or copy to clipboard: " + error);
  }
});

將 extension 分享給別人

如果想將 extension 分享給別人，請對資料夾執行以下指令，生成 Safari Extension App 的 Xcode 專案。

xcrun safari-web-extension-converter MediumShortener-6D25

打開 Xcode 專案，上方的裝置選擇 macOS > My Mac。

將 macOS 版本的 App & extension 設為付費帳號的 Team。

執行 Archive。

點選 Distribute App。

選擇 Direct Distribution。

稍等片刻後，出現 App 通過 Apple 驗證的視窗，請點選 Export 輸出 App。

之後只要將 App 傳給別人，對方執行 App 即可將 extension 安裝到 Safari。
