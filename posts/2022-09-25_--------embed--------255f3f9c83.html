將多行程式快速 embed 的手動輸入法

從 Xcode 14 開始，我們可以快速地將多行程式 embed，比方將兩個 Text embed 在 VStack。

接下來我們將以徐懷鈺的溫習為例，示範如何將多行程式快速 embed 在 VStack。

struct MovieRow: View {
    var body: some View {
        Text("溫習")
            .font(.largeTitle)
        Text("呼吸著你的呼吸\n發現我心跳跟著你的心")
            .foregroundColor(.gray)        
    }
}

ps: 從 Xcode 27 開始，我們可以直接利用 Embed in 包住多個元件。

利用 Embed 加入 SwiftUI 容器元件
SwiftUI 有一些特別的元件，專門以 { } 容納其它的元件，比方 HStack，VStack，List 等，Xcode 貼心地在 Code Actions 選單提供 Embed in 功能，方便我們快速加入這些元件。medium.com

方法 1: 選取多行程式，然後輸入 {

  • 選取多行程式
  • 輸入 {
  • 輸入 VStack
struct MovieRow: View {
    var body: some View {
        VStack {
            Text("溫習")
                .font(.largeTitle)
            Text("呼吸著你的呼吸\n發現我心跳跟著你的心")
                .foregroundColor(.gray)
        }
    }
}
選取程式後輸入 {, [, (,”，Xcode 自動輸入對應的 },], ), “
在 Xcode 輸入程式時，有個十分方便的功能。我們可以選取某段程式，然後再輸入 {, [, (, 或 "時，Xcode 會自動幫我們輸入對應的 },], ), 或 "，再也不怕不成對。medium.com

方法 2: 在多行程式的上方 & 下方分別輸入 { & }

  • 在多行程式的上方輸入 VStack {
  • 在多行程式的下方輸入 }

輸入 } 後，程式自動縮排地美美的。

struct MovieRow: View {
    var body: some View {
        VStack {
            Text("溫習")
                .font(.largeTitle)
            Text("呼吸著你的呼吸\n發現我心跳跟著你的心")
                .foregroundColor(.gray)
        }
    }
}
