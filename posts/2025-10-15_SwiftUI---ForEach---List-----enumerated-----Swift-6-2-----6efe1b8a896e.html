SwiftUI 的 ForEach & List 可以搭配enumerated 了 — Swift 6.2 新功能

透過 enumerated function 我們可以同時取得 array 的成員和對應的 index，但是在之前的 Swift 版本，enumerated 的結果並不能直接傳入 SwiftUI 的 ForEach & List，因此使用上沒那麼方便。

從 Swift 6.2 開始，這個限制終於被解除了，ForEach & List 可以直接搭配enumerated() 回傳的結果。

以下我們舉幾個實用的例子。

  • 在 List 顯示 array 的成員和編號。
  • 依序動畫。

在 List 顯示 array 的成員和編號。

struct ContentView: View {
    let books = [
        "七大祕密",
        "虎牙",
        "魔女與羅蘋",
        "怪盜與名偵探",
        "綠眼睛的少女",
        "黃金三角",
        "八大奇案",
        "奇巖城",
    ]

    var body: some View {
        List(books.enumerated(), id: \.element) { offset, book in
            Text("\(offset + 1). \(book)")
        }

    }
}

剛剛我們用 \.element 當 id，此寫法跟 \.1 是一樣的意思，因為 enumerated( ) 會得到 tuple，格式為 (offset: Int, element: Element)。若使用 offset 當 id 也可以，可寫成 \.offset 或 \.0。

當 array 的成員是自訂型別時，使用 \.element 當 id 可能會有問題，例如以下例子。

struct Book {
    let name: String
    let year: Int
}

struct ContentView: View {
    let books = [
        Book(name: "七大祕密", year: 1932),
        Book(name: "虎牙", year: 1933),
        Book(name: "魔女與羅蘋", year: 1934),
        Book(name: "怪盜與名偵探", year: 1935),
        Book(name: "綠眼睛的少女", year: 1936),
        Book(name: "黃金三角", year: 1937),
        Book(name: "八大奇案", year: 1938),
        Book(name: "奇巖城", year: 1939)
    ]

    var body: some View {
        List(books.enumerated(), id: \.element) { offset, book in
            HStack {
                Text("\(offset + 1). \(book.name)")
                Spacer()
                Text(String(book.year))
            }
        }
    }
}

出現錯誤 Initializer ‘init(_:id:rowContent:)’ requires that ‘Book’ conform to ‘Hashable’，因為當 id 的資料必須要 Hashable。

此問題有兩種解法。

  • 解法 1: 讓 Book 遵從 Hashable。
struct Book: Hashable {
    let name: String
    let year: Int
}
  • 解法 2: 使用可當 id 且 Hashable 的 property，比方書的名字。
List(books.enumerated(), id: \.element.name) { offset, book in

依序動畫

struct ContentView: View {
    let animals = ["🦊", "🐨", "🐰"]
    @State private var x: Double = 0
    
    var body: some View {
        VStack {
            HStack {
                ForEach(animals.enumerated(), id: \.element) { index, animal in
                    Text(animal)
                        .font(.largeTitle)
                        .offset(x: x)
                        .animation(.default.delay(Double(index) * 0.2), value: x)
                }
            }
            Button("Move") {
                x += 10
            }
        }
    }
}
