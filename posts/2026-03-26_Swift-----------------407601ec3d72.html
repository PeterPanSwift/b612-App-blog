Swift 描述常數型別時別將冒號打成等於

當我們撰寫程式時，有許多語法必須搭配指定的標點符號。然而這些小小的標點符號往往也是初學者一開始容易打錯的地方。

比方 Swift 描述常數型別的 type annotation 語法是在常數名的後面加上冒號。

struct Baby {
    let name: String
    let age: Int
}

然而常數常常會在後面加上等於設定內容，比方以下例子。

struct Baby {
    let name = "Peter"
    let age = 18
}

許多同學一開始還不習慣，很容易搞混，將冒號打成等於。

請千萬記得， 描述常數型別時別將冒號打成等於呀。
