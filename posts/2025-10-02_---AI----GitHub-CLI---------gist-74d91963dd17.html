不過將整個專案上傳的步驟有點複雜，如果只想儲存程式，不需要版本管理，也可採用另一個更快更簡單的方法，請 AI 將程式存成 GitHub 的 gist。

請 AI 幫忙之前，請先安裝 GitHub CLI 和登入 GitHub 帳號，AI 必須透過 GitHub CLI 建立 gist。

安裝 GitHub CLI 和登入 GitHub 帳號
參考 GitHub CLI 網頁的教學安裝 GitHub CLI。medium.com

有了 GitHub CLI，大部分的 AI 都能建立 gist，像是 Xcode coding agent、GitHub Copilot、Codex & Claude Code。以下我們用 Xcode 搭配 Codex 示範。

打開 Xcode 的 Coding Assistant，選擇 Codex。

輸入 @，選擇要變成 gist 的檔案 ContentView.swift。

輸入 prompt，使用 GitHub CLI 建立 gist。

AI 利用 gh gist create 指令成功建立 gist。

請 AI 將 gist 改成公開。

大功告成 ! 一切看似很美好，但是彼得潘複製網址貼到 Safari 卻看到了 404 ! 難道 AI 已經學會說謊 ?

其實錯不在 AI，問題出在我們手動從 Xcode 複製的網址會包含一些看不到的字元。

彼得潘將網址貼到 Terminal，發現多了一堆 <200b>，它們是為了排版加入的零寬空白。

既然不能手動複製，我們請 AI 直接提供可點選的連結或是複製到 pasteboard。

  • 方法 1: 請顯示成能直接點選的連結。

點擊連結後成功看到 gist。

  • 方法 2: 將網址 copy 到 pasteboard。
