在 Mac 安裝最新版的 Python

連到 Python 官網的 Download 頁面。

Download Python
The official home of the Python Programming Languagewww.python.org

點選 Download Python。

雙擊 python 的 pkg 檔。

依據視窗的安裝說明操作。

點選 Install。

完成 Python 的安裝程序，點選 Close 關閉視窗。

成功安裝後，從 Finder 的 Applications 分頁可看到多出了 Python 3.14 資料夾。

為了之後能用 Python 執行網路相關功能，請雙擊 Python 3.14 下的 Install Certificates.command 安裝 SSL 憑證。

現在 Mac 已具備執行 Python 程式的能力。重新啟動 Terminal，輸入 python3 --version 將顯示 Python 的版本。

Python 3.14.2

輸入 Python3 則可進入 REPL 模式輸入 python 程式。

從 VS Code 編輯 Jupyter Notebook 選擇 kernel 的 Python environment 時，選單裡也出現了剛剛安裝的 Python 3.14。
