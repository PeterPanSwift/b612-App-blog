期末專題主題不限，但須包含以下必備功能 。若有特別的 App idea，無法在 App 裡包含這些功能，可另外提出跟彼得潘討論。

ps: 電影、天氣、新聞、寶可夢 App 太多人做過，最好選別的主題，除非有把握在常見的主題加入一些特別的功能。

功能需求

  • 使用 async / await 串接後台的 API 抓取 JSON 資料後以 List 顯示，點選 row 可到下一頁顯示 detail，至少使用到兩個 API。

使用 JSONDecoder 解析 JSON，串接愈多 API 分數愈高。(上課範例以外的 API) 比方串接電影 API、YouTube API。以下電影 TMDB API 的 Get Popular & Get Top Rated 代表 2 個 API。

ps: 也可以串接 LINE, FB 等特別的 API，學習使用對方的 SDK。此情況不用使用 URLSession & JSONDecoder。

#19 串接第三方 API，解析 JSON 資料，轉換成自訂型別顯示
作業目的: 學習利用 URLSession 抓取後台的 JSON 資料後，利用 JSONDecoder 和 JSONSerialization 解析資料。medium.com
第三方 API 整理
Public API 列表medium.com
  • 以 TabView & NavigationStack 製作多頁面 App。
  • 定義 @Observable 的 class 串接網路 API 抓資料，使用到 environment。
  • 使用 ProgressView 和 ContentUnavailableView 顯示資料下載中。
  • 沒有網路時使用 ContentUnavailableView 顯示錯誤。
  • 使用 refreshable 實現下拉更新功能。
  • 使用 searchable 實現 search 功能，使用 ContentUnavailableView 顯示沒有資料。
  • 使用 ShareLink 實現分享功能。
  • 使用 TipKit 顯示 App 的操作說明 / 功能介紹。
  • 使用 SPM 加入第三方套件。(不包含上課範例提到的套件)
使用 SPM 安裝第三方套件 — 以抓圖套件 Kingfisher 為例
開發 iOS App 時，我們有許多管理安裝第三方套件的方法，其中最為人熟知的三大套件管理天王為 CocoaPods，SPM(Swift Package Manager) & Carthage。medium.com
  • 使用到至少一個沒教過的功能技術，使用愈多分數愈高。可在文章裡特別說明使用哪些沒教的技術。

例子:

Widget，CLLocationManager，Firebase，多國語言，QRCode，FB SDK，ARKit，Machine Learning，FaceID。
