從 VS Code 使用 Google Colab 開發 Python 程式

開發 Python 程式主要有兩種方法，一種是在自己的電腦安裝開發的工具軟體，像是安裝 Python & VS Code，一種則是從瀏覽器連到雲端的網站，比方 Google Colab。

這兩種方法各有優缺點，令人難以選擇。不過現在有更好的方法能同時享有兩者的好處。Google 推出了 VS Code 的 Colab extension，從本機安裝的 VS Code 可連到 Google Colab 開發 Python 程式，既可省去安裝開發工具的麻煩，還可享受 VS Code 強大的 IDE 功能和 GitHub Copilot 的 AI 功能。

打開 VS Code，切換到 Extensions 分頁，搜尋安裝 Google 的 Colab。

從 Command Palette (cmd + shift + p) 點選 Create: New Jupyter Notebook。

點選右上的 Select Kernel。

選擇 Colab。

選擇 Auto Connect。

點選 Allow。

點選 Open 打開網頁登入 Google 帳號。

登入 Google 帳號。

登入成功，點選 Allow 回到 VS Code。

點選 Open。

選擇 Python 3(ipykernel)。

視窗右上方的 Select Kernel 變成 Python 3 (ipykernel)。

完成以上設定後，就算電腦沒有安裝 Python，我們一樣能從 VS Code 連到 Colab 開發 Python 程式。

ps: 下一次從 VS Code 打開 Jupyter Notebook 寫程式時將自動記得之前登入的 Google 帳號，選擇 Auto Connect 後可直接選擇 Python 3(ipykernel)。

在 cell 輸入程式後點擊左側的三角形或按 shift + enter 執行程式。
