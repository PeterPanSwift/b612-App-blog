讓 table view 的 section header 自動計算高度

下圖為 FB App 的 po 文明細頁面，包含文章的內容和留言清單。(以 Apple TV 的好笑影集 Ted Lasso 為例）這樣的畫面該如何設計呢？

由於此頁面內容很多，需要上下捲動，所以我們通常會用 table view 或 collection view 實現。若用 table view 實作，下方的留言清單很適合以 table view cell 實現。而最上方的 po 文內容則有以下三種做法:

  1. 以 table view 的 section header 呈現。
  2. 以 table view 的 tableHeaderView 呈現。
  3. 以 table view 的第一個 cell 呈現。

接下來我們將示範以 section header 呈現 po 文內容的做法。由於 po 文內容的文字數量不固定，因此我們將利用 auto layout 讓 section header 自動計算高度，讓它能完整呈現 po 文內容。

新增繼承 UITableViewController 的類別 PostTableViewController

class PostTableViewController: UITableViewController {
}

在 storyboard 加入 table view controller，將類別設為 PostTableViewController

將 view 加到 First Responder 或 Exit 的底下

此 view 將呈現 po 文的內容，我們將在 Interface Builder 設計它的畫面，然後從程式將它設為 table view 的 section header。

在 view 上加入 label & image view，設定相關的 auto layout 條件

此處設定的 auto layout 條件十分重要，因為它會決定 view 的高度。

新增繼承 UIView 的類別 PostContentView，將呈現 po 文的 view 的類別設為 PostContentView

class PostContentView: UIView {
}

將 image view & label 拉 outlet 到 PostContentView

class PostContentView: UIView {
    @IBOutlet weak var imageView: UIImageView!
    @IBOutlet weak var label: UILabel!

將 view 拉 outlet 到 PostTableViewController

class PostTableViewController: UITableViewController {
    
    @IBOutlet var postContentView: PostContentView!

設定 cell 的 section header 為 postContentView

override func tableView(_ tableView: UITableView, viewForHeaderInSection section: Int) -> UIView? {
     return postContentView
}

在 viewDidLoad 設定 po 文的內容

override func viewDidLoad() {
        super.viewDidLoad()
        
        postContentView.label.text = "Small-time football coach Ted Lasso is hired to coach a professional soccer team in England, despite having no experience coaching soccer."
        postContentView.imageView.image = UIImage(named: "Ted Lasso")
}

設定 section header 自動計算高度

在 Interface Builder 點選 table view，切換到 Size inspector 頁面，將 Sections 下的 Header Height & Estimate 的 Automatic 勾選。

若要從程式設定，方法如下:

tableView.sectionHeaderHeight = UITableView.automaticDimension
tableView.estimatedSectionHeaderHeight = UITableView.automaticDimension

將 table view 的 style 改成 Grouped

如此 table view scroll 時，section header 才會跟著一起 scroll，而非卡在上面。

設定 cell 的 style & id

加入顯示留言清單的相關程式後，PostTableViewController 的完整程式如下

import UIKit
class PostTableViewController: UITableViewController {
    
    @IBOutlet var postContentView: PostContentView!
    let comments = [
        "超好看的 😍",
        "超好笑的 🤪",
        "不看會後悔一輩子 😭😭😭😭😭😭"
    ]
    
    override func viewDidLoad() {
        super.viewDidLoad()
        
        postContentView.label.text = "Small-time football coach Ted Lasso is hired to coach a professional soccer team in England, despite having no experience coaching soccer."
        postContentView.imageView.image = UIImage(named: "Ted Lasso")
        
        
    }
    
    // MARK: - Table view data source
    
    override func tableView(_ tableView: UITableView, viewForHeaderInSection section: Int) -> UIView? {
        return postContentView
    }
    
    override func numberOfSections(in tableView: UITableView) -> Int {
        // #warning Incomplete implementation, return the number of sections
        return 1
    }
    
    override func tableView(_ tableView: UITableView, numberOfRowsInSection section: Int) -> Int {
        // #warning Incomplete implementation, return the number of rows
        return comments.count
    }
    
    
    override func tableView(_ tableView: UITableView, cellForRowAt indexPath: IndexPath) -> UITableViewCell {
        let cell = tableView.dequeueReusableCell(withIdentifier: "CommentCell", for: indexPath)
        
        // Configure the cell...
        cell.textLabel?.text = comments[indexPath.row]
        return cell
    }
    
}

執行 App

現在隨著不同的 po 文內容，section header 都能完整呈現，因為它將聰明地利用我們設定的 auto layout 條件自動調整高度呢。
