打開 macOS script 顯示通知的權限

打開 Script Editor，新增一個檔案，輸入顯示通知的指令。

display notification "Hello from Script Editor!" with title "Try me 🧪"

點選三角形按鈕執行指令。

此時螢幕的右上方會出現 Script Editor 的通知權限請求，請選擇 Allow 允許。

ps: 若是忘了允許，可從 System Settings 的 Notifications 將 Script Editor 的 Allow notifications 打開。

再次點選三角形按鈕，確認 display notification 指令能成功顯示通知。
