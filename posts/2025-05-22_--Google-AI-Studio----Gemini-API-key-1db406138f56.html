從 Google AI Studio 生成 Gemini API key

連到 Google AI Studio。

Google AI Studio
Google AI Studio is the fastest way to start building with Gemini, our next generation family of multimodal generative…aistudio.google.com

點選左下方的鑰匙按鈕取得 API key。

點選右上方的 Create API key。

設定 API key 的名稱和專案。

可建立新專案或選擇之前的專案。

複製生成的 API key。

點選 Copy cURL quickstart 可取得串接 Gemini API 的 curl 指令。

curl "https://generativelanguage.googleapis.com/v1beta/models/gemini-flash-latest:generateContent" \
  -H 'Content-Type: application/json' \
  -H 'X-goog-api-key: 11112222333' \
  -X POST \
  -d '{
    "contents": [
      {
        "parts": [
          {
            "text": "Explain how AI works in a few words"
          }
        ]
      }
    ]
  }'

之後若要查詢之前建立的 API key，請從側邊欄點選 Dashboard。
