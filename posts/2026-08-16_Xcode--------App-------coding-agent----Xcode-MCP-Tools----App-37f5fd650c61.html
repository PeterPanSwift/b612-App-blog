Xcode 沒開也能開發 App — 外部的 coding agent 透過 Xcode MCP Tools 開發 App

從 Xcode 27 beta 5 開始，就算 Xcode 沒開，外部的 coding agent 也能透過 Xcode MCP Tools 進行 App 開發的工作，像是建立專案、編譯 App、預覽畫面、操作 App。

設定 Xcode MCP server

為了讓外部的 coding agent 能在 Xcode 沒開時存取 Xcode MCP server，請從 Terminal 輸入以下指令。

sudo xcrun mcp-server enable
mcp-server: enabled (unsafeAlwaysAllowAllAgents: false)

輸入以下指令可查詢 Xcode MCP server 的狀態。

xcrun mcp-server status
Permission: enabled
mcp-server: not running

從結果可看到它已經 enabled，但是處於 not running 的狀態。請輸入以下指令將 Xcode MCP server 跑起來。

xcrun mcp-server start

此時再輸入 xcrun mcp-server status 將看到 mcp-server 顯示 running。

接著我們分別示範從 Codex & Claude Code 連接 Xcode MCP server 開發 App。

Codex

  • 加入 Xcode MCP server。

打開 ChatGPT App，切換到設定的外掛程式頁面，點選新增 -> 新增 MCP 伺服器。

名稱輸入 xcode，啟動指令輸入 /usr/bin/xcrun，引數輸入 mcpbridge，然後點選儲存。

此時將跳出以下視窗，點選 Always Allow 允許 agent 使用 Xcode tools。

外掛程式的 MCP 分頁出現剛剛加入的 xcode MCP server。

ps: 輸入以下指令也可加入 Xcode MCP server。

codex mcp add xcode -- /usr/bin/xcrun mcpbridge

Claude Code

  • 加入 Xcode MCP server。
claude mcp add --scope user Xcode -- /usr/bin/xcrun mcpbridge

File modified: /Users/shih-yingpan/.claude.json
  • 列出 Claude 設定好的 MCP Server 清單。
claude mcp list

從手機的 ChatGPT & Claude 開發 App

從手機的 ChatGPT & Claude 可操控電腦的 ChatGPT & Claude 透過 Xcode MCP Tools 開發 App。不過有一點要特別注意，請先在電腦同意存取專案所在的資料夾，因為從手機是無法同意的。
