使用 #Preview 研究 Swift 的畫星星蘋果迴圈

彼得潘之前教學時發現 nested loop 對程式初學者是個滿大的難題，尤其經典的畫星星程式，同學們常常要研究很久，不斷地修改研究後才能想出解法。

最近 Xcode 15 推出了方便預覽 App 畫面的 #Preview 功能，彼得潘想到利用它即時預覽的特性，同學們練習畫星星時可以更方便地一邊修改程式，一邊從預覽畫面觀看成果。

以下我們分別介紹 SwiftUI & UIKit 程式裡練習寫畫星星迴圈的方法。

SwiftUI

在 ContentView 裡宣告 property content，在 let content = 後的 { } 裡練習用 nested loop 產生多排 🍎 的字串。

import SwiftUI

struct ContentView: View {
    let content = {
        var content = ""
        let count = 3
        for _ in 1...count {
            for _ in 1...count {
                content += "🍎"
            }
            content += "\n"
        }
        return content
    }()

    var body: some View {
        Text(content)
            .font(.largeTitle)
    }
}

#Preview {
    ContentView()
}

由於下方的 #Preview { ContentView() }，Xcode 的右邊出現了預覽畫面，顯示我們辛苦畫出的 🍎。

當我們練習其它形狀時，只要修改程式，即可馬上從預覽畫面觀看成果。比方以下是三角形的程式和預覽畫面。

UIKit

  • 在 function viewDidLoad 裡練習用 nested loop 產生多排 🍎 的字串，然後顯示到 label 上。
class ViewController: UIViewController {
    
    @IBOutlet weak var label: UILabel!
    
    override func viewDidLoad() {
        super.viewDidLoad()
        // Do any additional setup after loading the view.
        
        var content = ""
        let count = 3
        for _ in 1...count {
            for _ in 1...count {
                content += "🍎"
            }
            content += "\n"
        }
        label.text = content
    }
}
  • 在 class ViewController { } 的下方加入以下程式產生預覽畫面。
#Preview {
    let storyboard = UIStoryboard(name: "Main", bundle: nil)
    return storyboard.instantiateInitialViewController()!
}
