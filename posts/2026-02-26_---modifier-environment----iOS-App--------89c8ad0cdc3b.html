透過 modifier environment 設定 iOS App 的語言和方向

當我們從 iOS 的 Settings 調整系統的語言時，它會同時影響 App 的語言和排版方向。當我們開發 App 時，若想快速查看頁面在某種語言的模樣，從 Preview 添加 modifier environment 設定語言和排版方向也是不錯的方法。

以下我們以阿拉伯版的小王子名言示範。

在專案的 Localization 先加入 Arabic，Localizable.xcstrings 設定翻譯的文字。

畫面程式如下。

struct ContentView: View {
    var body: some View {
      
        HStack {
            Image(systemName: "quote.bubble.fill")
            Text("It is only with the heart that one can see rightly; what is essential is invisible to the eye.")
        }
        .font(.largeTitle)
        .padding()
    }
}

設定 locale，將語言變成阿拉伯。

#Preview {
    ContentView()
        .environment(\.locale, Locale(languageCode: .arabic))
}

設定 layoutDirection，將排版方式變成右到左。

#Preview {
    ContentView()
        .environment(\.locale, Locale(languageCode: .arabic))
        .environment(\.layoutDirection, .rightToLeft)
}

ps: iOS 的系統語言將同時影響 App 的語言和排版方向，然而 environment 的 locale 只影響語言，因此必須另外透過 layoutDirection 設定方向。
