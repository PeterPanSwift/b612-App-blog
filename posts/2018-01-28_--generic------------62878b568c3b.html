幫 generic 型別代號加上限制條件

generic 擁有設定型別條件的特殊能力，比方以下例子 ，由於型別代號 T 可置換成任何型別，因此如果小王子不小心養了殭屍 Zombie 當寵物，很可能在睡夢中被殭屍咬一口，再也見不到明天的太陽。

class LittlePrince<T> {
   var pet: T?
}

class Zombie {
   func bite() {
      print("🧛‍♀️🧛‍♂️")
   }
}

var prince = LittlePrince<Zombie>()
prince.pet = Zombie()
prince.pet?.bite()

為了避免憾事發生，我們可以幫型別代號加上限制條件，限制小王子只能馴養可愛的動物。

protocol Cute {
   func smile()
}

class Fox: Cute {
   func smile() {
      print("😊😘")
   }
}

class LittlePrince<T: Cute> {
   var pet: T?
}

var prince = LittlePrince<Fox>()
prince.pet = Fox()
prince.pet?.smile()
結果:

在型別代號後加上冒號和 protocol 名稱，即可限制型別代號要遵從 protocol。因此 T: Cute 限制型別必須遵從 Cute protocol，小王子只能馴養遵從 Cute protocol，散發可愛氣息的超萌生物，例如狐狸，而殭屍很遺憾被排除在千里之外，因為它沒有遵從 Cute protocol，和可愛完全沾不上邊。

剛剛的型別限制語法，除了可以指定遵從的 protocol，也可以指定某個類別。比方當我們指定 Animal 類別時，小王子可以馴養 Animal 物件或任何繼承 Animal 的類別建立的物件。

class Animal {
   func eat() {
      print("🍔🍱")
   }
}

class Fox: Animal {
   func run() {
      print("🦊")
   }
}

class LittlePrince<T: Animal> {
   var pet: T?
}

var prince1 = LittlePrince<Animal>()
prince1.pet = Animal()
prince1.pet?.eat()
var prince2 = LittlePrince<Fox>()
prince2.pet = Fox()
prince2.pet?.run()
結果:

透過剛剛的方法，我們可以輕易設定型別的條件，但可惜它只接受一個條件，如果想要多個條件，則須請 where 幫忙。

比方小王子希望他馴養的寵物屬於 Animal 型別，同時遵從 Quiet 和 Cute protocol， 又可愛又安靜，這麼多的條件，如何一次滿足呢? 以下兩個方法都可實現:

方法一:

在 < > 裡先說明第一個條件，然後利用 where 補上其它條件，中間以逗號分隔。

protocol Cute {
   func smile()
}

protocol Quiet {
   func sleep()
}

class Animal {
   func eat() {
      print("🍔🍱")
   }
}

class Fox: Animal, Cute, Quiet {
   func smile() {
      print("😊😘")
   }
   func sleep() {
      print("😴😴")
   }
}

class LittlePrince<T: Animal> where T: Quiet, T: Cute {
   var pet: T?
}

var prince = LittlePrince<Fox>()
prince.pet = Fox()
prince.pet?.smile()
prince.pet?.sleep()
prince.pet?.eat()
結果:
方法二: 利用 where 描述所有條件。
class LittlePrince<T> where T:Animal, T: Quiet, T: Cute {
   var pet: T?
}
