Modifying State

學習 @State，property wrapper。

以 @State 宣告的資料 isOn 改變時將讓 ConditionalViews 的畫面更新，執行 body { } 裡的程式。

struct ConditionalViews: View {
    @State var isOn = false
    
    var body: some View {
        VStack {
            if isOn {
                Circle()
                    .frame(maxHeight: 200)
                    .foregroundColor(.mint)
                Text("On")
            } else {
                Rectangle()
                    .frame(maxHeight: 200)
                    .foregroundColor(.gray)
                Text("Off")
            }
            
            Button("Press Me") {
                isOn.toggle()
            }
        }
    }
}
用狀態設計 SwiftUI 畫面 — 認識 State property
SwiftUI 用狀態決定如何顯示和更新畫面，因此它的很多 UI 元件都跟狀態有關。接下來我們就以下雨時顯示孫燕姿的壞天氣，放晴時顯示盧廣仲的我愛你歌詞為例，說明狀態如何深深影響著 SwiftUI 的畫面。medium.com

Using a Conditional Modifier

學習 Conditional Modifier，animation。

利用 ? : 控制 modifier 傳入的參數內容，呼叫 animation modifier 實現動畫效果。

struct ConditionalCircle: View {
    @State var isOn = false
    
    var body: some View {
        VStack {
            Circle()
                .frame(maxHeight: 200)
                .foregroundColor(isOn ? .purple : .mint)
                .shadow(color: isOn ? .indigo : .orange, radius: 20)
                .scaleEffect(isOn ? 1 : 0.75)
                .animation(.default, value: isOn)
            
            Button("Press Me") {
                isOn.toggle()
            }
        }
    }
}

SwiftUI Built-in Views

學習 @Binding，source of truth，Toggle，ColorPicker，$。

真正的資料只有一份，存在 state property。利用 Binding 讓 subview 參考存取同一份資料。

在 state property 加上 $ 可產生 Binding，以下例子的 Binding $isOn 和 $color 將讀取和修改 State property 儲存的資料，因此切換開關跟選顏色將改變 State property 的內容，造成畫面的更新。

struct Bindings: View {
    @State var isOn = false
    @State var color = Color.primary
    
    var body: some View {
        VStack {
            Toggle("Press Me", isOn: $isOn)
            ColorPicker("Select a Color", selection: $color)
            Text("Battery")
                .font(.largeTitle)
                .foregroundColor(color)
            Image(systemName: isOn ? "battery.100" : "battery.25")
                .font(.system(size: 150))
                .foregroundColor(color)
        }
        .padding()
    }
}

resizableFont 的定義。

extension View {
    func resizableFont(maximumFontSize: Double = 125, minimumScaleFactor: Double = 0.01) -> some View {
        self.modifier(FlexibleFontModifier(maximumFontSize: maximumFontSize, minimumScaleFactor: minimumScaleFactor))
    }
}

struct FlexibleFontModifier: ViewModifier {
    var maximumFontSize: Double
    var minimumScaleFactor : Double
    
    func body(content: Content) -> some View {
        content
            .font(.system(size: maximumFontSize))
            .minimumScaleFactor(minimumScaleFactor)
    }
}

使用 environment object，讓整個 App 都能存取資料

在 NavigationView 呼叫 modifier environmentObject，傳入 data，將型別 CreatureZoo 的 data 存入環境裡，之後 subview 都能存取 data。

struct MyApp: App {
    @StateObject var data = CreatureZoo()
    
    var body: some Scene {
        WindowGroup {
            NavigationView {
                ContentView()
                    .navigationTitle("My Creatures")
            }
            .environmentObject(data)
        }
    }
}

Create a New View to Share Data

學習 onTapGesture & 有趣的動畫效果。

點選動物時隨機動物的位置跟旋轉角度，搭配動畫效果。

struct DancingCreatures: View {
    @EnvironmentObject var data: CreatureZoo
    
    var body: some View {
        VStack {
            ZStack {
                ForEach(data.creatures) { creature in
                    
                    Text(creature.emoji)
                        .resizableFont()
                        .offset(creature.offset)
                        .rotationEffect(creature.rotation)
                        .animation(.default, value: creature.offset)
                }
            }
            .onTapGesture {
                data.randomizeOffsets()
            }
        }
    }
}

struct DancingCreatures_Previews: PreviewProvider {
    static var previews: some View {
        DancingCreatures().environmentObject(CreatureZoo())
    }
}

function randomizeOffsets 的定義。

extension CreatureZoo {
    func randomizeOffsets() {
        for index in creatures.indices {
            creatures[index].offset = CGSize(width: CGFloat.random(in: -200...200), height: CGFloat.random(in: -200...200))
            creatures[index].rotation = Angle(degrees: Double.random(in: 0...720))
        }
    }
}

加入 spring 的旋轉動畫效果。值得注意的，以下程式 animation modifier 的順序很重要，若是將 rotation 的 animation 移到 offset animation 的下面，將不會看到 spring 的旋轉動畫效果。

Text(creature.emoji)
    .resizableFont()
    .offset(creature.offset)
    .rotationEffect(creature.rotation)
    .animation(.spring(response: 0.5, dampingFraction: 0.5), value: creature.rotation)
    .animation(.default, value: creature.offset)

呼叫 synchronizeOffsets() 讓每個生物隨機一樣的 offset，讓它們移動到同一個位置。動畫效果搭配 delay，讓 array 裡的動物依序移動。

struct DancingCreatures: View {
    @EnvironmentObject var data: CreatureZoo
    
    var body: some View {
        VStack {
            ZStack {
                ForEach(data.creatures) { creature in
                    
                    Text(creature.emoji)
                        .resizableFont()
                        .offset(creature.offset)
                        .rotationEffect(creature.rotation)
                        .animation(.spring(response: 0.5, dampingFraction: 0.5), value: creature.rotation)
                    .animation(.default.delay(data.indexFor(creature) / 10), value: creature.offset)
                }
            }
            .onTapGesture {
                data.synchronizeOffsets()
            }
        }
    }
}

在 CreatureZoo 裡定義 function synchronizeOffsets & indexFor。

func synchronizeOffsets() {
        let randomOffset = CGSize(width: CGFloat.random(in: -200...200), height: CGFloat.random(in: -200...200))
        for index in creatures.indices {
            creatures[index].offset = randomOffset
        }
}
    
func indexFor(_ creature: Creature) ->  Double {
        if let index = creatures.firstIndex(where: { $0.id == creature.id }) {
            return Double(index)
        }
        return 0.0
}

開發 iOS App 時，我們時常會在上方的 navigation bar & 下方的 tool bar 加入元件，比方下圖 Calendar App 上方的放大鏡和下方的 Today。medium.com

定義輸入資料的畫面 CreatureEditor，以 Form 實現表單，搭配 Environment value dismiss 回到上一頁。

struct CreatureEditor: View {
    @State var newCreature = Creature(name: "", emoji: "")
    @EnvironmentObject var data : CreatureZoo
    @Environment(\.dismiss) var dismiss

    var body: some View {
        VStack(alignment: .leading) {
            Form {
                Section("Name") {
                    TextField("Name", text: $newCreature.name)
                    
                }
                
                Section("Emoji") {
                    TextField("Emoji", text: $newCreature.emoji)
                }
                
                Section("Creature Preview") {
                    CreatureRow(creature: newCreature)
                }
            }
        }
        .toolbar {
            ToolbarItem {
                Button("Add") {
                    data.creatures.append(newCreature)
                    dismiss()
                }
            }
        }        
    }
}

Add a CreatureDetail view

學習點選 List 的 row，切換到下一頁顯示 detail。

定義 CreatureDetail，搭配白色的 shadow 增添閃閃發光的效果。

struct CreatureDetail: View {
    let creature : Creature
    
    @State var color = Color.white
    @State var shadowRadius : CGFloat = 0.5
    @State var angle = Angle(degrees: 0)
    
    var body: some View {
        VStack {
            Text(creature.emoji)
                .resizableFont()
                .colorMultiply(color)
                .shadow(color: color, radius: shadowRadius * 40)
                .rotation3DEffect(Angle(degrees: 0), axis: (x: 5, y: 2, z: 1))
        }
        .padding()
    }
}

在 CreatureDetail 調整生物的模樣，比方調整陰影的顏色和生物的尺寸。

struct CreatureDetail: View {
    let creature : Creature
    @State var color = Color.white
    @State var shadowRadius : CGFloat = 0.5
    @State var angle = Angle(degrees: 0)
    @State var isScaled = false
    @State var blurRadius: Double = 0
    
    var body: some View {
        VStack {
            Text(creature.emoji)
                .resizableFont()
                .colorMultiply(color)
                .shadow(color: color, radius: shadowRadius * 40)
                .rotation3DEffect(isScaled ? Angle(degrees: 0) : Angle(degrees: 360), axis: (x: 5, y: 2, z: 1))
                .scaleEffect(isScaled ? 1.5 : 1)
                .animation(.spring(response: 0.5, dampingFraction: 0.5, blendDuration: 0.5), value: isScaled)
                .blur(radius: blurRadius)
            
            ColorPicker("Choose a Color", selection: $color)
            HStack {
                Text("Shadow")
                Slider(value: $shadowRadius)
            }
            Button("Scale") {
                isScaled.toggle()
            }
            HStack {
                Text("Blur")
                Slider(value: $blurRadius, in: 0...10)
            }
        }
        .padding()
    }
}
