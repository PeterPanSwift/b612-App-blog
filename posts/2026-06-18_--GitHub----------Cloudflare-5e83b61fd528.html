將 GitHub 的網頁程式部署到 Cloudflare

Cloudflare 提供方便的網站部署功能，尤其它可以直接跟 GitHub 專案綁定，當我們修改程式 push 到 GitHub 時，將可直接連動 Cloudflare 更新網站。

以下彼得潘從頭示範如何將 GitHub 的網頁程式部署到 Cloudflare。

連到 Cloudflare，登入帳號。

Cloudflare: Build for the agent era
Welcome to Cloudflare - Powering the next generation of applicationswww.cloudflare.com

點選側邊欄的 Workers and Pages。

點選 Create application。

選擇部署成 Worker 或 Pages，以下我們點選 Worker 的 Continue with GitHub。

選擇 GitHub 帳號和 repository，然後點選 Next。

點選 Deploy。

部署中。

部署成功，出現綠色的勾勾。

點選右上方的 Visit 即可打開熱騰騰的新網站。
