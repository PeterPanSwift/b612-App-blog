從 Xcode 使用 amend 修改上次的 git commit

開發 iOS App 時我們常常透過 git 的 commit 記錄程式的修改，例如下圖的 commit add fox 記錄著彼得潘在 assets 加入可愛的狐狸圖片。

然而有時我們會想修改上次的 commit，比方以下兩種情況。

  • 想修改 commit 的訊息。
  • 發現有忘了修改的地方，想要修改後合併到上次的 commit。

透過 git commit 的 amend 可修改上次的 commit。以下我們以剛剛的 commit add fox 為例說明。(ps: amend 就是修改的意思)

彼得潘後來想到，只在 asset 加入圖片沒有意義，必須在 ContentView 顯示狐狸圖片才能讓小王子開心。

修改 ContentView.swift 後，執行 Xcode Commit 的動作，跳到 Commit 視窗。

打開上方 Amend 的開關，表示我們想修改上次的 commit。

Amend 後方的 1c9c49c 其實有特殊意義，它代表上次 commit id 的前幾個字元。

當 Amend 開關打開時，下方的輸入框將預設填入上次 commit 的訊息。

我們可維持原來的訊息，也可以修改訊息。以下彼得潘將訊息改成 add fox and show fox in ContentView，然後再點選 Amend。

點選 Stage All and Commit。

Yay! 🎉 我們成功修改了 commit，同時更新了 commit 的內容、訊息和 id。

雙擊上圖的 commit 訊息可進一步查詢 commit 修改的內容。
