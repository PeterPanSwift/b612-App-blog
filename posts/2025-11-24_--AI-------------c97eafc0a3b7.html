請 AI 生成精美的程式逐行說明

初學者學習程式時，常常會製做程式的逐行說明筆記。從前我們需要手工製作，現在有了聰明的 AI，我們可以請它製作兩種版本的程式說明。

  • 精美圖片版。
  • 互動網頁版。

以下彼得潘使用 Gemini 3 Pro 搭配 SwiftUI 程式示範。

精美圖片版

生成圖片，在筆記本上用可愛的英文字體寫以下程式的筆記，說明 } 之外的每一行程式。程式要搭配 syntax highlight 的顏色，程式和說明的文字要不同顏色。加上一些可愛插圖。

struct ContentView: View {
    var body: some View {
        VStack {
            Image(systemName: "globe")
                .imageScale(.large)
                .foregroundStyle(.tint)
            Text("Hello, world!")
        }
        .padding()
    }
}

選擇 Image。

將說明改成更淺顯易懂，適合初學者。

互動網頁版

請 AI 生成點擊程式顯示說明的互動網頁。

生成網頁，在可愛的筆記本上用可愛的英文字體寫以下程式，程式要有 syntax highlight 的顏色，點選程式會顯示那行程式的英文說明

struct ContentView: View {
    var body: some View {
        VStack {
            Image(systemName: "globe")
                .imageScale(.large)
                .foregroundStyle(.tint)
            Text("Hello, world!")
        }
        .padding()
    }
}

選擇 Canvas。
