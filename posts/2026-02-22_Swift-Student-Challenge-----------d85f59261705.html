Swift Student Challenge 參賽作品的大小限制

最近有同學精心製作了 Swift Student Challenge 的參賽作品，請彼得潘給予意見，不過當彼得潘收到作品後，大大地吃了一驚，因為檔案超大的，快要 100 MB !

Apple 在比賽網頁清楚提到 swiftpm 的 zip 檔不能超過 25 MB，因此製作 App 時還是要注意一下大小，不要為了塞入豐富的內容和功能讓 App 過於肥大。

Eligibility and Requirements - Swift Student Challenge
Make sure to review the current eligibility conditions to confirm that you're qualified to participate.developer.apple.com

如果將 swiftpm 壓成 zip 後，發現大小超過 25 MB，可從 Terminal 切換到 swiftpm 下(ps: swiftpm 其實是資料夾)，透過以下指令列出全部檔案，依大小由大到小排列，找出害 App 過重的凶手。

find . -type f -exec du -h {} + | sort -hr

彼得潘透過以上指令研究同學的 App 後，發現原來是 git 惹的禍。前四名都是 git 相關的檔案。

開發 App 時使用 git 進行版本管理是滿好的習慣，不過準備 Swift Student Challenge 的 zip 檔時建議將 git 相關的檔案移除。git 相關的東西都在資料夾 .git 下，因此只要將 .git 整個移除即可。

rm -rf .git
