請 AI 幫忙進行 git 的 commit & push — 使用 Xcode 的 coding agent

開發 App 時，透過 git 進行專案的版本管理是很重要的一件事。但是對於 git 不太了解怎麼辦吧 ? 沒關係，我們可以請 AI 幫忙，請它進行 git 的 commit & push。

以下我們使用 Xcode 的 coding agent 示範。

當程式修改到某個想儲存的時間點時，我們可請 AI 進行 commit 記錄目前的程式。不同於會覆蓋之前內容的存檔，每次 commit 儲存的版本都會完整保留，未來我們將可隨時切換到某個 commit 時間點的程式版本。

打開 Xcode 的 Coding Assistant，選擇 Codex 或 Claude agent。

輸入 prompt commit。

AI 成功完成 commit，而且還聰明地分析程式描述詳細的 commit 訊息 Update ​Content​View greeting and icon styling。

打開 Source Control navigator，切換到 Repositories 分頁即可看到剛剛完成的 commit。

接著將專案程式 push (上傳)到 GitHub 的動作也可以請 AI 幫忙，輸入以下 prompt。

將 App 上傳到 GitHub，建立 public repository

詳細的操作說明可參考以下連結。

問題出在複製的網址會包含一些看不到的字元，造成它不是正確的網址。解決的方法很簡單，那就別複製，請 AI 將網址變成可點擊的連結。

將 repository 的網址變成可點擊的連結

點擊後即可成功連到專案的 GitHub 頁面。

打開 Source Control navigator，切換到 Repositories 分頁，Remotes 下的 origin 即為上傳到 GitHub 的 App 專案。

之後每當程式修改到某個想儲存的時間點時，我們可以直接請 AI 進行 commit & push，記錄完後直接上傳到 GitHub。
