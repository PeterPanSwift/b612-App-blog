vibe coding #48 — 將圖片加上漂亮標記 – 立體玻璃泡泡／發光框／手繪蠟筆

彼得潘平常程式教學時，常常需要圈選說明程式或 IDE 的元件。從前沒有 AI 時透過 Mac 的 Preview App 幫圖片加上注解，後來有了 AI 後常請 AI 幫圖片加上漂亮標記。

比方我們想圈選 Text("Hello, world!")。

請 AI 將 Text("Hello, world!") 加上漂亮的螢光圈選標記，生成的結果滿不錯的，不過 AI 生圖會花不少時間，而且也會消耗寶貴的 token。

因此彼得潘想想，不如請 AI 寫個幫圖片加上標記的 python 程式，這樣不只能快速生圖，而且也不會消耗 token。

以下彼得潘請 Claude Fable 5 幫忙，請它寫一個 python 程式，透過 OCR 幫圖片裡指定的文字添加立體玻璃泡泡、發光框跟手繪蠟筆的圈選效果。

AI 成功完成任務，生成 circle_text.py，使用 macOS 內建的 Vision framework 做 OCR，再用 Pillow 畫出 3D 立體泡泡的圈選效果。

指令的基本格式如下。

python circle_text.py image.png "text to highlight"

範例。

python circle_text.py xcode.png 'Text("Hello, world")'

我們還可透過參數 — color 指定顏色，比方改成黃色外框。

python circle_text.py xcode.png 'Text("Hello, world")' --color "#FFFF00"

為了能圈選 IDE 的元件，我們再請 AI 修改程式，支援圈選多個文字組合的區塊 ，而且能延伸到整個選項的框框。

範例。

python circle_text.py xcode2.png 'interface swiftui'

接著彼得潘請 AI 提供三種樣式，除了剛剛的泡泡，另外再提供發光框跟不規則形狀的手繪蠟筆。

  • 發光框。
python circle_text.py xcode.png 'Text("Hello, world")' --style glow
  • 手繪蠟筆。
python circle_text.py xcode.png 'Text("Hello, world")' --style crayon

不過從 Terminal 打指令跑 Python 程式還是有點麻煩，能不能直接從 Finder 對圖片檔加標記呢 ?

這也難不倒 AI，AI 開發出搭配 python 程式的圈選文字.app，利用 osacompile 將 AppleScript 編譯成 App，App 的結講如下

為了讓 Finder 的圖片能從圈選文字.app 開啟，App 的 Info.plist 加入以下設定。

<key>CFBundleDocumentTypes</key>
<array>
    <dict>
        <key>CFBundleTypeName</key>
        <string>Image</string>
        <key>CFBundleTypeRole</key>
        <string>Viewer</string>
        <key>LSItemContentTypes</key>
        <array>
            <string>public.image</string>
        </array>
        <key>LSHandlerRank</key>
        <string>Alternate</string>
    </dict>
</array>

現在當我們在 Finder 對某張圖片叫出右鍵選單時，將可點選打開檔案的應用程式 > 圈選文字。
