叫出 Coding Tools

先選取程式，然後透過以下方法叫出 Coding Tools。

  • 方法 1: 點選下圖的星星。
  • 方法 2: 從 Quick Actions 點選 Show Coding Tools 或按快速鍵 cmd + option + 0。
  • 方法 3: 從右鍵選單點選 Show Coding Tools。

成功叫出 Coding Tools 時，它將出現在左側，選取的程式則被漂亮的虛線框起。

說明程式

選取程式，點選 Coding Tools 的 Explain。

Image(systemName: "globe")
    .imageScale(.large)
    .foregroundStyle(.tint)

AI 鉅細靡遺地說明程式。

產生文件

選取溫度換算的程式，點選 Coding Tools 的 Document。

func fahrenheitToCelsius(_ fahrenheit: Double) -> Double {
    (fahrenheit - 32) * 5 / 9
}

AI 產生以 /// 描述的詳細文件。

產生 Preview

選取程式，點選 Coding Tools 的 Generate a Preview 產生 AnimalView 的預覽畫面。

struct AnimalView: View {
    let name: String
    let emoji: String
    let description: String
    
    var body: some View {
        HStack {
            Text(emoji)
                .font(.system(size: 50))
            VStack {
                Text(name)
                Text(description)
            }
        }
    }
}

AI 生成 #Preview 包含的貓咪預覽畫面。

產生 Playground

選取程式，點選 Coding Tools 的 Generate a Playground，產生測試 Animal 的相關程式。

struct Animal {
    let name: String
    let emoji: String
    let description: String

AI 生成 #Playground 包含的 Animal 測試程式。

Generate Fix for issue

請 AI 幫忙修正程式錯誤。

以下程式生成 AnimalView 時少了 Animal。

struct Animal {
    let name: String
    let emoji: String
    let description: String
}
import SwiftUI

struct AnimalView: View {
    let animal: Animal
    
    var body: some View {
        HStack {
            Text(animal.emoji)
                .font(.system(size: 50))
            VStack {
                Text(animal.name)
                Text(animal.description)
            }
        }
    }
}

#Preview {
    AnimalView()
}

點選錯誤訊息。

點選 Generate Fix for issue 的 Generate。

AI 成功修正問題，生成 AnimalView 時傳入可愛的 Animal 🦁。
