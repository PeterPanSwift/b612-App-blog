顯示多個 SwiftUI preview

從 SwiftUI preview 預覽 App 畫面時，有時我們會想預覽畫面在不同情況呈現的樣子，此時我們可創建多個 preview，然後在不同的 preview 分頁間切換顯示。

以下我們以 EmojiRow 為例，目標創作兩個 preview，分別顯示可愛的狐狸和企鵝。

struct EmojiRow: View {
    let emoji: String
    let name: String
    
    var body: some View {
        HStack {
            Text(emoji)
                .font(.system(size: 100))
            Text(name)
                .font(.largeTitle)
        }
    }
}

顯示多個 SwiftUI preview

一個 #Preview 可建立一個 preview，2 個 #Preview 可建立兩個 preview，建立幾個 #Preview 就可創建幾個 preview 分頁。

#Preview {
    EmojiRow(emoji: "🦊", name: "fox")
}

#Preview {
    EmojiRow(emoji: "🐧", name: "penguin")
}

兩個 #Preview 實現 2 個 preview 分頁，preview 上的 line 數字代表 #Preview 的行數。

設定 preview 的名字

如果想更清楚辨別 preview 分頁，建立 #Preview 時可設定分頁的標題，以下我們分別設定 fox 和 penguin。

#Preview("fox") {
    EmojiRow(emoji: "🦊", name: "fox")
}

#Preview("penguin") {
    EmojiRow(emoji: "🐧", name: "penguin")
}

用 Group 包含多個 view

如果懶得切換 preview 分頁，我們也可用 Group 包含多個 view，一次觀看多個 view 呈現的樣子。

#Preview {
    Group {
        EmojiRow(emoji: "🦊", name: "fox")
        EmojiRow(emoji: "🐧", name: "penguin")
    }
}
