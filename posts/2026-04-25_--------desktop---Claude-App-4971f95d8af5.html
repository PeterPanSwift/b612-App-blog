如何安裝電腦版(desktop)的 Claude App

系統需求。

  • macOS：macOS 11 (Big Sur) 或更高版本。
  • Windows：Windows 10 或更高版本。

連到 Claude。

Claude
Claude is Anthropic's AI, built for problem solvers. Tackle complex challenges, analyze data, write code, and think…claude.ai

點選左下的箭頭按鈕開啟下載頁面。

點選 Desktop App 的 Download for macOS 或 Download for Windows。

ps: 從以下連結也可直接連到下載頁面。

https://claude.ai/downloads

下載後雙擊檔案安裝 Claude App。

接著啟動 Claude App，點選 Get started。

登入帳號。

大功告成，看到 Claude App 的主畫面 !

值得注意的，當 Windows 沒有打開 Virtual Machine Platform 功能時， Claude 將無法使用 Cowork。

啟動的方法很簡單，滑鼠游標移到左上方 Chat 右邊的 Cowork 按鈕，點選 Virtual Machine Platform 的 Enable。

點選是。

滑鼠游標再次移到 Chat 右邊的 Cowork 按鈕，點選 Restart now 重新開機。

現在 Claude 終於能切換到 Cowork 分頁操作。
