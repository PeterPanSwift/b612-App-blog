我們可以在 GitHub 網頁，GitHub App 和各種知名的 IDE 使用 GitHub Copilot 寫程式。

  • 在 Xcode 使用 GitHub Copilot。
使用 GitHub Copilot for Xcode 幫忙寫程式
最近聽說 GitHub 推出了厲害的 AI 程式碼工具 Copilot，它可以提供不錯的程式碼建議，大幅加快程式的開發速度。medium.com
  • 在 VS Code 使用 GitHub Copilot。
  1. 點選上方 Search 右邊的 AI 聊天按鈕。

2. 登入帳號。

點選 Authorize Visual-Studio-Code。

點選 Allow 或 Open Visual Studio Code 回到 VS Code。

此時畫面將顯示 GitHub Copilot 的歡迎頁面。

3. 點選 AI 聊天按鈕打開 AI 聊天視窗。

現在可以開始在 VS Code 請 AI 寫程式了。從下方左邊數來第 3 個按鈕可切換 Agent / Ask / Plan，建議選擇可直接修改專案程式的 Agent 或 Plan 模式。

從下方左邊數來第 4 個按鈕可選擇不同的 AI model。

若是使用 GitHub Copilot Pro，則可選擇一些更厲害的 model。
