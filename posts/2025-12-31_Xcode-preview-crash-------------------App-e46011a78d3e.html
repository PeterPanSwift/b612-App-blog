Xcode preview crash 時，使用更方便查看錯誤的模擬器測試 App

當我們不小心寫出讓 App crash(閃退) 的程式時，Preview 雖然會貼心地顯示錯誤訊息，但是卻常常無法說出是哪行程式造成閃退。

用以下程式為例，array characters 儲存了我英的英雄名字，點擊按鈕將顯示下一個英雄名字。

struct ContentView: View {
    let characters = ["綠谷出久", "爆豪勝己", "歐爾麥特", "轟焦凍"]
    @State private var index = 0
    
    var body: some View {
        VStack {
            Text(characters[index])
                .font(.largeTitle)
            Button("下一個英雄就是你了") {
                index += 1
            }
            .buttonStyle(.borderedProminent)
        }
    }
}

我們持續點擊按鈕，當名字顯示轟焦凍時再繼續點擊按鈕將造成 App 閃退。

Preview 的上方顯示 Preview crashed，Index out of range，依據此訊息我們猜到八九不離十，應該是 index 超過 array 範圍造成程式閃退。

然而它卻沒提到是哪行程式造成閃退。若想更快找出問題，找出造成閃退的凶手，建議改從模擬器測試 App。

當模擬器的 App 閃退時，Xcode 通常會直接標示出問題的程式。如下圖所示，第 17 行的 Text(characters[index]) 造成 Index out of range。

從下方左邊的 Variables View 區塊還可看到 App 閃退時變數儲存的資料。index 的數值為 4，而 array characters 只有 4 個英雄，因此 index 已經超過存取 characters 成員的最大值 3
