使用 Codex 的 Build iOS Apps plugin 完成 App 的開發和測試

Codex 有許多方便好用的 plugin，其中有個專精開發 iOS App 的 plugin Build iOS Apps，包含 XcodeBuildMCP 和 iOS App 開發常用的各種 skill，像是 swiftui-ui-patterns 和 ios-debugger-agent。

透過 Build iOS Apps plugin 開發有許多好處，比方它的 swiftui-ui-patterns skill 將幫助 AI 寫出更好且新式的 SwiftUI 程式。

plugins/plugins/build-ios-apps/skills/swiftui-ui-patterns/SKILL.md at main · openai/plugins
OpenAI Plugins. Contribute to openai/plugins development by creating an account on GitHub.github.com

AI 原本常會使用舊式的 SwiftUI 寫法，比方使用舊式的 ObservedObject 和 EnvironmentObject。有了 swiftui-ui-patterns skill，AI 將優先使用新式的 Observable 和 Environment 寫法。

當 Codex 結合 Build iOS Apps plugin 後，它將不只是寫程式，它能一條龍完成 App 開發的各種工作，從使用 SwiftUI 製作 App 畫面，debug 修正程式的問題到啟動模擬器測試 App。

以下彼得潘以打地鼠遊戲為例，示範在 Codex 使用 Build iOS Apps plugin 開發 App。

啟動 Codex，點選側邊欄的外掛程式(plugins)。

搜尋 iOS，找到 Build iOS Apps。

安裝 plugin 的方法有兩種，點選 + 或是進入 Build iOS Apps 的介紹頁後點選右上方的加入 Codex。

點選安裝 Build iOS Apps。

現在我們在 Codex 開發 App 時可以請強大的外掛 Build iOS Apps 幫忙了。叫出它的方式有兩種。

  • 從外掛程式選擇 Build iOS Apps。
  • 輸入 @bui 再選擇 Build iOS Apps。

輸入 prompt，請 AI 開發打地鼠遊戲並加入另外繪製的地鼠圖片。

ps: Codex 也可以自動想到使用 Build iOS Apps plugin，不過為了確保它用到 Build iOS Apps plugin，最好還是在 prompt 提醒它。

使用 Build iOS Apps plugin 後，Codex 不只寫出 App 的 Swift 程式，在 assets 加入 AI 生成的地鼠圖，它還親自啟動模擬器試玩打地鼠，驗證遊戲的畫面和功能都是正確的。
