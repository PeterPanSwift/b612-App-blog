Apple Foundation Model 的 ModelManagerError Code=1026

最近在模擬器和 preview 測試 Apple Foundation Model 時，發現 LanguageModelSession respond 一直失敗。

比方我們請 LanguageModelSession 介紹冰島。

import FoundationModels
import Playgrounds

#Playground {
    let session = LanguageModelSession()
    do {
        let response = try await session.respond(to: "介紹冰島")
        print(response.content)
    } catch {
        print(error)
    }
    
}

Console 卻印出以下錯誤訊息。

Error Domain=FoundationModels.LanguageModelSession.GenerationError Code=-1 "(null)" UserInfo={NSMultipleUnderlyingErrorsKey=(
    "Error Domain=ModelManagerServices.ModelManagerError Code=1026 \"(null)\" UserInfo={NSMultipleUnderlyingErrorsKey=(\n)}"
)}

此問題跟版本有關，彼得潘的 macOS 是 26.2，Xcode 是 26.1，因為版本不合造成問題。當彼得潘升級 Xcode 26.2 後，LanguageModelSession 就能正常產生回答了。
