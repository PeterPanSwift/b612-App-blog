修正 Flutter Android App 的 package name com.example 問題

當我們準備將 Flutter 製作的 Android App 上架時，可能會因為 package name 的問題被殘忍地退件。

這是因為 IDE 生成的 Flutter App 專案通常會以 com.example 當 package name 的開頭，然而 com.example 這名字太像是練習的作業，不像正式的 App，因此上傳 App 到 Google Play Console 時將出現下圖的錯誤訊息，You need to use a different package name because com.example is restricted。

為了修正問題，我們必須修改 package name，更新專案裡多個出現 com.example 的地方。

不過一個一個改太辛苦了，以下我們使用方便的套件 change_app_package_name，只要一個指令即可更新 package name。

change_app_package_name | Dart package
Change App Package Name with single command. Update AndroidManifest, build.gradle, MainActivity files & move…pub.dev

使用以下指令安裝套件 change_app_package_name。

flutter pub add -d change_app_package_name

執行以下指令更新 package name，以下我們將 package name 更名為 com.p207.flutter_application_1。

dart run change_app_package_name:main com.p207.flutter_application_1

此時重新生成 App 的 AAB 檔，上傳到 Google Play Console 時再也不會出現 package name 的錯誤訊息。
