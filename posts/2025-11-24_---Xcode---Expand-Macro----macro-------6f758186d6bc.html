利用 Xcode 的 Expand Macro 查看 macro 生成的程式

開發 iOS App 時，我們時常會用到 SDK 定義的 macro，比方 #Preview、#Playground、@Observable、@Generable 等。

如果好奇的話，我們也可透過 Xcode 的 Expand Macro 查看 macro 生成的程式。

比方點擊 #Preview，然後點選 Expand Macro。

  • 方法 1: 從右鍵選單點選 Expand Macro。
  • 方法 2: 從 Quick Actions 點選 Expand Macro。

點選後將展開顯示 macro 生成的程式。

點選 X 可關閉 macro 生成的程式。

以下我們再多看幾個 Expand Macro 的例子。

  • #Playground。
#Playground {
    
}
  • @Observable。
@Observable
class Lover {
    var name = "peter"
    var weight = 60
    var isSingle = false
}
  • @Generable。
@Generable
struct MultipleChoiceQuestion {
    @Guide(description: "包含 emoji")
    let questionText: String
    @Guide(.count(3))
    let options: [String]
    let correctAnswerIndex: Int
}
