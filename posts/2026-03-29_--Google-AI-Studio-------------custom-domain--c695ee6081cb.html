將網站部署到 Cloudflare 並綁定自訂網域(custom domain)

將網站的專案程式上傳到 GitHub

連到 Google AI Studio 的專案頁面，點擊右上方的 Settings 按鈕。

點擊 Sign in to GitHub to continue，將專案上傳到 GitHub。

點擊連結取得專案的 GitHub 網址。

將 GitHub 上的專案部署到 Cloudflare

連到 Cloudflare，登入帳號。

Connect, protect, and build everywhere
Make employees, applications and networks faster and more secure everywhere, while reducing complexity and cost.www.cloudflare.com

點擊 Add > Pages。

點擊 Import an existing Git repository 的 Get started。

選擇對應的 GitHub 帳號和剛剛上傳的 GitHub 專案，然後點擊 Begin setup。

Framework preset 選擇網站採用的技術框架，在此彼得潘選擇 React (Vite)，然後點選 Save and Deploy。

專案部署中。

專案完成部署。

現在我們可從 Cloudflare 生成的網址 https://p207-app-qa-planet.pages.dev 連到網站。

但是別高興得太早，點擊 Google 登入時出現了錯誤。

問題出在網站的 Google 登入透過 Firebase Authentication，因此 Firebase 會檢查網址，只有它授權的網域能夠登入。

以下我們連到網站程式對應的 Firebase 專案頁面，然後點選安全性 > Authentication。

切換到設定的授權網域分頁，點擊新增網域。

輸入網址後按新增。

現在網站終於能順利 Google 登入。

將網站綁定自訂網域

我們還差最重要的最後一步，做了那麼多，全為了網站能綁定自訂網域。

設定自訂網域有兩個入口。

  • 入口 1: 點擊專案完成部署時出現的按鈕 Add custom domain。
  • 入口 2: 連到剛剛建立的 Cloudflare page，切換到 Custom domains 分頁，點擊 Set up a custom domain。

輸入彼得潘想要的自訂網域 qa.p207.app，然後點擊 Continue。

qa.p207.app 的 DNS 原本就透過 cloudflare 管理，因此我們不用再做其它設定，點擊 Activate domain 即可啟用。

若網域的 DNS 透過其它平台管理，則須點擊 Begin DNS transfer 進行相關設定。

自訂網域後，網站要經過幾分鐘到 48 小時的等待才能成功連線。

在等待的時候，別忘了將自訂網域加到 Firebase 的授權網域，讓 Google 登入正常運作。

彼得潘運氣不錯，經過不到十分鐘狀態就變成 Active。

現在我們可以從 https://qa.p207.app 連到 p207 App 問答星球。
