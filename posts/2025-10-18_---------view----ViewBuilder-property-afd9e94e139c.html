宣告方便接收多個 view 的 @ViewBuilder property

設計 SwiftUI App 時，VStack、HStack、ScrollView 等容器元件可以方便地以 closure { } 傳入多個 view，例如以下例子。

VStack {
    Text("🐨")
    Text("🦊")
    Text("🐰")
}

VStack 能在 closure { } 傳入多個 view 跟參數 content 前的 @ViewBuilder 有關。

init(
    alignment: HorizontalAlignment = .center,
    spacing: CGFloat? = nil,
    @ViewBuilder content: () -> Content
)

我們以 struct 自訂的 SwiftUI View 只要宣告 @ViewBuilder property 即可擁有類似的功能。

以下我們實作一個漸層精靈卡片 SpriteGradientCard 說明。

首先我們宣告型別為 Content 的屬性 content。

struct SpriteGradientCard<Content: View>: View {
    var content: Content

    var body: some View {
        ZStack {
            MeshGradient(
                width: 2,
                height: 2,
                points: [.init(0, 0), .init(1, 0), .init(0, 1), .init(1, 1)],
                colors: [.red, .blue, .green, .yellow]
            )
            .blur(radius: 80)
            .opacity(0.9)

            content
        }
        .overlay(alignment: .topLeading) {
            Image(.sprite)
                .resizable()
                .scaledToFit()
                .frame(width: 50)
                .rotationEffect(.degrees(24))
                .shadow(color: .white.opacity(0.9), radius: 12)
                .padding()
        }
        .clipShape(UnevenRoundedRectangle(topLeadingRadius: 50, bottomTrailingRadius: 100))
        .frame(width: 300, height: 300)
        .shadow(radius: 2)
    }
}

由於型別 Content 遵從 protocol View，我們可傳入任何一種 view 當卡片的內容，以下我們傳入 Text。

struct ContentView: View {
    var body: some View {
        SpriteGradientCard(
            content: Text("冰島極光小精靈")
                .font(.largeTitle)
                .foregroundStyle(.white)
        )
    }
}

不過此寫法只能傳入一個 view，因此我們再試試第二種寫法，將 content 的型別改成 function 型別 () -> Content。

struct SpriteGradientCard<Content: View>: View {
    var content: () -> Content

    var body: some View {
        ZStack {
            MeshGradient(
                width: 2,
                height: 2,
                points: [.init(0, 0), .init(1, 0), .init(0, 1), .init(1, 1)],
                colors: [.red, .blue, .green, .yellow]
            )
            .blur(radius: 80)
            .opacity(0.9)

            content()
        }
        .overlay(alignment: .topLeading) {
            Image(.sprite)
                .resizable()
                .scaledToFit()
                .frame(width: 50)
                .rotationEffect(.degrees(24))
                .shadow(color: .white.opacity(0.9), radius: 12)
                .padding()
        }
        .clipShape(UnevenRoundedRectangle(topLeadingRadius: 50, bottomTrailingRadius: 100))
        .frame(width: 300, height: 300)
        .shadow(radius: 2)
    }
}

此時我們可傳入 closure，在 { } 裡傳入卡片的內容，而且還可在 closure 進行一些運算。

struct ContentView: View {
    var body: some View {
        SpriteGradientCard {
            let textColor: Color = [.white, .red, .yellow, .green, .blue].randomElement()!
            return Text("冰島極光小精靈")
                .font(.largeTitle)
                .foregroundStyle(textColor)
        }
    }
}

不過此時我們一樣無法回傳多個元件，以下包含 Circle & Text 時將出現錯誤。

最後我們在 content 前加上 @ViewBuilder。

struct SpriteGradientCard<Content: View>: View {
    @ViewBuilder var content: () -> Content

    var body: some View {
        ZStack {
            MeshGradient(
                width: 2,
                height: 2,
                points: [.init(0, 0), .init(1, 0), .init(0, 1), .init(1, 1)],
                colors: [.red, .blue, .green, .yellow]
            )
            .blur(radius: 80)
            .opacity(0.9)

            content()
        }
        .overlay(alignment: .topLeading) {
            Image(.sprite)
                .resizable()
                .scaledToFit()
                .frame(width: 50)
                .rotationEffect(.degrees(24))
                .shadow(color: .white.opacity(0.9), radius: 12)
                .padding()
        }
        .clipShape(
            UnevenRoundedRectangle(
                topLeadingRadius: 50,
                bottomTrailingRadius: 100
            )
        )
        .frame(width: 300, height: 300)
        .shadow(radius: 2)

    }
}

現在 closure 裡可以像 VStack & HStack 一樣生成多個 view 了。

struct ContentView: View {
    var body: some View {
        SpriteGradientCard {
            let textColor: Color = [.white, .red, .yellow,  .blue].randomElement()!
            Circle()
                .stroke(.green.gradient, lineWidth: 10)
                .padding(20)
            Text("冰島極光小精靈")
                .font(.largeTitle)
                .foregroundStyle(textColor)
        }
    }
}

One more thing: 搭配 @ViewBuilder 的 computed property & function

@ViewBuilder 也可以加在 computed property & function，實現回傳多個 view 的功能。

  • computed property。
struct ContentView: View {
    var body: some View {
        VStack {
            emojiTexts
        }
    }
    
    @ViewBuilder var emojiTexts: some View {
        Text("🦊")
        Text("🌹")
        Text("🤴")
    }
}
  • function。
struct ContentView: View {
    var body: some View {
        VStack {
            makeEmojiTexts()
        }
    }
    
    @ViewBuilder
    func makeEmojiTexts() -> some View {
        Text("🦊")
        Text("🌹")
        Text("🤴")
    }
}

computed property & function 加上 ＠ViewBuilder 除了帶來回傳多個 view 的好處，還享有以下好處。

  • 可回傳不同型別的 view。

沒有 ViewBuilder。

加上 ViewBuilder。

@ViewBuilder var star: some View {
    if Bool.random() {
        Text("⭐️")
    } else {
        Image(systemName: "star")
    }
}
  • 只有一個 view 時可省略 return。

沒有 ViewBuilder。

加上 ViewBuilder。

@ViewBuilder var animal: some View {
    let animal = ["🦊", "🐨", "🐧"].randomElement()!
    Image(systemName: animal)
}
