將自訂的 SwiftUI view & modifier 加到 Views library & Modifier library

開發 SwiftUI App 時，我們可以打開 Library window，從它的 Views library 頁面拖曳加入元件，省下手打程式的辛苦。

將自訂的 SwiftUI view & modifier 加到 Views library & Modifiers library

開發 SwiftUI App 時，除了手打程式，我們也可以打開 Library window，從 Views library & Modifiers library 頁面加入 view & modifier。

Views library & Modifiers library 裡都是 SwiftUI 內建的元件，有沒有可能加入我們自己發明的元件呢 ?

當然可以，我們可以利用 LibraryContentProvider 實現以下功能。

  • 將自訂的 SwiftUI view 加到 Views library。
  • 將自訂的 SwiftUI modifier 加到 Modifiers library。

將自訂的 SwiftUI view 加到 Views library

  • 新增檔案，定義美麗的 AppleView。
import SwiftUI

struct AppleView: View {
    var body: some View {
        Image(systemName: "apple.logo")
            .resizable()
            .scaledToFit()
            .shadow(radius: 10)
            .padding()
            .background(.orange.gradient)
    }
}

#Preview {
    AppleView()
}
  • 點選 Xcode menu 的 Editor > Create Library Item。

點選 AppleView.swift 後，點選 Xcode menu 的 Editor > Create Library Item。

此時將產生遵從 protocol LibraryContentProvider 的型別 Previews_AppleView_LibraryContent。

將自訂的 view 加到 library 的關鍵在於 LibraryContentProvider，遵從 protocol LibraryContentProvider 時，變數 views 的內容將出現在 Views library 裡。

views 的型別為 [LibraryItem]，因此我們可以回傳多個 LibraryItem，一次加入多個元件到 Views library。當我們將 views 的內容設為 LibraryItem(AppleView()) 時，AppleView 將出現在 library 裡。

struct Previews_AppleView_LibraryContent: LibraryContentProvider {
    var views: [LibraryItem] {
        LibraryItem(AppleView())
    }
}

如下圖所示，Apple View 出現了 ! 隸屬於專案名 Demo — Other 分類下，表示它是專案 Demo 裡自訂的 view。

我們也可以產生多個 LibraryItem，例如以下例子會將 AppleView & OrangeView 加到 Views library。

struct Previews_AppleView_LibraryContent: LibraryContentProvider {
    var views: [LibraryItem] {
        LibraryItem(AppleView())
        LibraryItem(OrangeView())
    }
}

等等，views 的型別不是 [LibraryItem] 嗎 ? 為什麼我們產生 array 時不用寫 [ ] 呢 ? 這和背後 views 宣告前的 LibraryContentBuilder 有關，有興趣的朋友可以進一步查詢相關說明。

預設只會出現在自己專案的 library

當我們開啟別的專案，在 Views library 是看不到 Apple View 的，因為它只會出現在自己專案的 library。若想要自訂的 view 在各個專案的 library 都能現身，則需搭配 Swift Package，相關說明可參考以下連結。

自訂 library 裡元件的名字

library 裡元件預設的名字跟元件的型別有關，不喜歡的話，我們也可設定它的名字，在生成 LibraryItem 時於參數 title 傳入名字。

struct Previews_AppleView_LibraryContent: LibraryContentProvider {
    var views: [LibraryItem] {
        LibraryItem(AppleView(), title: "無與倫比的🍎")
    }
}

自訂 library 裡元件的類別

我們可將 library 裡自訂的元件分類，方便之後尋找。在生成 LibraryItem 時於參數 category 傳入類別，有 effect，layout，control & other 四種選擇。

struct Previews_AppleView_LibraryContent: LibraryContentProvider {
    var views: [LibraryItem] {
        LibraryItem(AppleView(), title: "無與倫比的🍎", category: .control)
    }
}

將自訂的 SwiftUI modifier 加到 Modifiers library

加入 modifier 的方法跟加入 view 類似，一樣是定義尊從 LibraryContentProvider 的型別，只是定義的內容從 views 改成 function modifiers(base:)。

以下我們以自訂的 modifier SongTextViewModifier 為例說明。

struct SongTextViewModifier: ViewModifier {
    let size: CGFloat

    func body(content: Content) -> some View {
        content
            .font(.system(size: size, weight: .bold))
            .foregroundStyle(.orange)
            .shadow(radius: 20)
    }
}

extension View {
    func songTextStyle(size: CGFloat) -> some View {
        modifier(SongTextViewModifier(size: size))
    }
}

定義尊從 LibraryContentProvider 的型別，function modifiers(base:) 回傳 LibraryItem。

struct Previews_AppleView_LibraryContent: LibraryContentProvider {
    func modifiers(base: any View) -> [LibraryItem] {
        LibraryItem(base.songTextStyle(size: 20))
    }
}
