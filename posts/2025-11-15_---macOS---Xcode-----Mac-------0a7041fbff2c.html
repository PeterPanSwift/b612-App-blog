查詢 macOS & Xcode 版本和 Mac 機型的方法

查詢 macOS 版本

  • 從關於這台 Mac。

點選左上的 Apple Icon，點選關於這台 Mac。

  • 從終端機輸入 sw_vers。

打開終端機(Terminal) App。

輸入 sw_vers。

範例結果。

ProductName:  macOS
ProductVersion:  27.0
BuildVersion:  26A5353q
  • 從 Spotlight 點選關於這台 Mac。
  • 從設定的一般 > 關於頁面。

查詢 Xcode 版本

  • 從 Xcode menu 點選 Xcode > About Xcode。
  • 從 Terminal 輸入 xcodebuild -version。

範例結果。

Xcode 27.0
Build version 27A5194q
  • 從 Xcode 啟動後顯示的視窗。

查詢 Mac 機型

  • 從關於這台 Mac。

點選左上的 Apple Icon，點選關於這台 Mac。

  • 從 Terminal 輸入 system_profiler SPHardwareDataType | grep "Chip"。

範例結果。

Chip: Apple M3 Max

同時查詢 macOS & Xcode 版本和 Mac 機型

從 Terminal 輸入 sw_vers && xcodebuild -version && system_profiler SPHardwareDataType | grep "Chip"。

範例結果。

ProductName:  macOS
ProductVersion:  27.0
BuildVersion:  26A5353q
Xcode 27.0
Build version 27A5194q
2026-06-09 17:24:49.599 system_profiler[37072:342756] hw.cpufamily: 0x72015832
      Chip: Apple M3 Max
