啟動 Push Notifications

Push Notifications 可以發送推播給 iOS & Android，讓我們拋開 Android，只專注在 iOS 吧。

選擇 Environment 為 Sandbox 或 Production

Apple 的推播有分測試環境(Sandbox)和正式環境(Production)，它和 APNs server 有關。APNs server 有兩種，development 和 distribution。Development server 的網址是 api.development.push.apple.com:443，我們平常從 Xcode 開發裝到手機的 App，收到的推播來自 development server。而 distribution server 的網址為 api.push.apple.com:443，我們從 App Store, TestFlight, AdHoc 安裝的 App，則從 distribution server 接收推播。

因此若想測試從 Xcode 安裝的 App 是否收到推播，必須選擇 Sandbox。若想讓 App Store, TestFlight, AdHoc 安裝的 App 收到推播，必須選擇 Production。
