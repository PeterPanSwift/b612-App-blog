Xcode 的 GitHub 帳號設定

打開 Settings 視窗

從 Quick Actions 輸入框打開 Settings。

新增帳號

切換到 Source Control 頁面，點選 Add Account。

設定 GitHub 帳號

在帳號設定的選單裡，我們有多種不同的帳號可選擇，在此我們選擇 GitHub。

輸入 GitHub 的 account & token。等等，我們只知道密碼，不知道 token 呀。

請參考以下連結取得 token。

取得 GitHub token 的兩種方法
方法 1: 透過 GitHub CLI。apppeterpan.medium.com

然後回到剛剛 Xcode 的畫面輸入 account & token，點選 Sign In 登入。

大功告成 ! Accounts 下順利出現 GitHub 帳號。
