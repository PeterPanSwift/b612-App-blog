使用 Google AI Studio 開發 Kotlin Android App

Google AI Studio 除了開發網站，現在也能開發 Kotlin Android App 了。以下彼得潘以可愛的打企鵝為例，一步步介紹開發 Android App 的相關步驟。

開發 Android App

連到 Google AI Studio。

Google AI Studio
The fastest path from prompt to production with Geminiaistudio.google.com

點選 prompt 輸入框下方的 Build an Android app。

輸入 prompt，請 AI 另外繪製 App 需要的圖片。

打地鼠 App，角色改成事先用 AI 繪製的可愛企鵝圖片

可按 tab 輸入 AI 建議的功能。

AI 開發程式前會先詢問我們想要的設計風格，挑好喜歡的風格後點選 Select this design。

AI 成功完成可愛的打企鵝 App。

通常 AI 初次完成的版本都會有些問題，它會自動列出找到的錯誤，點選 Fix 即可叫它修正。

AI 成功修正問題，右邊的 Preview 頁面出現可操作的 Android App。

切到 Code 分頁可瀏覽編輯 App 的 kotlin 程式。

將 App 裝到 Android 手機

點選 Preview 頁面右上方的 Install 將 App 裝到 Android 手機。

安裝前記得參考網頁的說明先開啟 Android 手機的 developer mode 和 USB debugging，然後將手機接線連到電腦。

點選 Install via USB 安裝。

選擇手機後點選連線。

發布 App

點選右上方的 Publish 可以邀請朋友測試 App 跟將 App 上架到 Play Store。

點選 Publish app for testing。

朋友可從下圖的連結跟 QR Code 下載安裝 App。

ps: 只有帳號被加入 internal test 名單的人能夠安裝。
