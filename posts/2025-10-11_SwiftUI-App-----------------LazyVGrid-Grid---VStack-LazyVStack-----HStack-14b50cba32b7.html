SwiftUI App 實現格子狀照片牆的三種做法 — LazyVGrid、Grid & VStack(LazyVStack) 搭配 HStack

開發 SwiftUI App 時，實現格子狀照片牆有三種做法，LazyVGrid、Grid & VStack(LazyVStack) 搭配 HStack。以下彼得潘以 AI 生成的桌球少年圖片為例示範這三種寫法。

LazyVGrid

import SwiftUI

struct LazyGridGalleryView: View {
    let imageNames = [
        "乒乓少年_夕陽綠拍凝視",
        "乒乓少年_夕陽綠拍記錄",
        "乒乓少年_夜間專注筆電",
        "乒乓少年_室內灰牆球桌",
        "乒乓少年_教室紅拍專注",
        "乒乓少年_條紋連帽紅拍",
        "乒乓少年_橘衣藍拍晨光",
        "乒乓少年_灰衣紅拍晨光",
        "乒乓少年_眼鏡制服激動",
        "乒乓少年_眼鏡書房筆記"
    ]
    let columns = Array(repeating: GridItem(), count: 2)

    var body: some View {
        ScrollView {
            LazyVGrid(columns: columns) {
                ForEach(imageNames, id: \.self) { imageName in
                    Image(imageName)
                        .resizable()
                        .scaledToFill()
                        .frame(height: 250)
                        .clipped()
                }
            }
        }
    }
}

利用 GridItem 的數量控制照片牆有幾個 column，對 LazyVGrid 不熟的朋友可參考以下連結。

格子狀排列的 LazyVGrid & LazyHGrid
新版的 SwiftUI 推出了專門呈現格子狀排版的 LazyVGrid & LazyHGrid，實現類似 IG 的照片牆頁面變得容易許多。接下來彼得潘將以小時候看的亞森羅蘋為例，一步步介紹 LazyVGrid & LazyHGrid。medium.com

Grid

import SwiftUI

struct GridGalleryView: View {
    let columns = 2
    let imageNames = [
        "乒乓少年_夕陽綠拍凝視",
        "乒乓少年_夕陽綠拍記錄",
        "乒乓少年_夜間專注筆電",
        "乒乓少年_室內灰牆球桌",
        "乒乓少年_教室紅拍專注",
        "乒乓少年_條紋連帽紅拍",
        "乒乓少年_橘衣藍拍晨光",
        "乒乓少年_灰衣紅拍晨光",
        "乒乓少年_眼鏡制服激動",
        "乒乓少年_眼鏡書房筆記"
    ]
    
    var body: some View {
        ScrollView {
            Grid(horizontalSpacing: 12, verticalSpacing: 12) {
                let rows = (imageNames.count + columns - 1) / columns
                ForEach(0..<rows, id: \.self) { row in
                    GridRow {
                        ForEach(0..<columns, id: \.self) { column in
                            let index = row * columns + column
                            if index < imageNames.count {
                                Image(imageNames[index])
                                    .resizable()
                                    .scaledToFill()
                                    .frame(height: 250)
                                    .clipped()
                            }
                        }
                    }
                }
            }
        }
    }
}

利用 (imageNames.count + columns — 1) / columns 計算 GridRow 的數量，相關數學的說明可參考以下連結。

數學和程式的經典分組問題(Ceiling Division)
medium.com

剛剛程式的 ForEach(0..<rows, id: \.self) 和 ForEach(0..<columns, id: \.self) 使用數字當 id，不過此寫法在牽扯到動畫或資料變動時可能會有問題。

使用 array 的 index 當 ForEach id 的特別問題
當我們用 SwiftUI 的 ForEach 顯示 array 的內容時，通常需要指定區分成員的 id。medium.com

因此我們也可採用另一種寫法，搭配 package Swift Algorithms 的 chunks(ofCount:) 將資料分組，如此也省去自己寫程式分組的麻煩。

import Algorithms
import SwiftUI

struct GridGalleryView: View {
    let columns = 2
    let imageNames = [
        "乒乓少年_夕陽綠拍凝視",
        "乒乓少年_夕陽綠拍記錄",
        "乒乓少年_夜間專注筆電",
        "乒乓少年_室內灰牆球桌",
        "乒乓少年_教室紅拍專注",
        "乒乓少年_條紋連帽紅拍",
        "乒乓少年_橘衣藍拍晨光",
        "乒乓少年_灰衣紅拍晨光",
        "乒乓少年_眼鏡制服激動",
        "乒乓少年_眼鏡書房筆記",
    ]

    var body: some View {
        ScrollView {
            Grid(horizontalSpacing: 12, verticalSpacing: 12) {
                let chunked = imageNames.chunks(ofCount: 2)
                ForEach(chunked, id: \.self) { row in
                    GridRow {
                        ForEach(row, id: \.self) { name in
                            Image(name)
                                .resizable()
                                .scaledToFill()
                                .frame(height: 250)
                                .clipped()
                        }
                    }
                }
            }
        }
    }
}
