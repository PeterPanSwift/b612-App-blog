將網頁版的 Flutter App 部署到 Firebase

透過 Flutter 我們可以開發跨平台 App，它不只能運行在 iOS & Android 上，也能變成透過瀏覽器存取的網頁。

為了讓任何人皆能從瀏覽器存取 Flutter App，我們必須將 Flutter App 部署到伺服器上。令人開心的，目前有許多佛心的平台免費讓我們部署網頁，比方 GitHub Pages & Firebase Hosting。

以下彼得潘以 Firebase Hosting 為例，一步步介紹如何將 Flutter App 部署到 Firebase。

  • 安裝 Firebase CLI 和登入 Firebase。
  • 打開 Firebase webframeworks 的功能。
  • 初始化 Firebase Hosting 服務。
  • 將網頁版的 Flutter App 部署到 Firebase。
  • 修改程式更新網頁。
  • 將新專案的 Flutter App 部署到 Firebase。

安裝 Firebase CLI 和登入 Firebase

我們將在 Terminal 透過 Firebase CLI 執行 Firebase 的相關指令，請參考以下連結安裝 Firebase CLI 和登入 Firebase。

方便管理 Firebase 的 Firebase CLI(Command Line Interface)
透過 Firebase CLI 我們可以方便地從 Terminal 下指令管理 Firebase 專案和部署網站。以下彼得潘簡單介紹如何在 macOS & Windows 安裝 Firebase CLI。medium.com

打開 Firebase webframeworks 的功能

在 Terminal 輸入以下指令。

firebase experiments:enable webframeworks

結果。

Enabled experiment webframeworks

初始化 Firebase Hosting 服務

為了將網頁部署到 Firebase 我們必須先初始化 Firebase Hosting 服務，在剛剛開啟 Flutter 專案的 IDE Terminal 輸入以下指令。

firebase init hosting

將網頁版的 Flutter App 部署到 Firebase

在 IDE 的 Terminal 輸入以下指令，生成網頁版的 Flutter App 並將它部署到 Firebase。

firebase deploy

修改程式更新網頁

之後若須修改程式時，請在 Terminal 輸入以下指令重新生成網頁，部署到 Firebase。

firebase deploy

將新專案的 Flutter App 部署到 Firebase

前面介紹的很多步驟只有第一次要做，之後若有新專案要部署到 Firebase，只須輸入以下兩個指令，執行初始化 Firebase Hosting 和部署到 Firebase。

firebase init hosting
firebase deploy
