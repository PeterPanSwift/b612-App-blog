請 AI 生成可辦識的 QR Code 圖片

最近 OpenAI 推出 ChatGPT Images 2.0，搭配 Thinking 模式的 ChatGPT 終於能生成可辨識的 QR Code 圖片。

Introducing ChatGPT Images 2.0
ChatGPT Images 2.0 introduces a state-of-the-art image generation model with improved text rendering, multilingual…openai.com

ps: 非 Thinking 模式的 ChatGPT 跟 Gemini 目前還無法生成可辨識的 QR Code。

  • 範例 1。

生成以下網址的 QR Code，搭配可愛的北極狐，QR Code 必須可以辨識。

https://swiftuip207.mystrikingly.com

  • 範例 2。

生成以下網址的 QR Code，QR Code 中間顯示可愛的北極狐，QR Code 必須可以辨識。

https://swiftuip207.mystrikingly.com

  • 範例 3。

生成 QR Code，規格如下。

1. 網址是 https://swiftuip207.mystrikingly.com

2. 顏色是可愛的漸層色

3. QR Code 中間顯示可愛的北極狐

4. QR Code 必須可以辨識
