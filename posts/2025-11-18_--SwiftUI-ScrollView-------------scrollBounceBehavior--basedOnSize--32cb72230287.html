讓 SwiftUI ScrollView 依據內容決定是否捲動的 scrollBounceBehavior(.basedOnSize)

捲動的 SwiftUI ScrollView 常被應用於呈現大量的內容，內容再多也塞得下，例如以下呈現金庸小說名句的 JinYongQuoteView。

struct JinYongQuoteView: View {
    let quote: String
    
    var body: some View {
        ZStack {
            Image(.background)
                .resizable()
                .scaledToFill()
                .containerRelativeFrame(.horizontal)
                .ignoresSafeArea()
            ScrollView(.vertical) {
                Text(quote)
                    .font(.system(size: 80))
                    .frame(maxWidth: .infinity)
            }
        }
    }
}

#Preview("神鵰俠侶") {
    JinYongQuoteView(quote: """
        問世間，
        情是何物，
        直教生死相許。
        天南地北雙飛客，
        老翅幾回寒暑。
        歡樂趣，
        離別苦，
        就中更有癡兒女。
        君應有語，
        渺萬里層雲，
        千山暮雪，
        隻影為誰去。
        """)
}

問世間，情是何物字數滿多的，的確需要捲動，然而換成倚天屠龍記的名句時捲動卻顯得多餘。

#Preview("倚天屠龍記") {
    JinYongQuoteView(quote: """
        武林至尊，
        寶刀屠龍。
        號令天下，
        莫敢不從。
        倚天不出，
        誰與爭鋒?
        """)
}

此時我們可在 ScrollView 呼叫 scrollBounceBehavior(.basedOnSize)，它將依據內容決定是否捲動，只有當內容超過 ScrollView 本身的大小時才能捲動。

struct JinYongQuoteView: View {
    let quote: String
    
    var body: some View {
        ZStack {
            Image(.background)
                .resizable()
                .scaledToFill()
                .containerRelativeFrame(.horizontal)
                .ignoresSafeArea()
            ScrollView(.vertical) {
                Text(quote)
                    .font(.system(size: 80))
                    .frame(maxWidth: .infinity)
            }
            .scrollBounceBehavior(.basedOnSize)
        }
    }
}
