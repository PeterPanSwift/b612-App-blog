vibe coding #49 — 請 AI 使用 Cloudflare 開發具備登入和 CRUD 功能的 API & API 文件

開發 iOS App 時，我們常常希望 App 能串接網路 API，具有帳密登入和雲端存取資料的功能。然而當我們只會開發 App，不會後台技術時，過去通常只有幾種選擇。

  • 跟後台工程師合作。
  • 使用 Firebase、Supabase 等現成的後台(BaaS)。
  • 把試算表當簡易後台資料庫，比方 Google Sheets、Airtable。

現在有了 AI 的幫忙，我們也可以嘗試自己開發後台。AI 就像我們的後台工程師，他不只幫忙建立 REST API，而且還會順便生成可測試的 API 文件。

以下彼得潘以開發訂飲料 App 為例，示範如何請 AI 使用 Cloudflare 開發具備帳密登入和資料 CRUD 功能的 API，並生成可互動測試的 API 文件。

  • 後台技術架構。
  • 可不可飲料 menu。
  • 請 AI 開發 API。
  • 請 AI 生成 API 文件。
  • 請 AI 依據 OpenAPI 規格開發 SwiftUI App。

後台技術架構

當我們請 AI 使用 Cloudflare 開發 API 時，可以採用以下技術組合。

  • 使用 Cloudflare Workers 建置後端 API。
  • 使用 Cloudflare D1 當關聯式資料庫。
  • 使用 Cloudflare R2 儲存圖檔。
  • 以 OpenAPI 3.1 定義 API 規格，再透過 Scalar API Reference 產生 API 文件。

可不可飲料 menu

接下來彼得潘將以自己常喝的可不可飲料為例，請 AI 參考可不可的 menu，將飲料的相關資訊和照片存到 Cloudflare。

請 AI 開發 API

以下彼得潘使用 ChatGPT Codex 的 5.6 Sol high 開發，輸入以下 prompt。

開發訂飲料 App 的 API，請先從以下網址抓取 menu，
包含名字、價錢、照片、簡介、詳細介紹、分類，資料存在 cloudflare
https://kebuke.com/menu

AI 成功抓取網頁的資料，將飲料的相關資訊存入 Cloudflare D1。 不過飲料圖片的部分，AI 改成將圖片網址存到 D1，沒有將圖片存到 Cloudflare R2，因為 R2 必須先啟用並設定付款資訊才能存檔。

有了完整的飲料資料，終於可以進入重頭戲，請 AI 開發 API ！

主要的 prompt 有兩個。

開發帳密登入和 CRUD 訂飲料的 API
加入分組 API，可建立群組，在群組裡訂飲料

請 AI 生成 API 文件

請製作並部署漂亮可互動測試的 API 文件

AI 以 OpenAPI 3.1 定義 API 規格(openapi.json)，再透過 Scalar API Reference 產生 API 文件，然後將它們部署在 Cloudflare。

AI 生成的 API 文件十分詳細，只有一個小小缺點，畫面有點單調。

因此彼得潘請它添加可愛風跟拿著桌球拍的北極狐。

變成可愛又可動的飲料 API 文件。

API 範例可切換各種程式語言，比方世界上最棒的 Swift。

或是最適合說明 API 的 curl。

API 文件不只是漂亮的花瓶，還可以直接測試 API 的串接。
