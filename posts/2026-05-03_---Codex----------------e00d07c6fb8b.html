使用 Codex 加入在螢幕陪伴我們的角落寵物

以下彼得潘一步步示範 Codex 寵物功能的相關操作。

  • 喚醒或收起寵物。
  • 和寵物互動。
  • 選擇寵物。
  • 自製寵物。

喚醒或收起寵物

在 Codex 的輸入框打 /，選擇寵物即可喚醒或收起寵物。

螢幕的角落出現寵物了 !

和寵物互動

我們可以自由地拖曳移動寵物，點選寵物則會打開 Codex 視窗。牠將一直陪著我們，不管我們切到哪個 App 視窗，牠都會在。

當游標停在寵物上出現 Ｌ型圖示時，拖曳移動可將它放大縮小。

當 Codex 正在做事時，寵物也會顯示相關的進度訊息。如下圖所示，當彼得潘正在瀏覽網頁時依然可從寵物的訊息了解 Codex 的進度。

當 Codex 完成工作時，寵物的訊息也會更新，右上方的圖案變成綠色的勾勾。

點選寵物打開 Codex，可愛的北極狐圖片果然畫好了。

Codex 生成的回答訊息也會顯示在對話框。

點選右上方的箭頭可展開訊息。

點選右下方的回覆可輸入 prompt。

在寵物身上按右鍵可點選關閉寵物。

選擇寵物

打開 Codex 的 Settings 頁面。

切換到外觀分頁，找到寵物區塊。

從寵物清單選擇寵物，Codex 內建許多可愛的寵物。

自製寵物

除了選擇內建的寵物，我們也可以利用 AI 的生圖功能自製寵物。

ps: 訂閱 ChatGPT Plus 以上的帳號才能直接生圖，其它則須另外申請 API Key 和花錢才能生圖。

為了自製寵物，請先學習新技能(skill) hatch-pet。

ps: hatch 是孵化的意思，有了 hatch-pet 就能孵化寵物。

輸入 $ 選擇使用的技能，在此我們選擇 Skill Installer。

輸入 hatch-pet。

學會新技能 hatch-pet，遵照指令重新啟動 Codex。

現在我們可以孵化寵物了，輸入 $ 選擇 Hatch Pet 。

做個白色北極狐寵物。

Codex 開始生成圖片孵化寵物，寵物需要多張圖片實現多樣的動作表情，請耐心等待孵化的結果。

孵化出超可愛的白色北極狐 Yuki !

從 Yuki 的 spritesheet.webp 可看到北極狐各種可愛的動作表情。

從寵物清單的自訂寵物區塊選擇 Yuki，

有了北極狐的陪伴，彼得潘使用 Xcode 寫程式開發 App 的效率瞬間增加 100 倍 !

彼得潘看著統一獅的棒球比賽時，北極狐也乖乖地坐在打擊區的格子。

我們也可以提供設計圖給 Codex 孵化寵物，比方請 Codex 參考彼得潘的 Q 版圖片。

附上圖片，請 Codex 參考圖片設計。

Codex 孵化出 Coder Kid。

各式各樣的彼得潘，連哭泣的彼得潘也有。

選擇 Coder Kid。

帥氣的 Coder Kid 陪著彼得潘看統一獅的棒球比賽。
