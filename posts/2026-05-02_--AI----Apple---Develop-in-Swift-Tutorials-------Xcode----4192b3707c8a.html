請 AI 讀取 Apple 的 Develop in Swift Tutorials 生成完整的 Xcode 專案

Apple 的 Develop in Swift Tutorials 包含許多優質的 iOS App 開發教學，可惜它沒有提供完整的 Xcode 專案下載連結，因此若想取得完整的程式，我們只能辛苦地一個個選取程式再複製貼上。

Design an interface | Apple Developer Documentation
Practice putting views where you want them and inspecting their size by building two onboarding screens for an iOS app…developer.apple.com

不過最近彼得潘透過 AI 找到懶人方法了。

原來 Develop in Swift Tutorials 的範例可利用 API 抓取相關程式的 json。

https://developer.apple.com/tutorials/data/tutorials/教學路徑.json

現在我們只要下個 prompt 即可叫 AI 生成範例的完整 Xcode 專案。

以下彼得潘使用 Codex 示範生成 Design an interface 的 Xcode 專案。

依據網頁內容生成完整的 Xcode 專案
https://developer.apple.com/tutorials/develop-in-swift/design-an-interface
網頁的程式範例來自以下 API 
https://developer.apple.com/tutorials/data/tutorials/develop-in-swift/design-an-interface.json

AI 成功生成範例的相關檔案。

打開 Xcode，畫面功能跟範例的教學一模一樣。
