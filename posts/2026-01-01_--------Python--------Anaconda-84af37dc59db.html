方便初學者學習 Python 和資料處理的 Anaconda

初學者剛開始學習 Python 和資料處理時，常常會在自己的電腦準備開發環境，花許多時間下載安裝相關的軟體。

現在有了 Anaconda，一切變得輕鬆許多。只要下載安裝 Anaconda(大蟒蛇) 即可讓電腦擁有 Python 和許多好用的套件和開發工具，比方資料處理的 numpy、pandas、matplotlib，開發 Python 程式的 Jupyter Notebook、Spyder。

安裝 Anaconda

連到 Anaconda 的 Download 頁面。

點選 Get Started。

註冊帳號。

選擇下載的平台。

Mac 版。

Windows 版。

以下彼得潘點選 Mac Anaconda Distribution 的 64-Bit (Apple silicon) Graphical Installer。

雙擊 pkg 檔安裝。

安裝好 Anaconda 後，我們的電腦不僅擁有 Python，還得到了許多好用的開發軟體。以下我們以適合初學者撰寫 Python 程式的 Jupyter Notebook 為例，介紹啟動 Jupyter Notebook 的兩種方法。

  • 從 Anaconda Navigator 啟動 Jupyter Notebook。
  • 從 Mac 的 Terminal 或 Windows 的 Anaconda Prompt 啟動 Jupyter Notebook。

從 Anaconda Navigator 啟動 Jupyter Notebook

Mac 請從 Finder > Applications 點選 Anaconda Navigator。

Windows 請從 Search 點選 Anaconda Navigator。

點選想啟動的 App，以下我們點選 Jupyter Notebook 的 Launch。

瀏覽器開啟 Jupyter Notebook 的視窗，可新增 notebook 或開啟某個 notebook。

新增 notebook 有兩個方法。

  • 點選 File > New > Notebook。
  • 點選 New > Python。

開啟 notebook 後若出現 Select Kernel 視窗請點選 Select 選擇 Python。

在 cell 輸入 python 程式，按下 shift + return 執行。

從 Anaconda Navigator 啟動 Jupyter Notebook 儲存的 notebook 預設將存在個人帳號的資料夾下。

從 Mac 的 Terminal 或 Windows 的 Anaconda Prompt 啟動 Jupyter Notebook

  • Mac 的 Terminal。

打開 Terminal，使用 cd 指令切換到某個資料夾，然後輸入以下指令啟動 Jupyter Notebook。

conda activate
jupyter notebook

之後建立的 notebook 將存在剛剛切換到的資料夾下。

  • Windows 的 Anaconda Prompt。

從 Windows Search 點選 Anaconda Prompt。

使用 cd 指令切換到某個資料夾，然後輸入 jupyter notebook 啟動 Jupyter Notebook。
