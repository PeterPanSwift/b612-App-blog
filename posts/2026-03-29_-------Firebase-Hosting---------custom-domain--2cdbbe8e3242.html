將網站部署到 Firebase Hosting 並綁定自訂網域(custom domain)

現在我們常常用 AI 開發網站，但是完成後要怎麼上線讓別人連到呢 ? 通常要經過網站部署和綁定網域兩個步驟。

以下彼得潘以 Google AI Studio 開發的學生問答網站為例，示範如何將網站部署到 Firebase Hosting，然後再綁定自訂網域(custom domain)。

將網站部署到 Firebase Hosting

為了讓 AI 能下指令將網站部署到 Firebase，請先安裝 Firebase CLI。

方便管理 Firebase 的 Firebase CLI(Command Line Interface)
透過 Firebase CLI 我們可以方便地從 Terminal 下指令管理 Firebase 專案和部署網站。以下彼得潘簡單介紹如何在 macOS & Windows 安裝 Firebase CLI。medium.com

安裝好後在 Terminal 透過指令 firebase login 登入 Firebase 帳號。

接著用 VS Code 開啟網站專案，然後請 AI Codex 幫忙將網站部署到 Firebase Hosting。

若網站原本就有 Firebase 的相關功能，AI 能找出連結的 Firebase Project ID，它將自動部署到連結的 Firebase 專案。從下圖可看出專案的 firebase-applet-config.json 帶有 Firebase Project ID，因此 AI 能找出連結的 Firebase 專案。

若網站沒有 Firebase 的相關功能，AI 將詢問我們要連結哪個 Firebase 專案，或是幫我們建立全新的 Firebase 專案。

AI 成功將專案部署到 Firebase Hosting，訊息如下。

Firebase 幫網站生成的預設網址為 https://gen-lang-client-0418597643.web.app/ 。

連到 Firebase 的專案管理網頁，切到託管和無伺服器的 Hosting 分頁。

從下圖可看到新增了兩個可連線的網域，證明 AI 成功將網站部署到 Firebase Hosting。

綁定自訂網域(custom domain)

若想另外搭配自訂網域，請點擊新增自訂網域。

輸入網域，在此彼得潘輸入 qa2.p207.app。

將下圖的資訊記下來，待會我們將在 DNS 管理頁面進行設定，如此 qa2.p207.app 才能順利導到 gen-lang-client-0613937854.web.app 。

彼得潘透過 Cloudflare 管理網域 p207.app，因此連到 Cloudflare 後點選 p207.app。

Connect, protect, and build everywhere
Make employees, applications and networks faster and more secure everywhere, while reducing complexity and cost.www.cloudflare.com

切換到 DNS 下的 Records 分頁，點選 Add record。

輸入剛剛記下的資訊，Type 選擇 CNAME(網域別名)，Name 輸入 qa2，Target 輸入 gen-lang-client-0613937854.web.app，Proxy 記得關掉。Name 不用輸入 qa2.p207.app，因為我們正在設定的網域就是 p207.app。

回到剛剛的 Firebase 頁面，點擊驗證。

通常需要幾分鐘到 24 小時才能驗證成功，請休息一下再回來查看。

彼得潘運氣不錯，等了不到十分鐘即出現已成功設定自訂網域。

最後還需等待建立憑證的動作完成。

大概等個五分鐘後，彼得潘看到了狀態變成已連結。

現在終於可以從新網址 https://qa2.p207.app/ 連到 P207 App 問答星球。
