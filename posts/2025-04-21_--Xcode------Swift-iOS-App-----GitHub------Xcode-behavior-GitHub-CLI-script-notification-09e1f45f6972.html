撰寫將 Xcode 專案上傳到 GitHub 的 script submit_xcode_project_to_github.sh

#!/bin/zsh

# 🏡 專案資料夾
project_dir=${XcodeProjectPath%/*}
cd "$project_dir" || exit

# 🐣 Commit 所有變更
git add .
git commit -m "📚 作業更新 - $(date '+%Y-%m-%d %H:%M:%S')" 2>/dev/null

export PATH="$PATH:/opt/homebrew/bin"  

# 🐙 如果沒連接 GitHub，幫他建立 repo
if ! git remote get-url origin &> /dev/null; then
  repo_name=$(basename "$project_dir")
  if gh repo create "$repo_name" --public --source=. --remote=origin --push; then
    # 🦊 成功建立後取得網址
    repo_url=$(git remote get-url origin)
    echo "$repo_url" | pbcopy
    osascript -e "display notification \"Repo 建立成功 🎉🦊\n網址已複製到剪貼簿！\" with title \"GitHub 上傳成功\" subtitle \"$repo_name\""
  else
    osascript -e "display notification \"建立失敗！請檢查 repo 是否已存在 🥲\" with title \"上傳失敗\""
fi
else
  git push origin main 2>/dev/null || git push origin master
fi

以上 script 將進行以下動作。

  • 用 git 指令記錄專案的所有修改。
  • 利用 gh repo create 指令在 GitHub 上建立 repository，內容來自 Xcode 專案。
  • 將專案的 GitHub 網址複製到剪貼簿。
  • 顯示成功或失敗的通知。

寫好 script 後，記得要設定檔案的執行權限。

chmod +x submit_xcode_project_to_github.sh

設定執行 script 的 Xcode behavior 和快速鍵

新增 behavior Submit to GitHub，設定執行 submit_xcode_project_to_github.sh，快速鍵設為 cmd+option+ctrl+s。

從 Xcode 一鍵上傳專案到 GitHub

假設同學完成了作業，專案裡有一些修改和新增的檔案。

One more thing: 讓使用者輸入 commit message & repository name

在 script 加入 display dialog 讓使用者輸入 commit message & repository name。

#!/bin/zsh

# 🧁 提示使用者輸入 commit 訊息
commit_message=$(osascript <<'END'
tell application "System Events"
    activate
    try
        text returned of (display dialog "請輸入這次的 commit 訊息：" default answer "📚 作業更新" with title "Git Commit 訊息" buttons {"OK"} default button 1)
    on error
        return "📚 作業更新"
    end try
end tell
END
)

# 🍰 提示使用者輸入 GitHub repo 名稱
repo_name=$(osascript <<'END'
tell application "System Events"
    activate
    try
        text returned of (display dialog "請輸入 GitHub repo 名稱：" default answer "" with title "GitHub Repository 名稱" buttons {"OK"} default button 1)
    on error
        return ""
    end try
end tell
END
)

# 🏡 專案資料夾
project_dir=${XcodeProjectPath%/*}
cd "$project_dir" || exit

# 🐣 Commit 所有變更
git add .
git commit -m "$commit_message" 2>/dev/null

export PATH="$PATH:/opt/homebrew/bin"

# 🐙 如果沒連接 GitHub，幫他建立 repo
if ! git remote get-url origin &> /dev/null; then
  # 若未輸入 repo 名，使用資料夾名稱
  [[ -z "$repo_name" ]] && repo_name=$(basename "$project_dir")

  if gh repo create "$repo_name" --public --source=. --remote=origin --push; then
    # 🦊 成功建立後取得網址
    repo_url=$(git remote get-url origin)
    echo "$repo_url" | pbcopy
    osascript -e "display notification \"Repo 建立成功 🎉🦊\n網址已複製到剪貼簿！\" with title \"GitHub 上傳成功\" subtitle \"$repo_name\""
  else
    osascript -e "display notification \"建立失敗！請檢查 repo 是否已存在 🥲\" with title \"上傳失敗\""
  fi
else
  git push origin main 2>/dev/null || git push origin master
fi

執行 Xcode behavior Submit To GitHub 時將出現 commit message & repository name 的輸入框。
