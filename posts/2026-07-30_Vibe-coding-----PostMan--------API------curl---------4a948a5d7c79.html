Vibe coding 自己的 PostMan — 開發串接 API，執行本機 curl 指令的精美網頁

開發 App 時，我們常常會利用 PostMan 或 curl 指令測試 API。相較於 PostMan，curl 指令簡單許多，只要在 Terminal 貼上即可執行，但它生成的結果不像網頁那樣漂亮，也無法展開折疊 JSON。

所以彼得潘決定請 AI 幫忙，Vibe Coding 一個自己的 PostMan 工具 !

以下彼得潘使用 Codex 開發，搭配 GPT 5.6 Sol high，輸入的主要 prompt 如下。

開發一個在本機跑的網頁，觸發本機的 curl 指令串接外部 API，在網頁顯示漂亮的 JSON 結果。
不需要使用 Sites 建置技能

成果如下，北極狐風格的 PostMan，名字取名為 Curl Canvas ~
