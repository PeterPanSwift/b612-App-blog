使用 Google AI Studio 開發串接後台的網站

透過 Google AI Studio 我們可以利用 AI 開發完整的網站，而且還能方便地串接後台和 API。

最近彼得潘正在看李宏毅教授的 AI 教學影片，想到不如就用 Google AI Studio 開發一個學習記錄網站，測測它開發的能力。

以下是網站主要的功能清單。

  • 新增和瀏覽學習記錄。
  • 使用 Firebase Firestore 將資料存在雲端。
  • 使用 Firebase 實現 Google 登入。
  • 使用 Firebase Storage 儲存上傳的照片。
  • 使用 Google Places API 查詢地點。

連到 Google AI Studio。

Google AI Studio
The fastest path from prompt to production with Geminiaistudio.google.com

點選右上方的 Get started 登入 Google 帳號。

點選左側的 Build。

點選右上方的設定按鈕。

model 選擇比較厲害的 Gemini 3.1 Pro Preview。

輸入以下 prompt，點選 Build 生成網站。

開發一個學習記錄 App，功能如下。
1. 記錄的資訊包含名字、連結、日期、note、是否完成。
2. 資料存在 Firebase。
3. Google 帳號登入。

儲存資料的地點選擇 Taiwan，然後點選 Enable 完成 Firebase 的初始設定。

ps: 之後若忘記連結的 Firebase 專案，可直接輸入 prompt 詢問 AI。

連結的 Firebase 專案網址?

AI 成功生成第一版的學習記錄 App。

從右邊的 Preview 可操作 App，

點選 Sign in with Google 登入帳號後即可記錄學習的資料。

接著我們繼續修改 App，將它變得更漂亮。

畫面上加入可愛的北極狐元素，使用 AI 生成圖片

網頁將在顯示時利用 AI 即時生成可愛的北極狐圖片。

不過網頁的右側一直轉個不停，聊天視窗的下方也出現了錯誤訊息，2 errors running the code。沒關係，按下 Fix 叫 AI 修正，AI 自己造的 bug 自己修。

AI 成功地修正了問題。

彼得潘後來想了想，比較喜歡直接在專案加入極光和北極狐的圖片，而不是在網頁顯示時透過 AI 生成隨機的圖片。

使用 AI 生成冰島極光風格的背景圖片和北極狐圖片，將圖片加入專案，不要在顯示網頁時動態生成

可惜 AI 說它無法生圖，它改成另外下載圖片再加到專案。

但是網頁並沒有出現極光的背景呀，切到 Code 頁面查看專案後，發現果然是圖片的問題。

因此我們改成另外用 AI 生圖，然後手動將圖片上傳到左側的 public 資料夾。

網站終於出現了美麗的極光背景和可愛北極狐。

現在我們可點選右上方的 Publish，將它變成人人都能連的網站。

在發佈前我們必須點選 Set up billing，設定網站搭配的付款帳號。

Google 會提供一些免費的額度，超過才會付錢。為了怕不小心超過付出大量金額，最好點選 Set spend cap 設定每月上限。

如果完全不想花錢，可將金額設為 0。

點選 Publish app 發佈 App。

從 App URL 可看到 App 的網址。

彼得潘連到剛剛的網址，成功記錄李宏毅教授的優質課程，生成式AI時代下的機器學習。

Google AI Studio 不能修改網站的網址，若想將網址改成自訂網域，必須將網站的專案程式部署到其它地方，方法可參考以下連結。

將 Google AI Studio 開發的網站綁定自訂網域(custom domain)
將 Google AI Studio 開發的網站綁定自訂網域(custom domain) 透過 Google AI Studio …apppeterpan.medium.com

接著讓我們繼續添加功能，試試能不能串接 Google Places API。

記錄時增加地點欄位，顯示附近的地點列表讓使用者選，
使用者也可以輸入文字搜尋，使用 Google Places API

看來程式難不倒 AI ，只是我們要自己去 Google Cloud Console 進行相關設定和取得 API key。

接著我們再試試常見的照片上傳功能。

記錄時可設定多張照片

AI 利用 Firebase Storage 儲存上傳的照片。

不過彼得潘測試時，發現照片上傳出了點問題。

加了照片後，一直停在 Uploading 耶

原來是權限的問題，目前 AI 可以自動設定 Firestore 的權限，但是 Storage 存檔的權限則須我們自己設定。

連到 Firebase 專案的 Storage 頁面貼上剛剛 AI 提供的權限規則。

加了新功能後，原本上線的網站並沒有更新，因此記得要打開 Publish 頁面，點選 Re-publish app 更新網站。

現在我們記錄時可以設定地點跟上傳多張照片。

利用 Google Places API 列出附近的誠品。

上傳照片時可從電腦一次選擇多張照片。

點選 Save Record 新增資料。

列表顯示學習記錄時多了地點和照片。

我們也可以連到 Firebase 的專案頁面查看資料是否真的存在上面。

Authentication 頁面顯示登入過的使用者清單。

Firestore 頁面顯示學習記錄清單。

Storage 頁面顯示照片清單。

若想下載專案的程式，可在 Google AI Studio 的專案頁面切到 Code 分頁，

然後點選右上方的下載按鈕取得專案的 zip 檔。

專案也可以跟 GitHub 連結，從專案頁面點選右上方的設定按鈕。

然後切換到 GitHub 分頁進行設定。

AI 還會幫我們填寫詳細的 commit 訊息。
