使用 Claude 的 Computer use 控制 Mac 開發 iOS App — 建立 Xcode 專案、寫程式、執行模擬器、螢幕錄影、上架 App、加套件

最近 Claude 推出強大的 Computer use 功能，我們平常在電腦的大部分操作它都能辦到。它就像真人一樣能看到螢幕畫面，然後進行點擊移動滑鼠和打字等操作。

Let Claude use your computer in Cowork | Claude Help Center
Claude can now use your computer to complete tasks in Cowork and Claude Code (refer to our Claude Code Docs for more…support.claude.com

以下彼得潘以開發 iOS App 的基本操作當考題，試試 Claude 是否能達成任務。

  • 建立 Xcode 專案。
  • 寫程式。
  • 執行模擬器。
  • 從模擬器操作 App 並進行錄影。
  • 上架 App。
  • 使用 SPM 加套件。

啟用 Computer Use

打開 Claude App 的設定頁面，打開 Desktop app 下的 General > Computer Use 開關。

點選 Turn on。

切到 Claude App 的 Cowork 分頁進行操作。

建立 Xcode 專案

請使用 Xcode 建立 iOS SwiftUI App project

Claude 必須取得權限才能控制電腦，請點選 Request 打開 Accessibility & Screen recording 的權限。

設定權限後重啟 Claude，再次輸入 prompt。

請使用 Xcode 建立 iOS SwiftUI App project

Claude 徵求使用 Xcode 的權限，點選 cmd + return 同意。

點選 Allow。

Claude 成功打開 Xcode 的專案建立視窗。

但是 Claude 因為權限問題不能輸入專案名字，我們得自己手動輸入。

輸入名字後跟 Claude 說聲打好了，按 Next 就交給它了，彼得潘懶得按 Next。

Claude 成功建立 iOS App 專案。

寫程式

請 Claude 做它最擅長的工作寫程式。

修改畫面，做一個打地鼠 App

唉，因為權限問題，Claude 無法直接修改檔案。不過它已經複製到剪貼簿，我們可以自己在 Xcode 按下 cmd + a 和 cmd + v 貼上，右邊的 Preview 成功出現可愛的打地鼠畫面。

執行模擬器

啟動 iPhone Air 模擬器執行 App

Claude 誤以為模擬器是 Preview 的裝置，因此我們再下一次 prompt，明確跟它說請從上方選擇裝置。

上方的裝置選擇 iPhone Air，然後執行 App

點選 cmd + return 同意存取模擬器的權限。

Claude 成功選到 iPhone Air 模擬器。

App 順利地在模擬器啟動。

從模擬器操作 App 並進行錄影

請在模擬器玩打地鼠 App 並從模擬器進行錄影，玩到遊戲結束時停止錄影

Claude 成功在模擬器玩打地鼠，而且也將過程錄製成影片，雖然它玩得很爛，一隻地鼠也沒打到。

上架 App

請使用 Xcode 將 App 上傳

Claude 成功將 App 上傳到 App Store Connect。

使用 SPM 加套件

請 Claude 透過 Xcode 的 SPM 加套件。

請將套件 dotlottie-ios 加到 Xcode project

心得

Claude 的 Computer use 的確有很大的潛力，雖然它目前還有點笨，一個簡單的任務也要做很久，或是只能做到八成，需要我們人工介入幫忙。相信隨著時間推移，未來它應該能流暢地控制電腦做很多事，我們可以舒服地坐在椅子上看它工作就好。
