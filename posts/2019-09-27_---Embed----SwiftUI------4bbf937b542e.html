利用 Embed in 加入 SwiftUI 容器元件

SwiftUI 有一些特別的容器元件，專門以 { } 容納其它的元件，比方 HStack，VStack，List 等，Xcode 貼心地在選單裡提供 Embed in 功能，方便我們快速加入這些元件。

比方我們想將 Text 元件包在 VStack 裡。

struct ContentView: View {
    var body: some View {
        Text("Hello, world!")
            .padding()
    }
}
  • 方法一: 點選 Text 後，從 Quick Actions 點選 Refactor > Embed in。
  • 方法二: 選取要包住的整段程式， 叫出右鍵選單，然後點選 Refactor > Embed in。

點選 Embed in 後的程式如下。

在框框輸入元件的名字，在此我們輸入 VStack。

struct ContentView: View {
    var body: some View {
        VStack {
            Text("Hello, world!")
                .padding()
        }
    }
}

想一次 embed 多個 view 也不是問題。選取要 embed 的內容，然後點選 Refactor > Embed in。

ps: 按下 control + return 也可叫出右鍵選單。
