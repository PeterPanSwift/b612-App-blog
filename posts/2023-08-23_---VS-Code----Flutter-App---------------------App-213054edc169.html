使用 VS Code / Antigravity IDE 開發 Flutter App — 建立專案，打開專案和啟動模擬器執行 App

開發 Flutter App 時，我們有許多 IDE 可選擇，其中 VS Code / Antigravity IDE 是滿多人偏愛的 IDE，以下彼得潘示範使用 VS Code / Antigravity IDE 開發 Flutter App 的相關操作。

  • 建立 Flutter 專案。
  • 打開專案。
  • 啟動模擬器
  • 執行 App。
  • hot reload。

建立 Flutter 專案

  • 方法 1: 從 terminal 輸入指令。

打開 Terminal，輸入指令 flutter create + 專案名稱建立專案。

flutter create first_app

結果如下，成功產生專案的資料夾 first_app，資料夾下包含開發 App 會用到的相關檔案。

In order to run your application, type:

  $ cd first_app
  $ flutter run

Your application code is in first_app/lib/main.dart.

ps:

  1. 專案名稱的英文只能小寫，請用 _ 分隔單字，不能有空白或特殊字元，而且不能用數字開頭。

2. 專案資料夾避免存放在跟 iCloud 或 Dropbox 等雲端空間同步的地方，雲端同步將影響 Flutter App 的執行。

  • 方法 2: 從 Command Palette。

打開 Command Palette(cmd+shift+p)，輸入 flu，選擇 Flutter: New Project。

選擇 Empty Application。

選擇專案存放的地方。彼得潘選擇 Desktop 後再點選 Select a folder to create the project in。

輸入專案名字後按 enter。

勾選 Flutter App 支援的平台，然後點選 OK。

  • 方法 3: 從 AI 聊天視窗請 AI 建立 Flutter 專案。

打開專案

利用剛剛的方法 2 從 IDE 建立專案後將自動打開。如果當初是從 terminal 建立專案，啟動專案有以下方法。

  • 利用指令啟動專案。
利用指令啟動 IDE 開啟專案 — Xcode、VS Code、Antigravity IDE、Android Studio
在 Mac 下指令啟動 IDE 開啟專案十分簡單，只要輸入以下格式。medium.com
  • 從 IDE 點擊 Open Folder，然後選擇專案資料夾。

第一次打開專案時請點選 Yes, I trust the authors。

專案成功開啟的畫面。

啟動模擬器

我們必須先啟動模擬器，之後才能將 App 裝到模擬器上測試 。請點選下圖紅色框框的裝置按鈕。

或從 Command Palette(cmd+shift+p) 選單點選 Flutter: Select Device。

啟動某個模擬器，在此彼得潘選擇 Start iOS Simulator。

此時將開啟 Device Hub App，請選擇模擬器後點選 Start。

啟動成功後出現 iOS Simulator。

IDE 右下的裝置名稱也變成了 ios simulator。

習慣 Android 的朋友也可以選擇 Android 模擬器，比方 Start Pixel 10。Android 模擬器通常會有 cold boot 和無 cold boot 的選項，建議選擇無 cold boot，啟動速度會比較快。

ps: 硬碟空間太少可能會無法啟動模擬器，請確保有一定的硬碟空間。

如果找不到 Android 模擬器的選項，請參考以下連結新增 Android 模擬器。

從 Android Studio 的 Virtual Device Manager 新增 Android 模擬器(emulator)
Android 有許多不同機型的模擬器，我們可從 Android Studio 的 Virtual Device Manager 新增 Android 模擬器。medium.com

從 Terminal 也可以啟動模擬器，先輸入 flutter emulators 顯示模擬器清單。

然後再用 flutter emulators — launch 加模擬器名字啟動它，比方以下例子將啟動 iOS 模擬器。

flutter emulators --launch apple_ios_simulator

啟動 App

  • 方法 1: 點選三角形的啟動按鈕。

切換到 main.dart，然後點選右上方三角形的啟動按鈕。

ps: 三角形旁的下拉箭頭可選擇 Start Debugging 或 Run Without Debugging。

  • 方法 2: 點選 Start Without Debugging / Start Debugging。

從 Command Palette 或 menu 點選。

ps: Mac 的快速鍵請加上 fn，因此 Start Without Debugging 會變成 fn + ctrl + F5。

  • 方法 3: 點選 function main() 上方的 Run。

切換到 main.dart，然後點選 function main() 上方的 Run。

  • 方法 4: 切換到側邊欄的 Run and Debug 分頁，點選 Run and Debug。
  • 方法 5: 在 Terminal 輸入以下指令。
flutter run

hot reload

開發 Flutter App 時，我們可利用 hot reload 功能加快開發速度。當我們修改程式時，hot reload 會直接更新 App，因此我們不用再花時間重新啟動 App。

以下圖為例，我們將 main.dart 裡的 Hello World! 改成 Hello Kitty!。

存檔(快速鍵 cmd + s)後 App 的畫面馬上神奇地更新成 Hello Kitty!。

如果 App 畫面沒有自動更新，我們也可以自己點選下圖的閃電按鈕或從 Command palette 觸發 hot reload。

如果想偷懶，覺得按 cmd s 觸發 hot reload 有點辛苦，我們可透過以下步驟實現修改程式後自動 hot reload。
