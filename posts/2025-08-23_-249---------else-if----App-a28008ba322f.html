#249 模仿紅綠燈創作 else if 切換 App

紅綠燈切換的順序為 🟢 > 🟡 > 🔴 > 🟢，很適合寫成 else if 邏輯判斷，比方以下程式。

if currentState == "green" {
    currentState = "yellow"
} else if currentState == "yellow" {
    currentState = "red"
} else if currentState == "red" {
    currentState = "green"
}

Grok 實作的紅綠燈範例。

https://gist.github.com/PeterPanSwift/30f0cb2cfa702f345befc7da66df7691

請模仿紅綠燈發想其它例子，創作 else if 的切換 App。

ps: 因為要使用 else if，通常至少要有三種切換的 case。

AI 發現的例子。

  • 電池電量（滿電、中電、低電、沒電）
  • 咖啡機狀態（待機、沖泡、完成）
  • 天氣狀態（晴天 / 陰天 / 下雨）
  • 燈光模式（關燈、弱光、強光）
  • 貓咪心情（開心 / 想睡 / 生氣）
  • 冰淇淋口味（香草 / 巧克力 / 草莓）
