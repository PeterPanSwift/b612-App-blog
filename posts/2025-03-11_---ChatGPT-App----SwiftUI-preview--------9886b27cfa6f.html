使用 ChatGPT App 生成 SwiftUI preview 需要的假資料

設計 SwiftUI 畫面時，我們時常在 preview 生成畫面需要的假資料。以下我們示範使用 ChatGPT App 生成 SwiftUI preview 需要的假資料。

使用 Mac ChatGPT App 的 Work with App 修改程式
最近 Mac ChatGPT App 的 Work with App 推出新功能，現在它不只能讀取配對 App 的程式，還能直接幫我們修改程式呢。medium.com

以下為 SwiftUI 的範例畫面 AnimalRow。

import SwiftUI

struct AnimalRow: View {
    let name: String
    let emoji: String
    let description: String
    
    var body: some View {
        Text("Hello, World!")
    }
}

#Preview {
    AnimalRow()
}

我們加了三個 property，因此產生錯誤 Missing arguments。

以下我們使用 ChatGPT App 生成 AnimalRow 需要的假資料。

  • 範例 1。

AI 隨機生成某個動物的資料。

#Preview {
    AnimalRow(name: "Lion", emoji: "🦁", description: "King of the jungle")
}
  • 範例 2。

請 AI 生成企鵝相關的資料。

#Preview {
    AnimalRow(name: "企鵝", emoji: "🐧", description: "這隻企鵝活潑可愛，身披黑白羽毛，宛如小小紳士。牠在冰原上悠然自得，步履輕盈，展現優雅風采。每日在嚴寒中尋找快樂，無懼暴風雪與極夜，總以堅定勇敢的姿態迎接挑戰，散發獨特魅力，成為大自然中最耀眼的明星。！")
}
  • 範例 3。

為了讓 GPT 知道 Animal 有哪些參數，我們先輸入 Animal 的參數名字，方便 GPT 待會輸入框框的內容。

#Preview {
    AnimalRow(animal: Animal(
        name: "企鵝",
        emoji: "🐧",
        description: "企鵝是南極冰原上的可愛生靈，牠們穿著黑白羽毛，搖搖晃晃地走路十分滑稽。每天牠們聚在一起互相取暖，捕捉魚蝦充飢。夕陽西下時，牠們的身影拉長成一幅美麗畫卷。牠們活潑可愛，讓人感受到大自然的奇妙奧秘。真棒喔"
    ))
}

GPT App 其實也能一次讀取多個檔案。比方開啟兩個 Editor 視窗，讓 GPT 讀取 AnimalRow.swift & Animal.swift。

#Preview {
    AnimalRow(animal: Animal(name: "Cat", emoji: "🐱", description: "A cute cat"))
}
  • 範例 4。

我們也常將畫面顯示的資料定義成型別，以下我們想在 Animal 裡生成 preview 需要的假資料。

struct Animal {
    let name: String
    let emoji: String
    let description: String
    
    static let samplePenguin = Animal(name: "企鵝", emoji: "🐧", description: "企鵝生活於極寒冰原，其黑白相間的外表猶如燕尾禮服；牠們雖無法飛翔，但在冰海中能優雅游泳。笨拙步伐流露溫馨幽默，每一動作引得觀者會心微笑，牠們的可愛與堅韌，著實令人讚歎不已。展現生命韌性與美好，真動容。")
}
